## 摘要
物理AI的许多应用运行在有限或封闭的物理世界中，对象行为由有限的物理规律支配。例如在仓库中工作的机器人和在视频游戏中移动的智能体。为了更好地组织、过滤和策展物理AI应用的数据，我们提出了一种以个别数据集的独特设置和物理规律为中心的新方法。我们训练了LeCuration，一个小型世界模型，旨在作为独立的、更大的下游模型的数据策展工具。为了构建该模型，我们选择LeWorldModel（LeWM）作为潜在编码器和预测器，并添加了一个扩散Transformer（DiT）解码器，为自回归游戏推演添加视觉信息。我们发现该模型的嵌入可以用作异常检测信号和基于内容的聚类启发式方法，并且使用该模型自回归预测游戏状态使我们能够定性检查动作-状态一致性。本文在CS:GO游戏数据上提供了一个定性的概念验证案例研究；我们尚未报告定量的策展指标或下游训练结果，我们认为这是关键的下一步。

## Abstract
Many applications of physical AI run within finite or closed physical worlds with a limited set of physical laws governing object behavior. Examples include robots working in a warehouse and agents moving around in a video game. In order to better organize, filter, and curate data for physical AI applications, we propose a new approach centered on the unique settings and physical laws of individual datasets. We train LeCuration, a small world model intended to serve as a data curation tool for a separate, larger downstream model. To build this model, we choose LeWorldModel (LeWM)as our latent encoder and predictor, adding a diffusion transformer (DiT) decoder to add visuals to autoregressive gameplay rollout. We find that the embeddings of this model can be used as an anomaly detection signal and as a content-based clustering heuristic, and that auto-regressively predicting the game state with this model allows us to qualitatively check for action-state consistency. This paper presents a qualitative, proof-of-concept case study on CS:GO gameplay data; we do not yet report quantitative curation metrics or downstream training results, which we identify as the key next step.

## 2. 论文提出的方法论

### 2.1 核心思想

- 以 **LeWorldModel（LeWM）** 为基础，将其从规划/控制模型改造成**数据策展工具**。
- 核心理念：利用小型世界模型的潜在表示与预测误差，作为聚类、检索和异常检测的信号，而不需要标签或物理引擎信息。

### 2.2 模型架构

- **数据压缩层**：使用 Tiny AutoEncoder for Stable Diffusion（TAESD）将原始帧从 `224×224×3` 压缩到 `4×28×28` 的 Stable Diffusion 潜在空间。
  - TAESD 参数量约 2.4M，比原 Stable Diffusion 自编码器快约 20 倍。
- **Latent Encoder（潜在编码器）**：
  - 在 TAESD 潜在上工作的 patch-ViT。
  - 每个游戏帧输出一个 196 维的 CLS 世界状态向量 `e_{t+1}`，作为该帧的语义摘要。
  - 参数量约 2M。
- **Latent Predictor（潜在预测器）**：
  - Causal Transformer，隐藏维度 512，8 层，16 个头。
  - 输入为最近 6 帧的嵌入历史 + 动作嵌入，预测下一帧的世界状态 `\hat e_{t+1}`。
  - 参数量约 13M。
- **动作嵌入器**：
  - 将 51 维 one-hot 动作向量（键盘、鼠标等）映射到 196 维。
  - 结构：1D 卷积 + 2 层 MLP。
- **Diffusion Transformer（DiT）Decoder**：
  - 仅用于可视化，不参与策展信号计算。
  - 条件为 CLS 世界状态，生成 TAESD 潜在，再解码回 RGB 帧。

### 2.3 训练目标与公式

- 采用 JEPA 式自监督训练，目标为预测下一帧嵌入。
- 损失函数：
  \[
  L = \text{MSE}(e_{t-6:t}, \hat e_{t-6:t}) + \lambda \cdot \text{SigReg}(e_t)
  \]
  - 其中 `SigReg` 为 Sketch Isotropic Gaussian Regularizer，防止表示坍缩。
  - 正则系数 \(\lambda = 0.09\)。
- 使用 stop-gradient 目标，由编码器的慢 EMA 副本生成，EMA 衰减为 0.9999。

### 2.4 两阶段训练流程

1. **预训练阶段**：
   - 随机采样帧-动作序列，用 6 帧历史预测下一帧世界状态。
   - 300 epochs，batch size 32，耗时约 120 分钟。
2. **自回归后训练阶段**：
   - 从 6 帧窗口开始，自回归预测未来 50 帧世界状态，并与真实帧编码进行比较。
   - 使用折扣因子 1.03 强调更远帧的质量。
   - 20 epochs，batch size 16，耗时约 60 分钟。
3. **DiT 解码器训练**：
   - 在冻结的世界状态上训练，600 epochs，耗时约 30 分钟。

- **采样率**：帧和按键均为 16 Hz。
- **动作信息**：51 维 one-hot 编码的按键、鼠标移动等。
- **数据规模**：论文未给出总帧数或视频时长，但提到从训练语料中提取了 1M 个 CLS 嵌入用于聚类和最近邻检索，因此数据集至少包含百万级帧。
- **标签情况**：无任何人工标签、碰撞标注或物理监督，仅游戏视频 + 动作序列。

### 3.2 评估方式与“benchmark”

- 本研究是**定性、概念验证式**的，没有定量 benchmark，也没有与现有数据策展基线进行对比。
- 主要评估思路：
  - **嵌入聚类质量**：使用 UMAP + HDBSCAN 对 1M 个 CLS 嵌入聚类，观察簇是否与可识别的游戏场景对应。
  - **自回归最近邻检索**：将预测嵌入匹配到训练集中的最近邻真实帧，检查视觉一致性。
  - **覆盖率驱动的策展**：基于嵌入簇中心做 farthest-first traversal，提出覆盖最大化和稀有轨迹上采样策略，但未实际训练下游模型验证。
  - **异常检测信号**：自回归 rollout 时计算预测嵌入与真实嵌入的欧氏距离：
    \[
    d_t = \|\hat e_t - e_t\|_2
    \]
    观察 `d_t` 尖峰是否对应罕见、异常或突变的游戏事件。

### 3.3 对比方法

- 论文没有与传统数据策展方法（如随机采样、基于规则的过滤、CLIP 嵌入聚类等）进行定量对比。
- 主要参照物是 **LeWorldModel（LeWM）**，但本工作对 LeWM 进行了架构和用途上的修改，而非直接比较性能。
- 可视化方面对比了 DiT 生成帧与最近邻检索帧，认为在封闭地图数据集中，最近邻检索有时比 DiT 更清晰、更可解释。

## 6. 主要结论与发现

1. **小型世界模型可以作为数据策展多工具**：一个约 15M 参数的模型足以在大规模游戏数据上产生语义有意义的嵌入和预测。
2. **嵌入空间具有语义组织能力**：UMAP + HDBSCAN 聚类能够自动区分不同地图位置、视角、烟雾遮挡、门框剪影等场景，无需任何标签。
3. **最近邻检索验证了嵌入几何的语义一致性**：预测嵌入的最近邻真实帧在场景、朝向和光照上与预测内容高度一致。
4. **发现了模型的具体弱点**：武器在嵌入和生成中经常被错误表示，原因是武器在屏幕中占比小、相关动作出现频率低。这为下游数据策展提供了明确的方向——应过采样武器切换和射击片段。
5. **嵌入发散可作为无监督异常信号**：自回归 rollout 中 `d_t = \|\hat e_t - e_t\|_2` 的尖峰能够标记罕见或异常事件，如场景瞬移、遮挡、突发动作等。
6. **成本优势明显**：策展模型训练和推理成本远低于下游世界模型，嵌入和异常分数可缓存复用。

## 8. 不足与局限

  - 没有聚类纯度、检索精度、异常检测指标。
  - 未训练下游模型，无法证明策展策略的实际收益。

  - 仅在 CS:GO 单一地图 `de_dust2` 上测试，结论是否适用于其他游戏、机器人或真实物理数据未知。
  - 数据集不公开，结果难以复现。
- **异常信号不够物理特定**：
  - `d_t` 尖峰可能来自罕见路径、录像剪切、遮挡、累积 rollout 误差等，无法区分“视觉惊讶”与“物理不合理”。

- **最近邻检索对封闭世界依赖强**：
  - 在单一地图上效果好，但面对更丰富、开放的数据集可能失效。
- **无基线对比**：
  - 未与随机采样、规则过滤、CLIP 聚类等常见数据策展方法进行定量比较。
- **策展策略未验证**：
  - 覆盖率最大化、稀有轨迹上采样等策略只是提出，未实际训练下游模型评估效果。
- **动作信息利用有限**：
  - 动作是 51 维 one-hot，未深入探索连续动作或更复杂的输入表示。
