# ABSTRACT 

Synthetic data now is essential to LLM training, used to strengthen advanced capabilities such as autonomous and long-horizon task execution. Yet recent work shows that training on it at scale can degrade model generation, making it important to decide what synthetic data is worth training on. While current data curation practices do so with individual-level signals (i.e., estimates of each data sample’s training utility in isolation), across pre-training and post-training settings we show that this is insufficient for synthetic data, and that group-level signals (i.e., estimates of utility that account for interactions among data samples) are necessary for effective data curation. First, we show that individual-level signals are blind to how samples jointly affect training: synthetic datasets with different compositions can be indistinguishable under individual-level influence yet differ sharply under group-level influence, and curating by the latter yields better downstream performance, particularly in generative capability. Second, we find that group-level signals matter more as training pipelines become increasingly synthetic: among widely used data curation methods, only those incorporating them improve over baseline, with gains increasing when weights capturing relations among samples are amplified. Finally, we translate these findings into practice – for model developers under a compute budget, we offer a cheap diagnostic that prioritizes which groups of synthetic data most need group-level estimation, recovering much of the benefit of full group-level scoring at a fraction of the compute cost. 

# 1 INTRODUCTION 

Synthetic data is crucial to large language model (LLM) development, and is now heavily used across all stages of LLM training, from synthetic corpora in pre-training (Li et al., 2023; Abdin et al., 2024) to inducing reasoning post-training (Nvidia et al., 2024; Team, 2025). It supplies targeted training signal for advancing LLM capabilities that are difficult to learn from organic web data alone, such as extended-horizon coding autonomy (Pan et al., 2025), competition-level mathematics (Trinh et al., 2024; Ren et al., 2025; Hubert et al., 2026), and reliable tool use (Qin et al., 2023; Liu et al., 2024b). Although synthetic data is essential to continued progress in LLM capabilities, using it requires care. Recent work shows that training on it at scale can degrade LLM generative capabilities (a phenomenon known as “ model collapse ”) since synthetic data exhibits narrower coverage than organic web data and inherits generator biases (Dohmatob et al., 2024; Guo et al., 2024; Shumailov et al., 2024; Chen et al., 2024a). Moreover, these consequences are costly for LLM developers, who waste substantial compute to recover from collapsed training runs (Chowdhery et al., 2023; Wortsman et al., 2024; Grattafiori et al., 2024). Therefore, using synthetic data effectively requires understanding how it contributes to (or harms) model training, so that it can be selected carefully. While current data curation practices guide this selection with individual-level signals (i.e., estimates of each data sample’s training utility in isolation), we show that these signals are insufficient, and that effective synthetic data curation instead requires group-level signals (i.e., estimates of training utility that account for interactions among data samples). First, individual-level signals are blind to these interactions: using data influence measures to quantify the utility of synthetic datasets, we find that datasets with different compositions (e.g., domains and diversity) can be indistinguishable under 1arXiv:2610.00779v1 [cs.CL] 30 Sep 2026 individual-level influence yet differ under group-level influence. Curating training data by group-level influence also yields better downstream performance, particularly in generative capability .Next, we show that as LLM training pipelines grow increasingly reliant on synthetic data, incorporat-ing group-level signals in standard data curation methods is necessary to enhance model performance. Analyzing several data curation methods used in practice (Trotman et al., 2014; Xia et al., 2024; Yu et al., 2025; Wang et al., 2024), we find that, in this setting, methods which use group-level signals avoid model degradation and improve over baseline performance, whereas individual-level methods do neither. Gains increase further when the weights that capture relational information among data samples are amplified, suggesting that interactions within datasets should be modeled explicitly as pipelines rely more on synthetic data. Finally, we build on our findings to address a practical concern: group-level methods can be com-putationally expensive, since capturing interactions among data samples often requires additional memory and compute, and practitioners with limited resources need to know where to allocate budget for them. To guide this decision, we offer efficient diagnostics: by leveraging within-group gradient diversity, we identify groups where individual-level signals are likely to be misleading. Allocating budget to scoring these groups recovers much of the group-level signal at a fraction of the compute cost. To summarize, our contributions and findings are: 1. Individual-level signals are insufficient for curating synthetic data. Datasets that are indistinguishable under individual-level influence differ greatly in group-level influence, and curating by group-level influence yields better downstream performance. 2. Group-level signals matter more as data pipelines grow increasingly synthetic. Among widely used data curation methods, we find only methods which incorporate group-level signals improve over baseline, with gains in generative capability. 3. Leveraging group-level signals under a compute budget. We offer practitioners cheap diagnostics, leveraging within-group gradient diversity, to decide where group-level signals are worth computing under a tight budget.

However, for the individual proxy oracle, cheaper approximation methods exist for LLM data curation, such as LESS and LoGRA (Choe et al., 2025; Xia et al., 2024), making the individual proxy oracle in Equation (2) tractable for group-level influence estimation compared to the true group-level oracle. With these measures in place, a natural question is why synthetic data calls for particular attention. Below, we discuss two key challenges that arise in curating synthetic datasets when we solely rely on individual-level scores. 

Challenge 1: Synthetic data is homogeneous. A large synthetic corpus is often generated from a few seed prompts (Li et al., 2023; Maini et al., 2024) (e.g., instruction-following data bootstrapped from a small pool of human-written tasks (Wang et al., 2023b; Taori et al., 2023)), making it more homogeneous than an organic corpus collected from the web. This homogeneity makes it harder to distinguish the synthetic samples that most improve model performance. As shown in Figure 1a, synthetic data samples have lower variance than organic ones not only at the token-level and in information density, but also in individual-level data influence. 

Challenge 2: A dataset’s value is non-additive. Moving beyond individual data points, a dataset’s value is shaped by the combined contribution of its members: interactions between samples can induce cancellation or amplification effects (Koh et al., 2019; Basu et al., 2020), making a dataset’s value non-additive in its samples. These properties are invisible to an individual scorer. Figure 1b shows an example, where the individual proxy oracle does not track the group oracle, causing a mismatch between the datasets each ranks highly for model training, which we explore in the following sections. 

# 3 GROUP -LEVEL SIGNALS FOR SYNTHETIC DATA INFLUENCE 

The previous section showed that the individual proxy oracle and the group oracle can disagree. Here, we show through controlled experiments that this disagreement matters in practice: synthetic data groups that look equivalent under the individual proxy can differ significantly in group-level influence and downstream value. The remainder of the section describes the task settings in Section 3.1, the experimental procedure in Section 3.2, and the results in Section 3.3. 33.1 TASK SETTINGS 

We study the gap between individual and group-level influence in pre-training and post-training settings. The datasets and models used in both settings are described below. 

Pre-training. The first setting is synthetic data pre-training, which is increasingly being incorpo-rated into frontier LLM training pipelines (Liu et al., 2024a; Grattafiori et al., 2024; Yang et al., 2025). In this setting, we train on data from the Repro-Rephrased-72B (Yu & Xiong, 2025) dataset, which has been refined from low-quality web scrapes, and oracle scoring uses Repro-400M (trained on 6.59B Repro tokens) (Yu & Xiong, 2025) as the base model against a 128-sample FLAN (Chung et al., 2024) reference set, following prior oracle-scoring work (Yu et al., 2024; 2025; Jiao et al., 2025). We evaluate on eight standard pre-training benchmarks (ARC-Challenge, CommonsenseQA, CoQA, HellaSwag, LAMBADA, MMLU, PIQA, SQuAD). 

Post-training. The second setting is post-training using reinforcement learning with verifiable rewards (RLVR), a key factor in inducing reasoning in LLMs for coding, math, and agentic tasks. Here, we train on data from the GooseReason (Lu et al., 2026) dataset, and oracle scoring uses Qwen2.5-1.5B-Instruct (Qwen et al., 2025) as the base model against a 128-sample GPQA-extend (Rein et al., 2024) reference set, chosen for its graduate-level, multi-domain reasoning coverage. Together, our results point to two blind spots in synthetic data curation. First, practitioners should not rely solely on individual-level scor-ing, as interactions between samples influence model training in ways that individual-level scor-ing does not capture. As in Section 3, our findings suggest that forming groups of data to train on requires careful consideration. As data pipelines come to depend on synthetic and self-generated data, group effects in data selection methods should be modeled directly to prevent suboptimal selection. 

# 5 DIAGNOSTICS FOR GROUP -L EVEL DATA SELECTION 

In this section, we turn to the practical cost of group-level scoring. Because group-level scores capture relational information between samples, they require more compute than individual-level scores, raising the question of where practitioners with limited compute should spend a group-scoring budget. We show that this question has a principled answer: the gap between individual and group scoring is bounded by a quantity that is cheap to compute, which serves as an efficient diagnostic that 7reliably predicts the gap in practice and directs group oracle calls to the groups that are most poorly reflected by individual-level scoring.

# 6 CONCLUSION 

In this paper, we asked which signals identify what synthetic data is worth training on, and showed that group-level signals, which capture interactions among samples, are needed. Across pre-training and post-training, synthetic datasets indistinguishable under individual-level influence differ under group-level influence, which also yields better downstream performance, with gains concentrated in generative capability. Among widely used data curation methods, only those using group-level signals improve over baseline, with further gains when relational weights are amplified. Finally, we recommend within-group gradient diversity as a diagnostic for when group-level signals are worth their cost. Our findings motivate future work on scalable group-level curation methods that model this relational structure directly. 97 ACKNOWLEDGMENTS

# A RELATED WORK 

Synthetic data for LLM Training. Synthetic data is now used at every stage of LLM training. In pre-training, it supplements or rewrites web text to raise its information density, either through textbook-style generation (Li et al., 2023; Abdin et al., 2024) or by rephrasing and recycling existing documents (Maini et al., 2024; Nguyen et al., 2025; Yu & Xiong, 2025). In mid-training, it is used to target specific capabilities before post-training, such as long-context, math, and code (Team, 2024; Yang et al., 2024; OLMo et al., 2025; Zeng et al., 2026). In post-training, it supplies instruction-following and reasoning supervision that is difficult to source from humans at scale, through self-generated instructions (Wang et al., 2023b; Taori et al., 2023; Mitra et al., 2024), distillation from larger teachers (Adler et al., 2024; Team, 2025), and self-improvement over verified model outputs (Zelikman et al., 2022; Singh et al., 2023; Yuan et al., 2023). It is also used to construct the environments and tasks that post-training runs over, including tool-use APIs and trajectories (Qin et al., 2023; Liu et al., 2024b) and verifiable tasks for reinforcement learning (Lu et al., 2026). 

Synthetic data selection. While past work has shown that individual-level data selection is effective for organic data (including representation-based (Pezeshkpour et al., 2021), gradient-based (Grosse et al., 2023; Kwon et al., 2024; Xia et al., 2024), and lexical methods (Trotman et al., 2014)), synthetic data often exhibits different characteristics. These characteristics include lower information density (Maini et al., 2024; Kang et al., 2025), under-representation of rare entities or domains (Zhu et al., 16 2024; Yu & Xiong, 2026), and more templated phrasing (Niklaus et al., 2026). Synthetic data curation therefore requires additional considerations, such as task complexity, environment construction, and model biases (Long et al., 2024; Nadˇ a¸ s et al., 2025). Selection strategies for synthetic data largely score each generation on its own, filtering by quality or reward models (Chen et al., 2024b; Wettig et al., 2024) or by similarity to a target task (Xia et al., 2024; Trotman et al., 2014). A smaller line of work instead scores generations against one another, promoting diversity or limiting redundancy across the retained set (Chen et al., 2024a; Zhu et al., 2024). 

Group-Level Data Influence. Since data inclusion decisions are typically made over groups rather than individual samples, a line of work has examined how influence estimates behave at the group level. Group influence is not the sum of its parts: the effects of individual samples can amplify or cancel one another, and the change induced by any single sample is small relative to that of the group it belongs to (Koh et al., 2019; Basu et al., 2020; Hu et al., 2024). The most common approach nonetheless scores a group by aggregating the influence estimates of its samples (Wang et al., 2023a; Zhang et al., 2025a;b). Cooperative-game formulations instead average a sample’s marginal contribution across subsets (Ghorbani & Zou, 2019; Jia et al., 2019; Wang & Jia, 2023), though the resulting scores remain per-sample and are again summed to value a group. A third line of work models the group directly, either by predicting model behavior as a function of the training subset (Ilyas et al., 2022; Park et al., 2023; Engstrom et al., 2024) or by estimating influence alongside relational information between samples in the same group (Wang et al., 2024; Sun et al., 2025; Yu et al., 2025).

20 B.5 DATA SELECTION METHODS 

This section presents additional details regarding the data selection methods from Section 4.1. B.5.1 FINE WEB -E DU 

The FineWeb-Edu (Penedo et al., 2024) classifier is a lightweight encoder-based regressor (a BERT-based encoder with a single-output regression head) that rates a document’s educational value from 0

to 5. We score every sequence in the pool independently. The classifier accepts at most 512 tokens. Therefore, for a given data sample, we score each chunk, and average the chunk scores to obtain a single score per sequence. For groups of samples, we average the individual sequence scores to obtain a single score per group. B.5.2 BM25 BM25 (Trotman et al., 2014) is a standard information retrieval method that ranks training samples based on lexical similarity to a query. The reference set sequences are decoded to text and whitespace-tokenized to form a BM25-Okapi document collection of documents, built once; each candidate sequence is then decoded and whitespace-tokenized in the same way and issued as a query against that collection. The score of a sequence is the mean of its BM25 scores, so higher scores indicate greater lexical relevance to the reference set and sequences are again ranked in descending order. B.5.3 GRAD SIM 

GradSim (Pruthi et al., 2020) estimates influence with the first-order inner product between the gradient of the loss on a training sample and the gradient of the loss on the reference set. We first compute a single reference gradient by back-propagating the token-weighted mean loss over the reference set at the base checkpoint θ; the base checkpoint is the same one used for oracle scoring in each setting (Table 3). We then compute, for each candidate sequence z, the gradient ∇θ L(z, θ ) at that same checkpoint. Each candidate is scored by the cosine similarity between its gradient and the reference gradient. B.6 GROUP FORMATION 

In this section, we describe the group formation procedure used in Section 4.1. For each data selection method considered in that section, we construct groups using a cluster-based inference procedure (Yu et al., 2025). We adopt this procedure to reduce computational cost, since some data selection methods (e.g., GMRel (Yu et al., 2025) and GREATS (Wang et al., 2024)) require iterative rounds of scoring over the entire dataset. Specifically, for each synthetic dataset from Section 4, we embed every sequence with BGE-base-en-v1.5 (Xiao et al., 2024) and partition the pool into 30 clusters via k-means. We then sample 20 

clusters and use each data selection method to form one group of size s = 5120 from each sampled cluster, yielding 20 groups per method. Individual-level scorers (i.e., GradSim (Pruthi et al., 2020), FineWeb-Edu (Penedo et al., 2024), and BM25 (Trotman et al., 2014)) form each group greedily by taking the top-scored samples within a cluster. GMRel (Yu et al., 2025) and GREATS (Wang et al., 2024) instead form each group through a relational greedy process: starting from an empty group, they repeatedly add the candidate with the highest score after re-scoring against the partially formed group , so that each addition accounts for its relation to the samples already selected, as described in Appendix B.5.
