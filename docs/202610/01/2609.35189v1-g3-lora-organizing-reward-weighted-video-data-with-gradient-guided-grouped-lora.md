## 摘要
在异构奖励加权数据上对基础视频模型进行后训练通常假设所有数据类别都会产生兼容的更新。当类别对应于不同的技能、领域或评估维度时，这一假设是脆弱的。我们在文本到视频后训练中研究此问题，其中 VBench2.0 维度定义数据桶，外部多模态奖励流水线分配样本权重。我们提出 G$^3$-LoRA（梯度引导的分组 LoRA），这是一种数据组织流程，它探测由奖励加权视频样本诱导的类别级梯度，移除共享的全局更新方向，根据残差梯度兼容性对类别进行聚类，训练特定分组的 LoRA 专家，并通过权重合并及随后从专家进行在线策略蒸馏将它们整合为一个适配器。我们通过将奖励加权流匹配视为速度场回归来论证这一流程：不兼容的奖励维度可能在重叠的噪声潜在区域中偏好不同的去噪方向，导致共享 LoRA 训练平均化能力。在 Wan2.1-T2V-1.3B-Diffusers 上，合并后的分组适配器在匹配的 VBench2.0 评估上优于基础模型、联合奖励加权 LoRA 基线以及使用相同流程训练的随机、语义和原始梯度划分；独立评估者也同意这一结论，并且在 CogVideoX-2B 上分组避免了联合训练的负迁移。增益并不均匀：合并压缩了最大的专家增益，蒸馏恢复了部分损失，而摄像机运动和若干局部质量维度仍然具有挑战性。总之，这些结果表明梯度兼容性可以作为组织奖励加权视频后训练数据的一种实用诊断工具。

## Abstract
Post-training foundation video models on heterogeneous reward-weighted data usually assume that all data categories induce compatible updates. This assumption is fragile when categories correspond to different skills, domains, or evaluation dimensions. We study this problem in text-to-video post-training, where VBench2.0 dimensions define data buckets and an external multimodal reward pipeline assigns sample weights. We propose G$^3$-LoRA (Gradient-Guided Grouped LoRA), a data organization procedure that probes category-level gradients induced by reward-weighted video samples, removes the shared global update direction, clusters categories by residual gradient compatibility, trains group-specific LoRA experts, and consolidates them into one adapter by weight merging followed by on-policy distillation from the experts. We motivate this procedure by viewing reward-weighted flow matching as velocity-field regression: incompatible reward dimensions may prefer different denoising directions in overlapping noisy latent regions, causing shared LoRA training to average capabilities. On Wan2.1-T2V-1.3B-Diffusers, the merged grouped adapter improves the matched VBench2.0 evaluation over the base model, a joint reward-weighted LoRA baseline, and random, semantic, and raw-gradient partitions trained with the same pipeline; an independent evaluator agrees, and on CogVideoX-2B grouping avoids the negative transfer of joint training. The gain is not uniform: merging compresses the largest specialist gains, distillation recovers part of this loss, and camera motion and several local-quality dimensions remain challenging. Together, these results suggest that gradient compatibility can serve as a practical diagnostic for organizing reward-weighted video post-training data.

- **具体场景**：论文以 VBench2.0 的 17 个非多样性评估维度定义数据桶，用外部多模态奖励流水线（Qwen3-VL-8B-Instruct）为每个样本赋予标量权重，再训练 LoRA 适配器。
- **整体含义**：将异构视频后训练重新表述为一个**数据组织问题**：类别应当按照优化兼容性分组，而不是仅按语义标签分组；梯度兼容性可以作为组织奖励加权视频后训练数据的实用诊断信号。

## 2. 论文提出的方法论

- **核心思想**：通过探测各类别在奖励加权流匹配损失下的梯度，移除共享全局更新方向，利用残差梯度之间的余弦相似度衡量类别兼容性，再据此聚类、训练分组专家并合并。
- **关键技术步骤**：
  1. **奖励加权类别梯度探针**：对每个类别 \(i\)，在固定扩散时间步和噪声种子下，估计奖励加权 LoRA 梯度 \(g_i = \frac{1}{|B_i|}\sum_{x\in B_i}\nabla_\phi L(\phi;x)\)，其中损失为奖励加权的流匹配 MSE：\(L(\phi;x)=\frac{w}{\bar w}\|\hat u_\phi(z_t,p,t)-u\|_2^2\)。
  2. **移除共享更新方向**：计算全局混合梯度 \(g_{global}\)，并从每个类别梯度中投影掉该方向，得到残差 \(r_i = g_i - \frac{\langle g_i,g_{global}\rangle}{\|g_{global}\|_2^2+\epsilon} g_{global}\)。
  3. **残差兼容度矩阵**：定义类别间相似度 \(S_{ij} = \frac{\langle r_i,r_j\rangle}{\|r_i\|_2\|r_j\|_2+\epsilon}\)，在多个训练阶段（0%、25%、50%、75%、100%）平均得到 \(\bar S_{ij}\)；正相似表示兼容，负相似表示潜在干扰。
  4. **聚类分组**：以距离 \(D_{ij}=1-\bar S_{ij}\) 进行 average-linkage 层次聚类，选择 \(M=5\) 组，使组内残差相似度为正、组间冲突最小化。
  5. **分组 LoRA 专家训练与合并**：每组训练一个 LoRA 专家（rank 8），然后将各专家的稠密权重增量按组大小加权平均，并通过截断 SVD 重新压缩为单一 rank-40 LoRA 适配器。
  6. **在线策略蒸馏（OPD）**：若合并损失部分专家能力，则在学生自采样轨迹的隐状态上，用组专家作为教师进行蒸馏，并加入对合并适配器的锚定项，损失为 \(L_{OPD} = \mathbb{E}\left[\|\hat u_\phi - \text{sg}(\hat u_{\psi_m})\|_2^2 + \lambda \|\hat u_\phi - \text{sg}(\hat u_{\phi_0})\|_2^2\right]\)。
- **机制解释**：将奖励加权流匹配视为速度场回归；不兼容的奖励维度可能在重叠的噪声潜在区域偏好不同的去噪速度方向，共享 MSE 回归会趋向条件均值，导致能力平均化。

- **梯度兼容性具有结构且可复现**：移除全局方向后，Wan2.1 上 136 对中有 75 对残差相似度为负；CogVideoX-2B 上三个探针队列均有 81–87 对为负。跨探针重采样 Pearson 0.847，残差相似度可预测跨维度 held-out 损失变化（Spearman \(\rho=0.256\)，\(p=0.003\)）。
- **分组优于联合训练和控制分区**：Wan2.1 上 Grouped LoRA mean 48.18（Base 47.07，Joint 46.99，随机分区 46.38/45.82，语义 47.20，原始梯度 47.35）；最差维度降幅从联合的 -8.00 降到 -4.52。
- **CogVideoX-2B 上避免负迁移**：Joint LoRA 使 Base 从 39.87 降至 27.95，而 Grouped LoRA 达 40.99；联合退化在 25% 训练时已出现，非 checkpoint 选择问题。
- **合并不均匀，蒸馏部分恢复**：合并压缩了最大专家增益（Group 4 多视角一致性损失 -21.60，Group 5 mechanics 损失 -15.14）；OPD 将 mean 从 48.18 提升至 49.91，恢复约 60% 的专家差距，改善 12/17 维度。
- **挑战维度**：摄像机运动（camera motion）未继承联合 LoRA 的 +8.00 增益；material、human interaction 等仍相对 Base 退步。

## 7. 优点

- **视角新颖**：将数据组织作为后训练的核心问题，而非单纯设计新损失函数或奖励优化目标；强调“哪些奖励加权样本应共享更新方向”。
- **残差梯度兼容性设计合理**：移除全局共享方向后再比较类别梯度，能揭示被共同方向掩盖的冲突；直接减法与投影残差得到相同分区，方法鲁棒。
- **机制解释清晰**：将奖励加权流匹配与速度场回归、条件均值回归联系起来，为“能力平均化”提供了局部几何解释。
- **实验控制严谨**：匹配协议、多个控制分区（随机、语义、原始梯度）、多训练阶段探针、独立评估器和成对 bootstrap 区间，增强了结果可信度。
- **诊断深入**：不仅报告最终分数，还分析合并保留、rank 截断、专家增量范数、OPD 恢复等，定位了性能损失的来源。
- **跨骨干验证**：在 Wan2.1（流匹配）和 CogVideoX-2B（扩散去噪）两种架构/目标上验证，提升泛化性。

## 8. 不足与局限

- **模型与任务规模有限**：仅覆盖两个 ≤2B 参数的开放视频骨干和一个 VBench2.0 派生的类别体系；未在更大模型、更多奖励源或评估套件上验证。
- **统计显著性与增益幅度**：Wan2.1 上合并适配器相对 Base 的 95% CI 为 \([-0.08, +2.26]\)，包含零；CogVideoX-2B 相对 Base 仅 +1.12，收益主要来自避免负迁移。
- **评估器耦合风险**：训练奖励来自 Qwen3-VL，VBench2.0 也使用视觉-语言判断；VideoScore 一致性降低但未消除耦合，且没有进行人类研究。
- **OPD 成本与覆盖范围**：OPD 增加约 205 GPU-hours，且只应用于主方法，未用于控制分区或 CogVideoX；OPD 的跨训练运行变异未测量。
- **梯度探针的简化**：兼容性度量是基于梯度的轻量代理，不能完整描述所有去噪动力学；未来可与更丰富的合并规则、重复控制分区和人类偏好研究结合。
- **维度级权衡仍存在**：摄像机运动、material、human interaction 等维度仍有明显退步，说明分组不能解决所有冲突；某些组（如 Group 5）在合并中因权重稀释而损失大。
- **分组数量选择依赖启发式**：\(M=5\) 基于组内相似度与负对个数选择，未进行系统模型选择，可能影响最优性。
