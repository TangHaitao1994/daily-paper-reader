## 摘要
当大型语言模型处理多轮任务，用户提出更改但最终拒绝该更改时，模型应像什么都没发生一样继续执行。我们发现了一个令人惊讶的失败：仅仅提及已被拒绝的更改就可能扰乱任务执行，即使用户的最终意图保持不变。为了系统研究语言模型在用户意图演变下的行为，我们引入了 Intent-Eval，一个涵盖工具操作、代码、数据库和数学的受控基准。在各类任务中，模型都容易受到被拒绝的提案和被取代的需求的影响，这与“提及即生效”混淆一致：对话内容即使在被拒绝或替换后仍被视为有效需求。随着交互继续，准确度下降可能加剧或持续，这突显了区分已提及内容与仍然有效的内容的必要性。基于这一见解，我们提出了 Intent-OPSD，一个决策条件下的同策略自蒸馏框架，教师和学生模型由同一模型初始化。冻结的教师模型从符合用户决策的完整任务中提供有效意图监督，在整个对话上训练学生模型以遵循反映用户意图的有效需求。

## Abstract
When a large language model handles a multi-turn task and a user proposes a change but ultimately rejects it, the model should continue as if nothing changed. We find a surprising failure: merely mentioning a rejected change can derail task execution, even when the user's final intent remains unchanged. To systematically study language model behavior under evolving user intent, we introduce Intent-Eval, a controlled benchmark spanning tool actions, code, databases, and mathematics. Across diverse tasks, models are vulnerable to both rejected proposals and superseded requirements, consistent with mentioned-as-in-effect confusion: conversational content is treated as active requirements even after it has been rejected or replaced. Accuracy degradation can deepen or persist as interaction continues, highlighting the need to distinguish what has been mentioned from what remains in effect. Building on this insight, we propose Intent-OPSD, a decision-conditioned on-policy self-distillation framework with Teacher and Student initialized from the same model. The frozen Teacher provides active-intent supervision from the complete task matching the user's decision, training the Student on the full dialogue to follow active requirements reflecting user intent.

## 1. 论文的核心问题与整体含义

- **研究背景**：多轮对话中，用户意图往往逐步展开，用户可能澄清需求、提出修改建议，并最终接受或拒绝这些修改。模型应当只遵循“仍然有效的需求”，忽略已拒绝或已被取代的内容。
- **核心问题**：现有大语言模型存在 **“提及即生效”混淆（mentioned-as-in-effect confusion）**：即使某个修改被用户拒绝，或者某条旧需求已被新需求取代，模型仍可能将其当作有效要求，导致最终答案偏离用户真实意图。
- **整体含义**：模型需要区分“对话中说过什么”与“什么仍然有效”。仅仅把任务拆成多轮就会降低性能；而加入无关澄清或提及被拒绝的修改，会进一步干扰任务执行。因此，多轮对话的鲁棒性不仅取决于任务难度，还取决于模型追踪“主动意图（active intent）”的能力。

## 2. 论文提出的方法论

- **核心思想**：利用模型较强的单轮任务能力，帮助其在多轮对话中遵循仍然有效的需求。教师模型接收与用户最终决策相匹配的**完整单轮任务**，学生模型接收**完整多轮对话**，通过自蒸馏将教师对“有效需求”的监督传递给学生。
- **Intent-OPSD 框架**：
  - 教师和学生由同一个基础模型初始化，教师冻结，学生可训练。
  - 对每个多轮条件 \(v\)，教师提示 \(c_v\) 选择：
    - \(c_v = S_{\text{Dir}}\)（直接修订任务），当 \(v = \text{Revised}\)；
    - \(c_v = S_{\text{Orig}}\)（原始任务），其他情况（Original、Neutral、Retained）。
  - 学生接收完整对话历史 \(H_v\)，并在最终回答位置进行同策略采样 \(\hat{y}_v \sim \pi_\theta(\cdot \mid H_v)\)。
  - 在最终回答的每个 token 位置 \(t\)，教师和学生都基于学生已生成的回答前缀计算下一 token 分布，并用 **Jensen–Shannon 散度**对齐：
    \[
    L_v = \frac{1}{|\hat{y}_v|} \sum_{t=1}^{|\hat{y}_v|} \mathrm{JS}\left(p^S_{v,t}, p^T_{v,t}\right)
    \]
  - 四个条件的损失平均：
    \[
    L = \frac{1}{4}\left(L_{\text{Orig}} + L_{\text{Neu}} + L_{\text{Ret}} + L_{\text{Rev}}\right)
    \]
  - 仅更新学生，中间回复不计算损失；推理时学生直接依据对话生成，不再需要教师或单轮提示。
- **训练源筛选**：教师必须在原始任务 \(S_{\text{Orig}}\) 和直接修订任务 \(S_{\text{Dir}}\) 上都能生成正确结果且通过对应验证器，该源才会被用于训练。
- **与基线 SFT 的区别**：匹配 SFT 使用教师验证过的答案作为硬目标进行监督；Intent-OPSD 则是在学生自己生成的轨迹上进行 token 级分布匹配，属于同策略蒸馏。

## 6. 论文的主要结论与发现

- **三种性能退化模式**：
  - **分散披露**：将同一任务拆成多轮，平均准确率比单轮原始任务下降 36.30 pp；
  - **对话开销**：加入不改变任务的中性澄清，额外下降 4.43 pp；
  - **决策诱导混淆**：提出修改后，无论接受还是拒绝，多轮准确率都比 Original 下降；Retained 低 8.06 pp，Revised 低 5.55 pp；即使在单轮中，通过提案+决策表达任务也会降低性能。
- **错误模式**：在 Original 正确但 Retained 错误的新错误中，59.63% 包含被拒绝的提案内容；在 Revised 错误中，30.97% 包含被取代的原始需求。数学领域尤为明显（Retained 67.70%，Revised 47.94%），说明模型在推理链中易复用已失效的数值。
- **交互深度影响**：
  - 积累实验中，第一个事件块造成的平均下降最大，随深度增加准确率继续下降；至 k=4，Neutral 下降 8.13 pp，Retained 下降 20.77 pp；
  - 持久性实验中，在已做出接受/拒绝决策后继续加入澄清，准确率仍低于决策基线，说明干扰可以持续存在。
- **方法有效性**：
  - Intent-OPSD 相对 Base 平均提升 10.81 pp，相对 matched SFT 提升 3.73 pp；
  - 在 16 个模型-领域对中，Intent-OPSD 全部超过 Base，13 个超过 SFT；
  - Actions 领域提升最大（+21.46 pp vs Base），Code 提升较小，表明当模型能解决任务但难以追踪有效需求时，该方法更有效。

## 7. 优点

- **受控基准设计**：Intent-Eval 将澄清、拒绝和修订三种事件放在同一批源任务上比较，并通过单轮对照分离任务难度和多轮影响。
- **明确的“主动意图”定义**：用 Original/Neutral/Retained 对应原任务，Revised 对应修订任务，使评估目标可验证。
- **多领域覆盖**：工具调用、代码、数据库和数学四类任务，能观察不同结构化场景中的共同模式。
- **深入的错误诊断**：通过检测非活跃内容在错误回答中的出现率，直接支持“提及即生效”混淆假设。
- **决策条件的自蒸馏方法**：教师任务与学生对话中用户最终决策对齐，针对性地提供有效需求监督；训练后学生无需教师，推理开销不增加。
- **可解释的改进范围**：分析了不同领域的增益差异，指出当“意图追踪是瓶颈”时方法收益更明显。

## 8. 不足与局限

- **单需求覆盖**：当前基准只考虑对**一个选定需求**的修改决策，无法覆盖多个相互关联需求同时变化的情况。
- **用户行为有限**：交互模式仍较受控，未涵盖更开放、混合澄清与修改的真实对话。
- **Retained 挑战未完全解决**：Intent-OPSD 在 Retained 上的平均准确率与 matched SFT 相近，说明处理“已拒绝更改”仍是一个难点。
- **监督依赖基准构造**：训练时需要从基准构建中获取完整主动任务规范；迁移到自然对话需要额外步骤从用户消息和决策中重建有效需求。
- **算力信息缺失**：论文未提供 GPU 型号、数量、训练时长等具体计算资源信息，难以评估实际成本。
- **模型覆盖有限**：虽然评估了 10 个模型，但多为 API 或开源中大型模型，对更小或更大规模模型的行为未系统分析。
- **可能的选择偏差**：训练源经过教师能否同时解决原始和修订任务的筛选，可能偏向教师已经擅长的任务，影响结果泛化性。
