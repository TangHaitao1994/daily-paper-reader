## 摘要
实时对话系统中的一般话轮转换行为要求在倾听时决定是继续倾听还是开始回应，以及在说话时决定是继续还是停止。现有的话轮检测器使用异构的、任务特定的标签空间，通常在有限的标注上训练或在孤立的语句上评估，这使得它们难以作为具有全面上下文的统一因果控制器使用。我们提出 XTurnix，一个紧凑的基于文本的模型，它将话轮控制形式化为以 AI 当前倾听或说话状态为条件的两个二元决策，并从完整对话历史中预测单个控制标记。XTurnix 在 550 万个自动从带时间戳的双说话人转录中提取的因果动作示例上进行预训练，然后在合成的多轮示例上进行微调，这些示例在四个状态-动作标签上的分布更加平坦。我们在四个公共基准和一个平衡的自建基准上评估了 XTurnix。在公共基准上，XTurnix 在所有 SemanticVAD 和 LiveKit 分割上取得了最佳结果，在 Smart-Turn Bench 上与原生 Smart-Turn 模型持平，并在 Easy-Turn 上取得了最高的未完成话轮准确率。在自建基准上，它达到了 89.06% 的准确率，比最强的第三方基线（68.75%）高出 20 多个百分点，同时在所有四个类别上的 F1 分数保持在 84.21% 到 90.63% 之间。这些结果表明，在一个紧凑的模型中实现了统一的倾听和说话状态话轮控制。代码可在 https://github.com/xcc-zach/xturnix 获取，交互演示在 https://huggingface.co/spaces/xcczach/xturnix-demo。

## Abstract
General turn-taking behavior in real-time dialogue systems requires deciding whether to keep listening or start responding while listening, and whether to continue or stop while speaking. Existing turn detectors use heterogeneous, task-specific label spaces and are often trained on limited annotations or evaluated on isolated utterances, making them difficult to use as a unified causal controller with comprehensive context. We propose XTurnix, a compact text-based model that formulates turn control as two binary decisions conditioned on the AI's current listening or speaking state and predicts a single control token from the complete dialogue history. XTurnix is pretrained on 5.5 million causal action examples automatically derived from timestamped two-speaker transcripts, then fine-tuned on synthetic multi-turn examples with a flatter distribution across the four state-action labels. We evaluate XTurnix on four public benchmarks and a balanced self-curated benchmark. Across the public benchmarks, XTurnix achieves the best results on all SemanticVAD and LiveKit splits, ties the native Smart-Turn model on Smart-Turn Bench, and achieves the highest incomplete-turn accuracy on Easy-Turn. On the self-curated benchmark, it reaches 89.06% accuracy, more than 20 percentage points above the strongest third-party baseline at 68.75%, while maintaining F1 scores between 84.21% and 90.63% across all four categories. These results demonstrate unified listening- and speaking-state turn control in a single compact model. Code is available at https://github.com/xcc-zach/xturnix, with an interactive demo at https://huggingface.co/spaces/xcczach/xturnix-demo.

## 1. 论文的核心问题与整体含义

- **研究背景**：实时对话系统（如全双工语音助手）需要持续管理“对话地板”（conversational floor）。AI 在**倾听状态**下必须判断用户是否已结束发言、何时开始回应；在**说话状态**下必须判断用户的输入是简单反馈（backchannel）还是打断，从而决定继续说话或停止并倾听。
- **现有方法的问题**：
  - 话轮检测器的输出标签空间**异构且任务特定**（如“完整/不完整”“backchannel”“endpoint”等），难以统一为通用控制接口。
  - 很多模型仅在孤立语句上训练或评估，缺乏完整对话历史。
  - 人工标注有限，难以扩展到大规模、多场景。
- **整体含义**：论文提出将话轮控制统一为**两个状态条件下的二元决策问题**，用一个紧凑的文本模型从完整对话历史中预测单一控制 token，实现“听/说”状态的统一话轮管理。

## 2. 论文提出的方法论

- **任务形式化**：
  - 定义四种状态-动作标签：
    - 倾听状态：`<|keep|>`（继续听）、`<|start|>`（开始说）。
    - 说话状态：`<|keep|>`（继续说）、`<|stop|>`（停止并听）。
  - 形式化为策略函数 \( a_t = f_\theta(H_t, s_t) \)，其中 \( H_t \) 为对话历史，\( s_t \in \{L,S\} \) 为 AI 当前状态。
  - 状态转移是确定性的：`<|start|>` 使状态变为说，`<|stop|>` 使状态变为听，`<|keep|>` 保持状态不变。

- **自监督训练数据构建**：
  - **源语料**：270 万个音频片段（173,717 小时），经过双说话人过滤后保留 689,669 个片段（44,142.5 小时），平均 23.13 个话轮。
  - **时间戳 token 时间线**：将每个说话片段的 token 按时间均匀分配，用户片段之间的静音插入 `<|pause|>`，然后将用户和助手 token 按时间排序合并。
  - **状态机标注**：从初始倾听状态扫描时间线，每个用户 token（包括 `<|pause|>`）生成一个因果训练样本，标签由时间顺序决定：
    - 倾听状态：若下一 token 仍是用户 token，则 `<|keep|>`；否则 `<|start|>`。
    - 说话状态：若下一助手 token 开始时间 ≤ 当前助手 token 结束时间 + 0.1 秒（表示助手在重叠用户输入中继续），则 `<|keep|>`；否则 `<|stop|>`。
  - **冲突过滤与标点归一化**：去除末尾标点，丢弃同一输入同时出现 `<|keep|>` 和 `<|start|>` 的冲突样本。
  - 最终得到约 **2.77 亿**个可用动作示例池，预训练实际消费 **550 万**个示例。

- **合成训练数据构建**：
  - 自监督数据高度不平衡：`<|listening|>/<|keep|>` 占 94.46%，说话状态样本极少。
  - 采用**输出优先**策略，定义目标分布 \( q_y \propto p_y^{1-\lambda} \)，\( \lambda=0.6 \)，使四类比例变为 62.78%、14.96%、7.78%、14.48%。
  - 使用 DeepSeek-V4-Pro-Preview 生成多轮对话上下文，每个上下文通过变换生成两个不同标签的对比样本。
  - 四类变换示例：
    - 倾听/`<|keep|>`：截断用户消息为不完整片段。
    - 倾听/`<|start|>`：保留完整用户消息。
    - 说话/`<|keep|>`：生成简短用户 backchannel。
    - 说话/`<|stop|>`：生成用户打断并截断为增量输入。

- **模型训练**：
  - 初始化自 Qwen3-0.6B，注册 6 个特殊 token（2 个状态、3 个动作、1 个静音）。
  - 最大序列长度 2048。
  - **预训练**：21,500 步，消费 5,504,000 个自监督样本，8 个设备，每设备 batch size 32，学习率 \(2\times 10^{-5}\)，损失按类别规模加权 \( \sqrt{n_{\max}/n_c} \)。
  - **微调**：10,026 个合成多轮样本，1 epoch，8 个设备，每设备 batch size 16，学习率 \(5\times 10^{-6}\)，共 79 步。
  - 最终模型命名为 **XTurnix-ZH-Base**；预训练检查点命名为 **XTurnix-PT**。
