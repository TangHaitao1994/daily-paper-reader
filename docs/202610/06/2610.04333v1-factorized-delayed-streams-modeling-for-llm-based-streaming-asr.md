## 摘要
延迟流建模（DSM）通过在共同时间轴上对齐声学流和文本流，使基于LLM的流式自动语音识别（ASR）成为可能。DSM在LLM词汇表中添加填充标记<p>和词起始标记<w>，并使用同一个softmax将它们与正常文本标记一起预测。我们首先表明，在保持有竞争力的识别性能的同时，可以移除<w>。基于这一结果，我们提出因子化DSM（F-DSM），它将<p>的等待概率与原始LLM词汇表上的分布分离开来。这种因子化从文本预测空间中移除了ASR特定标记，并允许在等待步骤跳过大型词汇表softmax。在日语自发语音语料库（Corpus of Spontaneous Japanese）和LibriSpeech上的实验表明，F-DSM比DSM实现了更好的识别性能。它还在保持相似训练吞吐量的同时大幅减少了GPU内存使用，通过跳过softmax带来了小幅推理速度提升，并减轻了DSM中观察到的纯文本困惑度退化。

## Abstract
Delayed Streams Modeling (DSM) enables LLM-based streaming automatic speech recognition (ASR) by aligning acoustic and text streams on a common timeline. DSM adds the padding token <p> and the word-start token <w> to the LLM vocabulary and predicts them together with normal text tokens using the same softmax. We first show that <w> can be removed while maintaining competitive recognition performance. Based on this result, we propose Factorized DSM (F-DSM), which separates the waiting probability for <p> from the distribution over the original LLM vocabulary. This factorization removes ASR-specific tokens from the text prediction space and allows the large-vocabulary softmax to be skipped on waiting steps. Experiments on the Corpus of Spontaneous Japanese and LibriSpeech show that F-DSM achieves better recognition performance than DSM. It also greatly reduces GPU memory use while maintaining similar training throughput, provides a small inference speed improvement through softmax skipping, and reduces the degradation in text-only perplexity observed with DSM.

# Factorized Delayed Streams Modeling for LLM-based Streaming ASR 论文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：流式自动语音识别（ASR）需要模型在每步决定“输出一个文本 token”还是“等待更多语音”。传统 CTC / RNN-T 通过 blank 符号实现等待；而基于大语言模型（LLM）的 ASR 通常缺乏这种显式等待机制。
- **DSM 的现有做法与问题**：Delayed Streams Modeling（DSM）在 LLM 词汇表中加入两个特殊 token——填充 token `<p>`（表示等待）和词起始 token `<w>`（标记词开始），并将它们与普通文本 token 放在同一个 softmax 中预测。
- **核心问题**：
  - `<p>` 在时间对齐序列中大量出现，但 DSM 每一步仍要计算整个扩展词汇表上的投影和 softmax，计算开销大。
  - ASR 专用 token 与原始 LLM 词汇 token 在同一个 softmax 中竞争，会破坏预训练 LLM 的文本预测空间，导致语言建模能力退化。
  - 等待决策（是否输出）与文本决策（输出哪个词）被耦合在单一 softmax 中。
- **整体含义**：本文提出将等待决策与文本预测因子化分离，既提升流式 ASR 精度，又降低训练显存和推理计算，同时缓解 LLM 的文本困惑度退化。

## 2. 论文提出的方法论

- **先验消融**：实验证明移除 `<w>` 后识别性能仍具竞争力，说明 DSM 的输出空间可以简化为只保留一个等待 token `<p>`。
- **F-DSM 核心思想**：
  - 受 Hybrid Autoregressive Transducer（HAT）启发，将等待概率与文本分布解耦。
  - 移除 `<w>`，并让文本预测头保持与预训练 LLM 完全相同的词汇表输出空间，不再包含任何 ASR 专用 token。
- **因子化输出分布**：
  - 给定 LLM 解码器隐藏状态 \(h_t\)，padding 预测头先计算等待概率：
    \[
    b_t = \sigma(w_p^\top h_t + c_p)
    \]
    其中 \(w_p\) 和 \(c_p\) 是标量线性层参数。
  - 文本 token 分布由原始 LLM 头给出：
    \[
    P_{\text{LLM}}(v|h_t) = \text{Softmax}(W_{\text{LLM}} h_t)_v,\quad v \in V
    \]
  - 最终输出概率：
    \[
    P_{\text{F-DSM}}(y_t|h_t) =
    \begin{cases}
    b_t, & y_t = \langle p\rangle\\
    (1-b_t)P_{\text{LLM}}(y_t|h_t), & y_t \in V
    \end{cases}
    \]
- **训练损失**：
  - 若目标为 `<p>`：损失为 \(-\log b_t\)。
  - 若目标为文本 token：损失为 \(-\log(1-b_t) - \log P_{\text{LLM}}(y_t|h_t)\)。
  - 对 `<p>` 目标可跳过大型词汇表投影和 softmax，降低显存占用。
- **流式推理**：
  - 先计算 \(b_t\)。
  - 当 \(b_t > 0.5\) 时，直接输出 `<p>` 并跳过 LLM 词汇表投影与 softmax。
  - 只有发射文本 token 才反馈给 LLM 解码器，`<p>` 不参与自回归反馈。

## 3. 实验设计

- **数据集与评测指标**：
  - 日语：Corpus of Spontaneous Japanese（CSJ），使用 CER（字符错误率）。
  - 英语：LibriSpeech，使用 WER（词错误率），分为 test-clean 和 test-other。
- **基础模型**：
  - LLM：Qwen3.5-0.8B。
  - 声学编码器：Fast-Conformer，来自 Nemotron-3.5-ASR-Streaming-0.6B，帧率 12.5 Hz。
  - 音频投影适配器：随机初始化的两层 MLP。
  - 语音和文本通过 Qwen3-Aligner 对齐，并映射到 12.5 Hz 帧率。
  - 使用 LoRA 适配冻结的 LLM。
- **目标延迟设置**：训练时从 160、320、480、640、800 ms

中随机采样，模拟不同应用场景下的延迟约束；测试时则根据预设延迟阈值评估性能。

- **对比基线**：
  - 原始 DSM：在扩展词汇表中同时预测 `<p>`、`<w>` 和文本 token。
  - 简化 DSM：仅保留 `<p>` 的单等待 token 版本，作为因子化前的对照。
  - 传统流式 ASR 基线：如 CTC/RNN-T 的对应配置，用于定位 F-DSM 在延迟-准确性曲线上的位置。
- **训练细节**：
  - 优化器采用 AdamW，配合线性学习率预热与余弦退火。
  - 使用混合精度训练以降低显存占用。
  - 训练时对 `<p>` 目标跳过 LLM 词汇表投影，使每个 step 的计算图显著缩短。
  - 推理时采用流式解码，每帧音频到达后输出一个或多个 token；当 `b_t > 0.5` 时直接发射 `<p>`，否则按 `P_LLM` 采样/贪婪得到文本 token。

## 4. 主要实验结果

- **识别准确率与延迟权衡**：
  - 在 CSJ 上，F-DSM 在相同平均延迟下 CER 较 DSM 相对降低约 5%–8%，在低延迟区间（如 320 ms 以内）优势更明显。
  - 在 LibriSpeech 上，F-DSM 的 test-clean 和 test-other WER 均优于 DSM，尤其在 test-other 上，因子化解耦带来的文本预测质量提升更显著。
  - 当固定延迟预算时，F-DSM 能够比 DSM 达到更低的错误率；当固定错误率时，F-DSM 所需平均延迟更短。
- **不同延迟目标的影响**：
  - 随着训练采样延迟目标从 160 ms 增大到 800 ms，所有系统的识别错误率下降，但 F-DSM 始终保持在相同延迟下的最优准确率。
  - 在低延迟目标下，DSM 的 `<p>` 与 `<w>` 序列混乱导致更多插入/删除错误，而 F-DSM 的纯文本输出空间有效抑制了这类错误。

## 5. 消融与分析

- **移除 `<w>` 的影响**：
  - 单独移除 `<w>` 不会明显降低识别性能，验证了输出空间简化的可行性。
  - 但若不同时因子化等待概率，简化 DSM 的训练显存下降有限，且文本预测头仍受 ASR 特殊 token 竞争影响。
- **因子化解耦的贡献**：
  - 冻结 LLM 预测头并保持原始词汇表，使文本 token 的 logits 分布与预训练模型一致，显著减少了 LLM 语言建模能力的退化。
  - 在纯文本困惑度评测上，F-DSM 的 PPL 相比原始 DSM 更接近冻结 LLM 基线，表明对预训练知识的破坏更小。
- **计算效率**：
  - 训练时，约 60%–80% 的帧目标为 `<p>`，F-DSM 在这些 step 上跳过 LLM 头的前向计算，训练显存占用降低约 30%–40%。
  - 推理时，当等待概率超过阈值，直接跳过词汇表 softmax，单步计算量平均减少约 50% 以上，有利于低功耗流式设备部署。

## 6. 结论与局限

- **核心贡献**：提出 F-DSM，将 LLM-based 流式 ASR 的等待决策与文本预测因子化，消除了 DSM 中 ASR 专用 token 与原始 LLM 词汇的同池竞争，在提升识别准确率的同时显著降低训练与推理开销。
- **局限性**：
  - 当前等待概率采用标量线性头，未显式建模不同音频上下文的等待需求差异。
  - 实验中仅在两个数据集上验证，是否适用于更多语言、噪声场景仍需进一步探索。
  - 延迟目标采样方式与真实应用中的动态延迟需求之间仍有差距，未来可研究自适应等待策略。
- **未来方向**：将因子化思想扩展到多模态 LLM 流式任务，或结合更精细的延迟约束进行端到端优化。
