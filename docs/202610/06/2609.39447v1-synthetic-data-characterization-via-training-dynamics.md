## 摘要
理解LLM生成数据的性质对于认识其在各类学习任务中的效用与局限性十分重要。本文通过样本层面的可学习性来刻画合成数据，研究不同LLM家族与规模之间的差异，并以人类撰写数据作为参照。我们首先生成涵盖单标签与多标签分类、标注以及树预测任务的合成数据集。随后，我们从编码器训练动态中推导机器数据与自然数据的经验数据分布，并估计这些分布在不同编码器间的稳健性。最后，我们评估基于这些可学习性信号的数据选择策略如何对两种数据来源产生不同影响。

## Abstract
Interpreting properties of LLM-generated data is important for understanding its utility and limitations across learning tasks. In this work, we characterize synthetic data through sample-level learnability, studying variation among LLM families and scales, alongside human-written data as a reference. We first generate synthetic datasets spanning single- and multi-label classification, labeling, and tree prediction tasks. We then derive empirical data distributions from encoder training dynamics for both machine and organic data, and estimate the robustness of these distributions across encoders. Finally, we evaluate how data selection strategies based on these learnability signals affect both data sources differently.

## 1. 论文的核心问题与研究动机

- **研究背景**：合成数据（由大语言模型 生成）在预训练、指令微调和任务微调中日益重要，但对其属性、多样性、真实性以及与人类数据分布之间的差异仍缺乏系统理解。
- **核心问题**：如何从**样本级可学习性（sample-level learnability）**的角度表征合成数据？不同 LLM 家族、模型规模、提示策略下生成的合成数据，在训练动态上呈现出怎样的差异？这些差异是否会影响后续的数据选择与模型训练？
- **研究动机**：现有研究通常将合成数据视为静态分布，关注表面相似度或特征空间距离，却忽略了**单个样本在训练过程中的动态行为**。而训练动态已被证明可以捕捉样本的易学性、噪声和边界特征。因此，本文尝试将训练动态方法系统扩展到合成数据表征领域。

## 2. 方法论

- **核心思想**：基于训练动态中的三个关键指标——**置信度、变异性、正确率**——在连续空间中刻画每个样本的可学习性特征，形成所谓的数据地图。

- **基础公式**：
  - 置信度（Equation 1）：  
    γ(x, y) = E_t[p_{θ_t}(y | x)]  
    表示模型在整个训练过程中对真实标签的平均预测概率。
  - 变异性（Equation 2）：  
    σ(x, y) = std_t[p_{θ_t}(y | x)]  
    表示模型对同一样本预测概率随训练步数的波动程度。
  - 正确率（Equation 3）：  
    α(x, y) = E_t[I{y = arg max_{y'∈Y} p_{θ_t}(y' | x)}]  
    表示模型平均预测正确的频率。

- **任务扩展**：原始公式主要适用于序列级分类，本文将其推广到四类任务：
  - **多标签分类**：将置信度定义为每个标签置信度的平均（Equation 4），正确率使用 Jaccard 得分并配合阈值 τ（Equation 5）。
  - **序列标注**：置信度可基于整句平均或逐 token 计算（Equation 6、7）。
  - **图预测（含依赖解析）**：在边级别因子化，置信度为所有边预测概率的平均（Equation 8），正确率基于边集合的重叠程度（Equation 9）。
  - 这些扩展使训练动态表征能覆盖除分类以外的任务结构。

- **分布比较方法**：
  - 使用 **Wasserstein 距离**作为无参数分布差异的非参数度量。
  - 使用 **Cliff's delta**作为效应量，衡量一个分布的样本值系统性高于另一分布的程度，取值在 [−1, 1] 之间。
  - 使用非参数方法是因为训练动态分布可能高度非高斯、多模态（如易学样本、困难样本、歧义样本簇）。

- **合成数据生成策略**（四类提示策略，粒度递增）：
  1. **朴素提示**：仅提供任务基本说明与目标序列长度。
  2. **示例提示**：在朴素提示基础上加入从人类数据中选取的两个示例。
  3. **难度感知提示**：从人类数据地图中的易学、困难、歧义三个区域分别选取示例，但不显式告知生成目标难度。
  4. **歧义目标提示**：在难度感知提示基础上显式要求模型生成“歧义型”样本。

## 6. 主要结论与发现

- **人类数据与合成数据的训练动态差异**：
  - 合成数据在情感分类与词性标注上能近似复现人类数据的“倒 C 形”置信度-变异性结构。
  - 多标签分类中变异性普遍较低，缺乏困难样本。
  - 依赖解析任务中合成数据未能生成高置信、低变异性的易学样本，且分布与人类数据差异较大。

- **不同 LLM 之间的差异**：
  - SST-5 上 LLaMA 与 Qwen 分布较为一致。
  - 多标签分类中 LLaMA 的分布与其他模型差异明显。
  - 依赖解析任务中不同 LLM 分布波动较大，反映出生成质量不稳定。

- **提示策略的影响有限**：
  - 提示策略的粒度变化对训练动态没有一致性影响，训练动态对提示复杂度不敏感，更多受模型生成过程本身影响。

- **编码器稳健性**：
  - 相对样本定位在不同编码器间基本稳定。
  - LLM2Vec 在训练集上拟合更好（正确率与置信度的差异为负）。
  - 合成样本在架构间呈现极化趋势，可能包含架构特异偏置，而人类数据的分布更均匀。

- **基于难度/可学习性的数据选择影响**：
  - 合成数据中高正确率（可学习）子集在域内和域外评估中表现更好。
  - 易学样本（高置信度）在合成数据上可能导致性能下降，而在人类数据上仍具有训练价值。
  - 数据选择策略对合成数据和人类数据的影响存在明显差异。
