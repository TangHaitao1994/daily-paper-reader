## 摘要
多尺度设计对于高效的音视频语音分离至关重要，但在音视频特征融合中有效建模多尺度信息仍具挑战性。我们认为现有方法能力有限主要源于：1）以相同方式处理来自不同模态的特征；2）忽视全局特征的作用。为解决这些问题，我们提出了一种全局引导的非对称注意力网络（GAANet）。该模型包含两项核心创新：第一，一种非对称多尺度融合框架，允许音频流和视觉流在各自最优的时间分辨率上提取并交互特征，无需对称的时间下采样；第二，一种全局引导的注意力机制，将每个模态压缩为时间维度为1的紧凑全局令牌，进而提供高级语义线索，以引导跨尺度的模态内和模态间融合。在LRS2和VoxCeleb2上的实验表明，GAANet达到了最先进的性能，在LRS2上达到16.5 dB SI-SNRi，在VoxCeleb2上达到14.0 dB，同时保持轻量计算特性，仅3.3M参数和19.8G MACs。这些结果凸显了非对称时间建模与全局引导在高效鲁棒多模态融合中的巨大潜力。源代码公开于 https://github.com/redizzy/GAANet

## Abstract
Multi-scale design is crucial for efficient audio-visual speech separation, yet effectively modeling multi-scale information for audio-visual feature fusion remains challenging. We argue that the limited capacity of existing approaches primarily arises from: 1) treating features from different modalities in the same manner, and 2) overlooking the role of global features. To address these issues, we propose a Global-guided Asymmetric Attention Network (GAANet). Our model introduces two core innovations: first, an asymmetric multi-scale fusion framework that allows audio and visual streams to extract and interact with features at their respective optimal temporal resolutions, removing the need for symmetric temporal downsampling; second, a global-guided attention mechanism that compresses each modality into a compact global token with a temporal dimension of one, which then provides high-level semantic cues to guide both intra- and inter-modal fusion across scales. Experiments on LRS2 and VoxCeleb2 demonstrate that GAANet achieves state-of-the-art performance, reaching 16.5 dB SI-SNRi on LRS2 and 14.0 dB on VoxCeleb2, while maintaining a lightweight computational profile with only 3.3M parameters and 19.8G MACs. These results highlight the strong potential of asymmetric temporal modeling and global guidance for efficient and robust multimodal fusion. The source code is publicly accessible at https://github.com/redizzy/GAANet

- **研究背景**：音频视觉语音分离（Audio-Visual Speech Separation, AVSS）旨在联合声学信号和唇部视觉线索，从混合语音中恢复目标说话人语音，在多说话人、低信噪比场景中具有重要价值。
- **现有问题**：
  - 现有多尺度 AVSS 方法通常采用对称融合框架，即将音频和视觉特征下采样到相同时间分辨率后再进行跨模态交互。
  - 音频时间分辨率高、变化快，视觉唇动相对缓慢且语义稳定，二者具有固有的时间不对称性，对称设计未能显式利用这一差异。
  - 现有方法主要关注局部时间对齐，忽视了语句级全局语义信息（如说话人身份、发音模式、目标主导性等）对融合的指导作用。
- **整体含义**：论文提出 GAANet，通过“非对称多尺度融合”和“全局引导注意力”两个核心设计，提升音视频融合的效率和鲁棒性，实现轻量且高性能的语音分离。

## 2. 论文提出的方法论

### 2.1 整体流程

- 音频编码器：通过 1D 卷积将混合波形转换为帧级表示 \(E_a \in \mathbb{R}^{N_a \times T'_a}\)。
- 视频编码器：提取唇部 ROI 帧的时空表示 \(E_v \in \mathbb{R}^{N_v \times T_v}\)。
- **A-V Fusion Block**：整合非对称多尺度融合与全局引导注意力，重复 \(N_1=4\) 次且共享参数。
- **听觉细化模块**：重复 \(N_2=12\) 次，对融合后音频特征进行精炼；经 ReLU 生成掩膜，并通过转置卷积解码重建目标波形。

### 2.2 非对称多尺度融合框架（Asymmetric Multi-Scale Fusion, AMF）

- **音频路径**：
  - 深度 \(D=4\)，逐级使用 1D 卷积（核大小 5、步长 2）、层归一化和 PReLU 进行时间下采样，得到多尺度音频特征 \(\{E_a^i\}\)。
  - 将各中间尺度池化对齐到最深尺度，并与最深尺度特征求和，得到累积多尺度音频表示 \(S_A\)。
- **视觉路径**：
  - 保持原始时间分辨率，不进行下采样。
  - 通过 \(D\) 个时间细化块（1D 卷积核大小 5、步长 1、层归一化、PReLU）扩大感受野，得到多级视觉特征 \(\{E_v^i\}\)。
  - 将所有层级求和得到累积多尺度视觉表示 \(S_V\)。

### 2.3 全局引导注意力机制（Global-Guided Attention, GGA）

- **全局描述符生成**：对 \(S_A\) 和 \(S_V\) 分别进行时间平均池化，得到时间维度为 1 的紧凑全局描述符 \(S_A\)、\(S_V\)。
- **跨模态全局调制**：
  - 视觉描述符通过 1D 卷积 \(Q_a\) 和 sigmoid 生成门控，对音频描述符进行调制：
    \[
    G_{A,0} = S_A + S_A \odot \sigma(Q_a(S_V))
    \]
  - 对称地，音频描述符调制视觉描述符：
    \[
    G_{V,0} = S_V + S_V \odot \sigma(Q_v(S_A))
    \]
- **生成全局 token**：通过前馈网络（FFN，包含三层卷积和全局层归一化 GLN）得到最终全局音频 token \(G_A\) 和全局视觉 token \(G_V\)。
