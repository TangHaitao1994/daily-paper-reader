## 摘要
现代文本转语音（TTS）由自回归（AR）编解码语言模型主导，其从左到右的解码带来了随语音长度增长的延迟、沿已生成前缀的误差累积，以及强加在残差向量量化（RVQ）token网格上的人为生成顺序。我们提出 Luna-TTS Family，基于扩散语言模型的 TTS 系统，在 100 万小时的中文、英文、日文和韩文语音上预训练。该系列通过逐步调整预训练的自回归文本 LLM 构建，从因果注意力到双向注意力，最后到块因果注意力，并包含两个变体，共享同一个 tokenizer、数据管道和 0.6B 主干谱系。Luna-TTS 是完全非自回归的：它在固定数量的并行细化步骤中生成整个 RVQ token 网格，零样本声音克隆和语音编辑自然以填充方式出现。Luna-TTS Realtime 通过持续训练得到，在 32 个编解码帧（1.28 秒）的块上自回归生成，同时并行对每个块去噪；它支持 KV 缓存的块式生成和增量音频传输，在预热服务协议下实现了 0.0240 的端到端 RTF 和 41.6 毫秒的局部首块延迟。退火微调阶段增加了对情感和非语言发声（NVVs）的显式控制，强化学习阶段应用 GRPO，并在实际去噪轨迹上计算策略比率。在 Seed-TTS-Eval 上，Luna-TTS 在所比较的开源和商业系统中，在全部四个指标上取得最佳结果（test-zh 上 0.73 CER / 79.7 SIM，test-en 上 1.49 WER / 76.8 SIM）；在更具挑战性的真实场景 CV3-Eval 上，它在我们比较中取得了最低的中文和英文错误率。与领先的商业系统相比，它在 NVV 和情感控制的大多数客观、基于模型和人工评分指标上取得了最佳结果。

## Abstract
Modern text-to-speech (TTS) is dominated by autoregressive (AR) codec language models, whose left-to-right decoding brings latency that grows with utterance length, error accumulation along the committed prefix, and an artificial generation order imposed on the Residual Vector Quantization (RVQ) token grid. We propose Luna-TTS Family, diffusion-language-model-based TTS systems pretrained on 1 million hours of speech across Chinese, English, Japanese, and Korean. The family is built by progressive adaptation of a pretrained AR text LLM, from causal to bidirectional and finally to block-causal attention, and comprises two variants sharing a single tokenizer, data pipeline, and 0.6B backbone lineage. Luna-TTS is fully non-autoregressive: it generates the entire RVQ token grid in a fixed number of parallel refinement steps, with zero-shot voice cloning and speech editing arising natively as infilling. Luna-TTS Realtime, derived by continual training, is autoregressive over blocks of 32 codec frames (1.28s) while denoising each block in parallel; it supports KV-cached blockwise generation and incremental audio delivery, achieving an end-to-end RTF of 0.0240 and 41.6 ms local first-block latency under the warmed serving protocol. An annealed fine-tuning stage adds explicit control over emotion and non-verbal vocalizations (NVVs), and a reinforcement-learning stage applies GRPO with policy ratios computed over the realized denoising trajectory. On Seed-TTS-Eval, Luna-TTS achieves the best results on all four metrics among compared open-source and commercial systems (0.73 CER / 79.7 SIM on test-zh, 1.49 WER / 76.8 SIM on test-en); on the harder in-the-wild CV3-Eval, it posts the lowest Mandarin and English error rates in our comparison. Against leading commercial systems, it achieves the best results on most objective, model-based, and human-rated metrics for NVV and emotion control.

## 2. 方法论

- **整体设计原则**
  - 单一生成阶段直接建模完整多码本 token 网格，不使用“语义 token + 独立 flow-matching/扩散 vocoder”的两阶段方案；
  - 任意顺序生成匹配 RVQ 网格几何结构，避免人为规定时间–深度顺序；
  - 一个掩码扩散目标通过调整块大小实现从全并行到流式的不同工作点。

- **Luna-Codec 语音 tokenizer**
  - 24 kHz 语音编码为 25 Hz、`Q=8` 个残差码本、每码本 2048 个条目，等效码率约 2.2 kbps。
  - 编码器和解码器均为因果结构，支持帧级流式重建。
  - 第一码本通过蒸馏 WavLM 帧级表示进行语义锚定，使深度轴大致从语言信息到声学细节排列，提高文本可预测性。
  - 训练数据：400K 小时中英日韩语音；损失包括时域/多尺度 mel 重构、VQ commitment、对抗训练以及第一码本蒸馏损失。

- **统一掩码扩散建模**
  - 目标 token 网格记为 \(X_0 \in V^{T\times Q}\)，条件 \(c=(y,P)\) 包括输入文本和可选声学提示。
  - 前向过程：每个位置独立以概率 \(t\) 替换为 `MASK`，条件 token 从不被掩码。
  - 训练损失为加权去噪交叉熵：
    \[
    L_{MD}(\theta) = -\mathbb{E}_{t\sim U(0,1]}\mathbb{E}_{X_t\sim q_t}\left[\frac{1}{t}\sum_{(i,q): X^{i,q}_t=M}\log p_\theta(X^{i,q}_0|X_t,c)\right]
    \]
  - **帧级多码本建模**：每帧的 8 个码本 embedding 相加成一个帧级表示，Transformer 序列长度保持为 \(T\)；输出端每个帧有 8 个并行分类头，分别预测各码本 token。
  - 文本 embedding、位置编码和文本头直接继承自 Qwen3-0.6B；声学 embedding 表和预测头为新增参数。

- **从 AR 文本 LLM 到语音扩散 LM 的渐进适配**
  1. **起点**：预训练 AR 文本模型 Qwen3-0.6B；
  2. **直接转换到 Luna-TTS**：将因果注意力替换为全双向注意力，继续在语音–文本数据上用掩码扩散目标训练；
  3. **持续训练得到 Luna-TTS Realtime**：将全双向注意力改为块因果注意力，采用块扩散目标。

- **Luna-TTS：全并行生成**
  - 训练时对整个 \(T\times Q\) 网格做不受限制的随机掩码；
  - 推理从全 `MASK` 网格开始，固定做 \(S=32\) 步迭代细化；
  - 采用 confidence-based unmasking（MaskGIT 式），按余弦调度逐步 commit，使用带 Gumbel 噪声的置信度选择；
  - 加入 classifier-free guidance，训练时以 0.1 概率丢弃文本条件；
  - **时长预测**：独立训练一个 Qwen3-0.6B token 级时长预测器，逐 token 预测时长后求和得到目标帧数 \(T\)；
  - **语音克隆与编辑**：将声学 prompt 视为未掩码区域，目标区域以 in-filling 方式补全；编辑即掩码任意 span 后在前后文下重建，无需额外机制。

- **Luna-TTS Realtime：块因果流式生成**
  - 将目标网格按时间分成 \(N=\lceil T/B\rceil\) 个块，块大小 \(B=32\) 帧（1.28 s）；
  - 建模为：
    \[
    p_\theta(X|c)=\prod_{b=1}^{N}p_\theta(X^{(b)}|X^{(<b)},c)
    \]
  - 块之间保持因果依赖，块内所有帧、码本并行去噪；
  - 推理时维护 KV cache，已 commit 的块不可修改；每个块 commit 后立即交给因果 codec 解码并流式输出；
  - 通过学习的 EOS 决策终止，最大长度作为服务保护。

- **RL 后训练：轨迹感知策略优化**
  - 将掩码扩散采样过程视为去噪轨迹 \(\tau=\{(s_k,M_k,a_k)\}_{k=0}^{S-1}\)；
  - 策略比率在“实际发生”的 token 决策上计算，而不是传统左到右因子分解；
  - 使用 GRPO：同一 prompt 采样 \(G\ge2\) 个候选，计算组内相对优势；
  - 奖励函数以内容正确性优先、说话人相似度次之，采用组内排序的 ordinal reward：
    \[
    R_{g,i}=\Psi_g(-\text{WER}_{g,i},\text{SIM}_{g,i})
    \]
  - 对 token 级 surrogate 做 PPO 式裁剪，且对每句话按 token 数归一化，避免长句权重过大。

- **表达控制**
  - 通过文本侧控制 token 实现：句子级 emotion token 控制整体情绪，inline NVV token 指定局部非语言发声（笑声、叹气、咳嗽等）；
  - 不需要独立风格编码器或控制头。
