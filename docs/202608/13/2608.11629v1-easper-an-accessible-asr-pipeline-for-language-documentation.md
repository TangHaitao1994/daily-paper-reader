## 摘要
音频转写是语言记录中的一个关键瓶颈。虽然 Whisper 等多语言自动语音识别（ASR）模型提供了解决方案，但田野语言学家往往缺乏使用这些模型所需的专业知识。我们提出了 Easper，一个开源、无需编程的工作流，使语言学家能够直接从 ELAN 标注中通过云资源迭代微调 ASR 模型。部署 ASR 还带来了一个冷启动问题：首先转写哪些录音以引导出一个准确的模型。利用 Easper，我们在三种瓦努阿图语言（比斯拉马语、纳夫桑语、恩古纳语）上评估了转写优先级策略。我们按录音会话微调模型，比较优先考虑声学清洁度与语言丰富度时的字符错误率轨迹。我们证明，优先处理词汇丰富的叙事并增加声学-语音重复，即使在嘈杂环境中，也能更快提升转写质量。

## Abstract
Audio transcription is a critical bottleneck in language documentation. While multilingual Automatic Speech Recognition (ASR) models like Whisper offer solutions, field linguists often lack the expertise to utilise them. We present Easper, an open-source, no-code workflow enabling linguists to iteratively fine-tune ASR models via cloud resources directly from ELAN annotations. Deploying ASR also raises a cold start problem: deciding which recordings to transcribe first to bootstrap an accurate model. Using Easper, we evaluate transcription prioritisation strategies on three Vanuatu languages (Bislama, Nafsan, Nguna). We fine-tune models by recording session, comparing Character Error Rate trajectories when prioritising acoustic cleanliness versus linguistic richness. We demonstrate that prioritising lexically rich narratives and increasing acoustic-phonetic repetition, even in noisy environments, leads to faster improvements in transcription quality.

## 2. 论文提出的方法论

### 2.1 Easper 工作流

- **总体设计**
  - Easper 是 ELAN-integrated Automatic Speech Recogniser 的缩写，定位为适合田野语言学家的便携式、开源 Python 桌面应用。
  - 工作流分三个阶段：数据准备、微调、设备端推理。

- **数据准备**
  - 使用 `pympi-ling` 处理 ELAN（`.eaf`）文件和音频。
  - 自动检查标注问题：
    - 超过 30 秒的片段会被标记，因为 ASR 模型通常需要短片段；
    - 检测跨层重叠标注；
    - 生成语料级字符/词频统计和字符二元组统计，帮助发现拼写不一致、打字错误和意外语码转换。
  - 最终输出 16 kHz 单声道 WAV 文件，以及将音频片段与转写文本对应的 CSV 文件。

- **模型微调**
  - 利用 Google Colab 等免费云资源，避免依赖本地 GPU。
  - 推荐微调 OpenAI Whisper-small（244M 参数）和 Meta XLS-R（300M 参数），理由是：
    - 可在免费云资源上微调；
    - 在极低资源语言上表现较强；
    - 模型体积小于 1 GB，便于离线部署。
  - 微调后的模型可下载到本地 Easper 桌面应用中使用。

- **设备端推理**
  - 推理流程四步：说话人日志/分离、分段、语音识别、导出 ELAN。
  - 分段使用 SpeechBrain 或 pyannote-audio 进行稳健的说话人边界检测；若语言学家预先知道说话人数，可进一步提高分离准确率。
  - GUI 允许用户选择模型、输入音频、调节分段敏感度；输出写入新 ELAN 文件，每个说话人一个层级，每段文本与音频区间对齐。
  - 支持“ASR 先出草稿、语言学家后编辑”的半自动转写模式。

### 2.2 录音选择策略

- **会话级特征提取**
  - 将每个录音会话视为不可分割的数据单元，符合田野语言学家按访谈、民间故事或诱导任务进行转写的实际工作方式。
  - 声学特征：
    - **SNR**：基于 OM-LSA 框架估计的信噪比。
    - **OVR**：重叠语音比例，使用 pyannote 检测。
  - 语言特征：
    - **TyTo(s)**：Type-Token Ratio，即 `#Types / #Tokens`，衡量词汇多样性；
    - **ToTy(s)**：论文提出的 Normalised Token-to-Type Ratio，定义如下：

\[
\text{ToTy}(s) = \frac{\#\text{Tokens}}{\#\text{Types} \times \text{Duration}}
\]

  - 其含义是每个唯一词的平均重复次数按会话长度归一化，避免长会话天然得分更高，也避免 TyTo 对只出现一次的词过度奖励。

- **五种数据选择策略**
  - **Baseline**：随机顺序添加会话。
  - **SNR Priority**：按 SNR 从高到低，优先最干净背景。
  - **Minimal Overlap Priority**：按说话人重叠率从低到高，优先最少重叠。
  - **TyTo Priority**：按 Type-Token Ratio 从高到低，优先最高词汇多样性。
  - **ToTy Priority**：按 Normalised Token-to-Type Ratio 从高到低，优先最高平均词汇重复。

- **增量训练方式**
  - 逐步按会话添加训练数据；每个训练步加入当前策略下排名最高的会话。
  - 若单个会话时长低于预设阈值，则继续加入后续高排名会话，直到该步达到最小时长，以缓解录音长度差异。

## 3. 实验设计

- **数据集**
  - 使用来自 PARADISEC 目录的三种瓦努阿图语言 ELAN 标注田野录音：
    - **Bislama（bis）**：约 30 万人使用，以英语词汇为基础的克里奥尔语；13 小时 45 分钟，49 个会话，11,575 段，123,093 个 token，4,801 个 type。
    - **Nafsan（erk）**：约 5,000 人使用；14 小时 50 分钟，32 个会话，9,245 段，107,775 个 token，8,526 个 type。
    - **Nguna（llp）**：约 9,500 人使用；仅 1 小时 01 分钟，71 段，7,976 个 token，852 个 type。
  - 该选择覆盖不同录音年代和质量：Bislama 为较近期、高质量音频；Nafsan 和 Nguna 为档案田野录音，标注质量也参差不齐。

- **模型与训练设置**
  - 每种语言分别初始化一个预训练 Whisper-Small（244M）。
  - 全模型微调，每个训练步 3 个 epoch，batch size 8，学习率 1e-5。
  - 测试集：Bislama 和 Nafsan 固定 30 分钟；Nguna 由于总量仅 61 分钟，测试集设为 10 分钟，以保留足够训练数据。

- **评估指标**
  - 主要使用 **Character Error Rate（CER）**。
  - 理由：CER 更接近语言学家后编辑所需的按键修改量；WER 对非标准拼写过于苛刻；PER 涉及语言特定音素符号，评估更复杂。

- **对比方法**
  - 比较五种数据选择策略下的 CER 学习曲线：随机基线、SNR 优先、最少重叠优先、TyTo 优先、ToTy 优先。
  - 通过在三个语言上分别运行这些策略，观察随训练数据量增加 CER 的变化轨迹。

## 6. 论文的主要结论与发现

- **语言丰富度优先于声学清洁度**
  - 在早期 ASR 微调中，优先选择词汇丰富、重复度高的叙事会话，比优先选择安静、无重叠的录音更能快速降低 CER。
  - SNR 优先和最少重叠优先策略表现一般，说明 Whisper 这类大规模预训练基础模型对田野录音中的非平稳噪声和重叠已有较强鲁棒性。

- **词汇深度比词汇广度更重要**
  - ToTy 优先策略通常优于 TyTo 优先策略。
  - 原因：神经网络需要足够的声学-音素重复来可靠学习新的字形到音素映射；一个词汇量巨大但每个词只出现一次的会话，不如一个反复强化核心词汇的会话实用。

- **实践建议**
  - 田野语言学家应主动诱导词汇密度高、重复性强的叙事，并优先转写这些内容。
  - 即使录音背景噪声较大，只要语言内容适合，也值得优先用于早期微调。

## 7. 优点

- **工程贡献明确**
  - Easper 从 ELAN 标注到云端微调再到离线 ELAN 回写，形成完整闭环，且无代码、便携，显著降低语言学家使用 ASR 的技术门槛。
  - 支持迭代式人在环路工作流，模型可随新标注数据持续改进。

- **研究问题具有现实意义**
  - 冷启动数据选择是许多低资源语言文档项目面临的真实问题，论文将其置于会话级、贴近田野实际的设定下研究。

- **方法直观且可操作**
  - 提出 ToTy 指标，兼顾词汇重复和会话时长归一化，避免传统 TyTo 的一些缺陷。
  - 五种策略简单、易于复现，语言学家可直接按特征排序指导转写优先级。

- **多语言验证**
  - 覆盖三种情况差异较大的语言，包括高资源和极低资源、新录音和档案录音，增强结论可信度。

- **指标选择合理**
  - 使用 CER 而非 WER 或 PER，更贴近后编辑成本，具有实用导向。
