## 摘要
从 Transformer 教师模型蒸馏得到的状态空间模型（SSM）兼具 Transformer 的性能与 SSM 的效率。我们将 Transformer-SSM 知识蒸馏扩展到多模态场景，并提出蒸馏音视频状态空间（DAVSS）模型。DAVSS 模型仅含 1400 万参数，参数量仅为 CAV-MAE 等基于 Transformer 模型的 1/12，但性能仍优于它们。DAVSS 在现有音视频模型的基础上进行了以下改进：1）更精细的输入分辨率：使用更小的 patch 大小处理输入，通过增加输入序列长度来弥补较小的模型规模。这一做法得到了以下观察的支持：较大的 patch 大小会导致性能下降。2）更深层的联合建模：将模型的较大部分（30%）用于音视频联合处理，而 CAV-MAE 中该比例不到 5%，从而在不显著增加与拼接后的音视频 token 相关的计算成本的情况下实现更深入的跨模态交互。

## Abstract
State-space models (SSMs) distilled from transformer teachers combine the performance of transformers with the efficiency of SSMs. We extend the Transformer-SSM knowledge distillation to a multimodal setting and propose the Distilled Audio-visual State-Space (DAVSS) model. The DAVSS model, 14M parameters, is 12 times smaller compared to transformer-based models such as CAV-MAE, and still outperforms them.   DAVSS improves over the existing audio-visual models by: 1) Finer input resolution: using smaller patch sizes process the input, compensating for the smaller model size by increasing input sequence lengths. This is supported by the observation that a larger patch size results in lower performance. 2) Deeper joint modeling: utilizing a larger portion of the model (30%) for joint audio-visual processing, compared to <5% in CAV-MAE, enabling deeper cross-modal interaction without significantly increasing the computational cost associated with the concatenated audio-visual tokens.

## 1. 论文的核心问题与整体含义

- **研究背景**：音频与视觉模态虽形式不同，但存在底层对应关系，联合学习两种模态已成为多模态研究的重要方向。Transformer 目前是音频与音视频建模的主流范式，但其自注意力机制具有 **二次时间复杂度**，在拼接音频-视觉 token 后序列变长，计算成本显著增加。
- **核心问题**：Transformer 的音视频模型（如 CAV-MAE）参数量大、计算效率低；状态空间模型（SSM）虽然高效，但在音频分类等任务上的性能此前落后于 Transformer。如何在保持高性能的同时，构建**更小、更高效**的音视频模型？
- **研究动机与整体含义**：将已有的 **Transformer→SSM 知识蒸馏**（DASS，蒸馏音频状态空间模型）从单模态扩展到多模态，提出 **DAVSS（Distilled Audio-Visual State-Space）**，利用 Transformer 教师（CAV-MAE）的知识提升 SSM 学生模型性能，同时发挥 SSM 处理长序列的高效性，实现小模型超越大模型。

## 2. 论文提出的方法论

- **核心思想**：用 **CAV-MAE 作为教师**，通过知识蒸馏训练一个基于状态空间模型的音视频学生模型 DAVSS；学生模型包含两个模态特定编码器（音频与视觉）和一个联合处理块。
- **模型架构**（DAVSS）：
  - 音频编码器输入：形状为 `1024 (T) × 128 (F)` 的梅尔谱图；视觉编码器输入：`224 × 224` 的 RGB 图像帧。
  - 每个模态编码器分为 **三个阶段**，每阶段包含一个状态空间块和一个基于 patch 合并的下采样层，逐步降低空间分辨率并增加特征通道数。
  - 音频和视觉编码器输出的二维特征先展平为一维、拼接，再重塑为二维特征，送入联合块处理。
  - 最后通过池化得到单一嵌入，由线性分类器输出最终标签。
- **关键技术细节**：
  - **更精细的输入分辨率**：采用比 CAV-MAE 更小的 patch 大小（如 patch size 4 或 6），产生更长的输入序列，以弥补模型规模较小的不足。实验表明 patch 越大性能越低。
  - **更深层联合建模**：将模型约 30% 的参数用于联合音视频处理；CAV-MAE 中联合层参数占比不到 5%。借助 SSM 的高效长序列建模能力，可在不显著增加计算成本的前提下实现更深入跨模态交互。
  - **知识蒸馏损失函数**：  
    \( L = 0.5 \left( L_{bce}(y, \hat{y}_{stu}) + L_{kldiv}(\hat{y}_{teach}, \hat{y}_{stu}) \right) \)

## 6. 论文的主要结论与发现

- **DAVSS 能以极小参数量超越 Transformer 教师**：14M 参数的 DAVSS-Tiny 在 AudioSet 上 mAP 为 51.6，优于 165M 参数的 CAV-MAE（50.5），且推理速度更快。
- **细分辨率输入是性能提升的关键**：使用更小 patch size 增加序列长度，可弥补小模型容量不足；随着 patch 增大性能单调下降。
- **更深联合建模有效**：将 30% 参数用于联合音视频处理可提升性能，但融合位置存在最优区间——过浅或过深均导致性能下降，说明需要一定数量的模态特定层将两种模态映射到公共空间。
- **知识蒸馏与初始化均重要**：仅靠随机初始化性能极低（mAP 28.2），加入蒸馏大幅提升（47.6）；ImageNet 初始化进一步提升至 50.3；音频分支用预训练 DASS 初始化可达到 52.2，但更强教师 DASSv3 初始化性能饱和（52.1）。
- **教师强度影响有限**：多帧教师可略微提升学生性能，但在标准 10 帧集成推理下，单帧与多帧教师差异不大。
- **分辨率可控制效率-精度权衡**：音频 patch 大小对推理速度影响大于视觉 patch 大小；选择 patch size 6 可显著快于 CAV-MAE 且性能仍更优。
