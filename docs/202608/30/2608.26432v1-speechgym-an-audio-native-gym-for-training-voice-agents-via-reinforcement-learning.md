## 摘要
语音代理必须完全通过语音调用工具并进行多轮对话，然而主流范式是在文本中训练它们。现有框架要么在专有语音 API 周围级联 TTS 和 ASR，梯度无法流动且每次调用成本使得在线策略强化学习难以承受；要么停留在文本中：它们能评估语音代理，但无法改进它们。我们提出 SpeechGym，一个音频原生的代理环境，其中两个全模态模型以原生音频对话，无外部 ASR 或 TTS，也没有 API 边界，在既有的文本代理基准的未修改任务、工具和成功检查之上运行，因此交互模态是唯一变量，循环保持本地且可端到端训练。音频代理能力并不源于音频理解。语音引入的失败是感知缺陷而非推理缺陷：代理选择了正确的工具和正确的参数槽，但填入了一个从波形中听错的值，而这一单一错误会级联为调用失败、重试同一调用以及浪费步骤预算。第二种失败是行为上的：在坚持要求的呼叫者面前，代理执行了未经授权的写入，并在回合结束时相信自己提供了帮助。两者都是可训练的，因为环境自动为它们提供标签：参数听错的调用会在数据库面前失败，而正确的调用会成功。障碍是稀疏性，而非信号。仅基于结果的 GRPO 在这里梯度匮乏，因为几乎每个 rollout 组都以相同方式失败；而按轮次的过程奖励对每个成功的工具调用给予奖励，几乎为每个组恢复了方差。以这种方式训练后，该代理无需进一步调优即可迁移到一个独立实现的语音基准，任务成功率翻倍以上，并将一个开放权重模型从该排行榜的末位提升至第二位，同时使用的轮次和 token 比训练前更少。

## Abstract
Voice agents must call tools and hold multi-turn dialogue entirely through speech, yet the dominant paradigm trains them in text. Existing frameworks either cascade TTS and ASR around a proprietary voice API, where gradients cannot flow and per-call cost makes on-policy reinforcement learning prohibitive, or stay in text: they measure voice agents but cannot improve them. We present SpeechGym, an audio-native agentic environment in which two omni-modal models converse in native audio, with no external ASR or TTS and no API boundary, over the unmodified tasks, tools and success check of an established text agentic benchmark, so that the interaction modality is the only variable and the loop stays local and trainable end to end. Audio agentic capability does not follow from audio understanding. The failures speech introduces are perceptual rather than reasoning deficits: the agent picks the right tool and the right argument slot but fills it with a value misheard from the waveform, and that single error cascades into a failed call, a retry of the same call, and a wasted step budget. A second failure is behavioural: under an insistent caller the agent performs an unauthorised write and ends the episode believing it helped. Both are trainable, because the environment labels them for free: a call with a misheard argument fails against the database while a correct one succeeds. The obstacle is sparsity, not signal. Outcome-only GRPO is gradient-starved here, since almost every rollout group fails identically, while a per-turn process reward crediting each successful tool call restores variance to nearly every group. Trained this way, the agent transfers with no further tuning to an independently implemented voice benchmark, more than doubling task success and carrying an open-weights model from last place to second on that leaderboard, while using fewer turns and tokens than before training.

## 1. 论文的核心问题与整体含义

- **研究动机**：语音代理需要在纯语音信道中调用工具、查询数据库并完成多轮对话，但主流训练范式仍在文本上进行。现有方案要么在专有语音 API 外围级联 ASR/TTS，梯度无法流通且在线强化学习成本过高；要么完全停留在文本，只能评估语音代理却无法训练改进。
- **核心问题**：如何在音频原生环境中端到端训练语音代理？语音模态会给代理带来哪些文本中不存在的失败模式？如何让这些失败转化为可学习的训练信号？
- **整体含义**：论文指出“音频理解能力”不等于“音频代理能力”——语音场景的失败主要是感知缺陷（听错槽位值）和行为缺陷（未经授权写入），而非推理缺陷。SpeechGym 将文本到语音的差距从一个固定测量问题转化为可优化问题，使语音代理能够通过强化学习真正改进。

## 2. 论文提出的方法论

### 2.1 环境设计：SpeechGym 架构

- **四个组件**（图 2）：
  - **用户模型 π_U**：冻结的 Qwen3-Omni-30B-A3B，直接生成原生音频作为呼叫方对话，不经 TTS。
  - **代理模型 π_θ**：可训练的 Qwen3-Omni-30B-A3B Thinker–Talker 模型，每步自主决定发出工具调用（结构化文本）还是语音回复。
  - **工具执行器 E**：直接沿用 τ²-bench 自带的执行器和数据库，工具调用保持文本，调用的参数错误即返回错误但不改变状态。
  - **评估器**：使用 τ²-bench 原有任务完成检查，不做修改。
- **关键设计**：只有用户–代理信道是音频，工具接口保持文本。这样将感知错误（听错参数）与行为错误（选错工具、越权操作）分离，因为工具接口无噪声，参数错误必源于听错或推理错误，而非传输损坏。
- **可训练性**：无外部 ASR/TTS、无专有 API 边界，整个循环本地可微分且采样免费。

### 2.2 奖励设计

- **终端奖励**：直接沿用 τ²-bench 的成功检查，不做自定义。每个任务从五个二元组件（数据库状态、信息传达、写操作参数、用户设备状态、自然语言断言）中选取一个子集 B(τ)，最终奖励为乘积：
  \[
  R(\tau) = \prod_{c \in B(\tau)} r_c, \quad r_c \in \{0,1\}
  \]
  所有必需条件满足才为 1，否则为 0；超过最大步数也为 0。
- **奖励一致性保证**：训练和评估的奖励路径完全一致；SpeechGym 的奖励在黄金轨迹上精确复现 τ²-bench 分数，且 vLLM 与非 vLLM 代码路径一致。

### 2.3 训练算法：GRPO + 每轮过程奖励

- **GRPO 基础**：每个任务采样 K=4 条完整语音轨迹，使用组内标准化计算优势：
  \[
  \hat{A}_{i,j} = \frac{r_{i,j} - \mu_i}{\sigma_i + \epsilon}
  \]
  更新目标为带 clip 的 PPO 风格损失（β=0，KL-free），仅训练 LoRA 适配器（rank 8, α=16）作用于 Thinker 的线性投影层，语音合成路径不训练。
- **过程奖励塑造**（解决梯度稀疏）：
  - 每个成功工具调用 +0.1，每个失败调用 −0.1；终端结果附加到最后一步。
  - 每轮回报为折扣和：
    \[
    G_t = \sum_{k=t}^{T} \gamma^{k-t} r_k, \quad \gamma = 0.99
    \]
  - 该奖励非 potential-based，因此优化目标改变，但终端评价标准（τ²-bench 原始检查）保持不变。

### 2.4 系统实现

- **vLLM-Omni 服务**：一个请求同时返回文本和语音，避免多次转换；按适配器名称提供服务，更新 LoRA 无需重载合并权重。
- **部署**：8×H200 单 pod，GPUs 0–5 运行三个 vLLM-Omni 服务器（每个 2 GPU），GPUs 6–7 运行 LoRA 训练；K=4 rollouts 在四个线程上轮询执行。
- **效果**：训练 epoch 端到端加速 5.4 倍，API 成本为 $0。

## 6. 论文的主要结论与发现

- **主要失败模式是感知而非推理**：基础 30B 全模态模型在语音 rollout 中听错槽位值的比例为 32%，文本仅为 2%（16 倍放大），并级联为 42% 工具错误率和 29% 死循环。同时观察到“自信错误地越权写入”这一行为缺陷。
- **梯度匮乏的根源是稀疏性，不是信号缺失**：仅结果奖励时，84% 的 rollout 组因组内全部失败而无梯度；每轮过程奖励将携带梯度的组比例提升至 99.6%。
- **跨流水线迁移显著**：训练后模型在 τ-Voice 独立环境中 pass@1 从 24% 提升至 53%，所有领域均有提升（Airline 24%→62%，Retail 45%→73%，Telecom 4%→24%），置信区间不重叠。
- **效率提升而非长度黑客**：成功翻倍的同时平均轮次从 26 降至 24，每任务 token 从 51,195 降至 48,398；在修复的任务上轮次降低 25%，与级联基线相比以更少轮次达到更高成功率。
- **策略是涌现的**：训练后代理自发学会拼写确认、纠正重试、切换查询键等修复策略，这些未在奖励中指定。

## 7. 优点

- **音频原生可训练环境**：首次将语音交互、多轮工具调用和在线强化学习三者结合，填补了现有评估-only 框架的空白。
- **奖励设计干净**：直接采用基准自身成功检查而非手工设计，使训练目标与评估目标一致，降低了奖励黑客风险。
- **过程奖励的精准诊断与解决**：定量展示仅结果奖励在低成功率下的梯度枯竭，并用每轮工具调用成功作为密集进度信号有效缓解。
- **跨流水线独立验证**：在完全不同的用户模拟器、声学条件和评分代码下不加微调即可迁移，提供了较强的泛化证据。
- **机制性检查充分**：通过行为标注（错误写入、死循环、恢复率）和成本分析（轮次/token 下降）排除指标博弈与长度黑客两个替代解释。
- **系统工程实用**：vLLM-Omni 服务与 LoRA 热更新使在线语音 RL 在本地算力下可行，API 成本为零。

## 8. 不足与局限

- **用户模型局限**：训练时用户模型为冻结的同款 Qwen3-Omni，与真实人类语音分布、口音、噪声、打断、电话信道等仍有差距，训练环境中的“理想化”语音分布可能限制真实场景泛化。
- **模型单一**：实验仅使用 Qwen3-Omni-30B-A3B 一款模型，未验证方法在其他全模态模型（如 VITA、Mini-Omni、Moshi）上的有效性；LoRA 仅作用于 Thinker，语音合成路径不对齐优化。
