## 摘要
流式文本到语音对于低延迟口语对话系统至关重要，然而许多系统等待句子级文本，因此只是伪流式。真正的令牌级合成必须从不确定前缀生成语音，同时在无界流中保持感知连续性并仅使用有界上下文。我们提出 X2Streaming-TTS，一个因果 TTS 框架，它消费异步到达的文本令牌并发出语音，而无需访问未来输入。为处理不确定前缀，我们引入因果提交，通过不确定性感知缓冲保持模糊表达为临时状态，并进行容量自适应、标点感知的分割。为保持声学连续性，我们进一步引入因果语音状态继承，跨段边界携带完整的 Code2Wav 状态和选定的历史 Talker 状态。结合注意力先验约束，它在保留有界声学上下文的同时阻止访问未来位置。实验表明，X2Streaming-TTS 在大多数主观和客观指标上优于现有伪流式模型。进一步分析表明，因果提交稳定了在线分割并减少因上下文不足导致的失败，而语音状态继承改善了边界连续性，且不降低自然度或说话人身份。X2Streaming-TTS 因此实现了严格的令牌级合成，质量与所评估的离线基线相当，单个请求的中位首音频令牌时间（TTFT）为 15.8 毫秒，128 个并发请求时的中位 TTFT 为 260.8 毫秒。我们的实现已公开于 https://github.com/X-Square-Robot/X2Streaming-TTS 。

## Abstract
Streaming text-to-speech is essential for low-latency spoken dialogue systems, yet many systems wait for sentence-level text and are therefore only pseudo-streaming. True token-level synthesis must generate speech from uncertain prefixes while maintaining perceptual continuity over an unbounded stream with bounded context. We present X2Streaming-TTS, a causal TTS framework that consumes asynchronously arriving text tokens and emits speech without accessing future input. To handle uncertain prefixes, we introduce causal commitment, which keeps ambiguous expressions provisional through uncertainty-aware buffering and performs capacity-adaptive, punctuation-aware segmentation. To preserve acoustic continuity, we further introduce causal speech-state inheritance, which carries the complete Code2Wav state and selected historical Talker states across segment boundaries. Together with an attention prior constraint, it blocks access to future positions while retaining bounded acoustic context. Experiments show that X2Streaming-TTS outperforms existing pseudo-streaming models on most subjective and objective metrics. Further analysis shows that causal commitment stabilizes online segmentation and reduces failures caused by insufficient context, while speech-state inheritance improves boundary continuity without degrading naturalness or speaker identity. X2Streaming-TTS thus achieves strict token-level synthesis with quality comparable to the evaluated offline baselines, a median time to first audio token (TTFT) of 15.8 ms for a single request, and a median TTFT of 260.8 ms at 128 concurrent requests. Our implementation is publicly available at https://github.com/X-Square-Robot/X2Streaming-TTS .

# X2Streaming-TTS 论文详细总结

## 1. 核心问题与整体含义

- **研究背景**：低延迟口语对话系统需要“真正”的流式文本到语音（TTS），即文本令牌异步到达时，系统应逐令牌、因果地生成语音，而不能等待完整句子。
- **核心矛盾**：语音一旦播放便不可修改，而流式文本前缀往往具有发音不确定性。例如，前缀 `He finished 3` 可能后续变为 `3 laps`（读作 *three*）或 `3rd`（读作 *third*），发音在词结束前已经分歧。系统若过早合成 `three`，便无法再修正为 `third`。
- **现有方法不足**：多数系统仍是“伪流式”，等待句子级文本或依赖未来令牌（lookahead），无法满足严格零前瞻因果性；同时，跨段边界重建音高、音色会造成可感知的不连续；仅按标点切分会产生过短片段，固定窗口切分则破坏语言结构。
- **本文目标**：实现严格的令牌级因果 TTS，在只看到当前和过去文本的前提下，决定“何时可以说话”以及“如何跨段延续语音状态”，同时保持有界上下文与实时性。

## 2. 方法论

### 2.1 系统总体框架与因果性约束

- 采用 **Qwen3-TTS** 作为骨干，因其具备三个必要性质：
  - 可计数的离散声学令牌输出；
  - 可迁移的波形解码状态（Code2Wav）；
  - 可观测的剩余缓存容量（KV-cache aware）。
- 严格因果性要求声学令牌 \(y_u\) 只能依赖当前时刻之前已观察到的文本令牌 \(x_{1:N(\tau_u)}\)、先前生成的声学令牌 \(y_{<u}\)，以及继承的语音状态 \(h_{k-1}\)，不能依赖未来文本。
- 系统由三个组件组成：
  - **流式前端**：决定哪些已到达文本可以释放；
  - **Talker**：将释放文本转换为离散声学令牌；
  - **Code2Wav**：将声学令牌解码为波形。

### 2.2 因果承诺（Causal Commitment）

用于决定“哪些文本可以不可逆地合成”以及“当前段何时关闭”。

#### 2.2.1 不确定性感知语义就绪

- 前端维护一个待定后缀 \(U_t\)，其发音可能被未来令牌改变。
- 每到达新令牌 \(x_t\)，将缓冲文本划分为：\(U_{t-1} \oplus x_t = E_t \oplus U_t\)，其中 \(E_t\) 是新释放的、发音已确定的最长前缀；\(U_t\) 是仍未解决的后缀。
- 确定性闭合规则覆盖数字、单位、符号、缩写和标点。例如，`3` 在未确定后续前会保留在 \(U_t\) 中；当后续令牌使其发音确定后，整个表达式被**原子化**规范化并释放，避免部分规范化进入声学模型。
- 语义就绪与容量控制顺序执行：只将“就绪且规范化”的单元放入活动 TTS 段；若活动段接近容量而 \(U_t\) 尚未解决，则关闭前面的稳定前缀，不切分未解决表达式。

#### 2.2.2 容量自适应标点感知分割（CAPS）

- **问题定义**：将文本切分成若干段，使每段声学生成所需的 KV-cache 足迹 \(G(S;\xi) \le B\)，同时最小化段数惩罚与边界类型惩罚。段边界类型 \(q_i\) 分为 1（句子末）、2（子句级）、3（弱标点）、Hard（非标点硬切），代价递增。
- **离线参考解**：采用动态规划 \(V(j) = \min_{0 \le i < j, G(x_{i+1:j};\xi) \le B}[V(i) + \lambda_{\text{seg}} + \mathbf{1}_{j<n} c(q_j)]\)，回溯得到最优边界。
- **在线容量估计**：
  - 对已完成段 \(S_k\)，用真实解码步数 \(A_k\) 与文本令牌数 \(n_k\) 更新扩展比估计：
    \[
    \widehat{\rho}_{k+1} = \Pi_{[\rho_{\min},\rho_{\max}]}\left((1-\beta_k)\widehat{\rho}_k + \beta_k \frac{A_k}{n_k}\right)
    \]
  - 预估缓存足迹 \(\widehat{G}_k(S;\xi) = \widehat{P}_k + \widehat{\rho}_k |S|\)，容量 \(\widehat{C}_k = \lfloor (B - R - \widehat{P}_k)/\widehat{\rho}_k \rfloor\)。
- **在线闭合规则**：设定阈值 \(T_{\ell,k} = \lceil \alpha_\ell \widehat{C}_k \rceil\)（\(\ell \in \{1,2,3\}\)，\(\alpha_1 \le \alpha_2 \le \alpha_3\)）。当新令牌 \(x_t\) 的边界类型为 \(\ell\) 且当前段长度 \(L_t \ge T_{\ell,k}\)，或 \(L_t \ge \widehat{C}_k\)（硬切）时，关闭当前段。
- **碎片化上界**：若每段最多容纳 \(C\) 个令牌，最坏情况下 CAPS 产生的段数满足 \(m_{\text{CAPS}} \le \frac{1}{\alpha_1} m^{\star}_C + 1\)，其中 \(m^{\star}_C = \lceil n/C \rceil\)。论文给出了证明。

### 2.3 因果语音状态继承（Causal Speech-State Inheritance）

用于跨段边界传递语音状态，保证声学连续性。

#### 2.3.1 两条独立路径

- **Code2Wav 状态继承**：完整传递前一段的波形解码器状态，包括 KV cache、卷积状态、反卷积状态和帧索引，用于 warm-start 下一段波形解码。
- **历史 Talker 状态继承**：传递前一段末尾固定数量 \(H\) 个 token 对齐的 Talker 状态，作为有界历史记忆（实验设置 \(H=4\)）。
- **健康检查**：仅当上一段满足“完整输入、消费全部文本、正常终止、扩展比在合理范围、Code2Wav 快照完整”等条件时，才继承两条路径；否则清空状态，从默认状态重新开始。

#### 2.3.2 固定因果注意力先验

- 形成记忆 \(M = [h_{-H+1:0}; e_{1:L}]\)，将历史 Talker 状态与当前段表示拼接。
- 注意力 logits 为内容相似度与距离偏置之和：
  \[
  \ell_{u,j} = 2\cos(q_u, m_j) + b(d_{u,j})
  \]
  其中距离偏置 \(b(d)\) 对 \(d<0\) 设为 \(-\infty\)（完全屏蔽未来），对近距离优于远距离，保证因果性。
- 通过内容相似度项，相关历史状态仍可被访问。

#### 2.3.3 有界注入

- 用注意力集中度 \(s_u\)（基于熵归一化）作为门控分数，\(s_u \in [0,1]\)。
- 定义有界增益 \(g_u = 0.015(0.5+0.5s_u)\)，注入的上下文为 \(m_u = \sum_{j \in A_u} a_{u,j} m_j\)，最终：
  \[
  z'_u = z_u + g_u m_u
  \]
- 由于 \(g_u \in [0.0075, 0.015]\)，注入的扰动被显式限制，避免历史状态过度影响当前表示。
