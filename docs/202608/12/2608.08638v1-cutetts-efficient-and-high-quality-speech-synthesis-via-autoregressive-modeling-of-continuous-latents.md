## 摘要
零样本文语转换（TTS）现已支持交互式助手、个性化媒体和无障碍工具。所有 TTS 系统都需要忠实的语言呈现、一致的说话人身份以及低延迟响应。然而，紧凑的流式系统必须在可预测的低速率潜在序列中保留足够的声学细节，而迭代扩散采样和无分类器引导会在每个自回归步骤中成倍增加推理成本。为了在高保真合成与低延迟推理之间取得平衡，我们提出了 CuteTTS，一种紧凑的连续自回归 TTS 系统。它结合了语义对齐的因果 VAE 潜在变量、块级自回归、显式说话人条件以及双向流匹配头。我们进一步引入了引导步蒸馏，该方法将无分类器引导和多个求解器步骤吸收到一个以区间为条件的学生模型中。在 LibriSpeech 和 Seed-TTS-Eval 上的评估表明，在零样本语音克隆中具有竞争力的可懂度和说话人相似度，同时与基础模型相比，蒸馏将首音频延迟降低了 23.3%，实时因子降低了 40.8%，且客观和主观质量相当。这些结果为连续自回归 TTS 提供了一条实用路径，使其能够兼顾高保真生成与实时交互的延迟需求。

## Abstract
Zero-shot text-to-speech (TTS) now supports interactive assistants, personalized media, and accessibility tools. All TTS systems require faithful linguistic rendering, consistent speaker identity, and low-latency response. Yet compact streaming systems must preserve sufficient acoustic detail in a predictable low-rate latent sequence, while iterative diffusion sampling and classifier-free guidance multiply inference cost at every autoregressive step. To strike a balance between high-fidelity synthesis and low-latency inference, we present CuteTTS, a compact continuous-autoregressive TTS system. It combines semantically aligned causal VAE latents with patch-level autoregression, explicit speaker conditioning, and a bidirectional flow-matching head. We further introduce guidance-step distillation, which absorbs classifier-free guidance and multiple solver steps into a single interval-conditioned student. Evaluations on LibriSpeech and Seed-TTS-Eval demonstrate competitive intelligibility and speaker similarity in zero-shot voice cloning, while distillation lowers first-audio latency by 23.3% and real-time factor by 40.8% relative to the base model with comparable objective and subjective quality. These results provide a practical path toward continuous-autoregressive TTS that reconciles high-fidelity generation with the latency demands of real-time interaction.

  - 迭代扩散采样和无分类器引导（CFG）在每一个自回归步骤上都要多次执行模型前向，推理成本成倍上升，直接影响流式延迟。

## 2. 方法论

### 2.1 因果音频 VAE 与语义对齐

- **结构**：采用 DAC 风格全卷积架构，包含堆叠因果卷积和残差块，支持增量编码/解码，将 24 kHz 波形映射到 12.5 Hz、64 维连续潜在序列。
- **σ-VAE 后验**：为避免连续自回归建模中的后验方差坍缩，编码器仅预测均值 \(\mu = E_\phi(x)\)，尺度从预设分布采样 \(\sigma \sim p_\sigma\)，得到 \(z = \mu + \sigma \epsilon\)。
- **语义对齐**：受 Semantic-VAE 启发，将 VAE 潜在序列与冻结的 WavLM 教师特征在时间和维度上对齐，通过余弦损失鼓励共享语言结构。
- **训练目标**：综合多分辨率 Mel 重构、对抗与特征匹配损失、轻加权 KL 正则项和语义对齐损失：

\[
\mathcal{L}_{\text{VAE}} = \lambda_{\text{mel}} L_{\text{mel}} + \lambda_{\text{adv}} L_{\text{adv}} + \lambda_{\text{feat}} L_{\text{feat}} + \lambda_{\text{KL}} L_{\text{KL}} + \lambda_{\text{sem}} L_{\text{sem}}
\]

- 训练完成后仅保留因果编码器和解码器，TTS 模型完全在连续 VAE 空间工作。

### 2.2 显式说话人条件

- 训练紧凑的 ECAPA 风格学生说话人编码器，蒸馏冻结的 WavLM Large 说话人验证教师。
- 损失包括：学生-教师余弦对齐、batch 内成对相似度匹配、教师诱导相似度分布匹配。
- 学生嵌入 \(s\) 通过可学习投影注入因果 backbone；在扩散头中通过自适应层归一化（AdaLN）条件化。
- 训练时使用条件 dropout，为推理阶段的无分类器引导提供无条件分支。

### 2.3 Patch 级扩散自回归

- 将目标潜在帧按 patch 大小 \(K\)（默认 \(K=2\)）划分为不重叠 patch：

\[
P_i = (z_{iK}, z_{iK+1}, \dots, z_{(i+1)K-1})
\]

- **Patch 编码器**：双向 Transformer，在每个 patch 内部加一个可学习 summary token，以其最终状态作为 patch 嵌入 \(a_i = A(P_i)\)；参考语音同样编码为 \(a^{\text{ref}}\)。
- **因果 backbone**：根据文本、说话人条件、参考 patch 序列和历史生成 patch 嵌入，计算当前步隐藏状态：

\[
h_i = F_\theta(y, s, a^{\text{ref}}, a_{<i})
\]

- **扩散头**：双向注意力，在条件 \((h_i, s, P_{i-1})\) 下对下一 patch 建模。
- **条件流匹配**：使用线性路径 \(x_t = (1-t)\xi + tP\)，目标速度 \(v^\star = P - \xi\)，训练损失：

\[
\mathcal{L}_{\text{FM}} = \mathbb{E}\left[\|v_\theta(x_t, t \mid h_i, s, P_{i-1}) - v^\star\|_2^2\right]
\]

- 生成当前 patch 后，patch 编码器得到 \(a_i\)，供下一个自回归步骤使用；stop head 控制终止，VAE 解码器增量输出波形块。

### 2.4 引导步蒸馏

- **教师轨迹**：LM 级 CFG 构建引导速度。条件分支为 \(c_i = (h_i, s, P_{i-1})\)；无条件分支去掉文本、参考和说话人条件，仅保留历史 patch：\(c_i^u = (h_i^u, P_{i-1})\)。引导速度：

\[
v_T^{\text{cfg}}(x,t \mid c_i) = v_T(x,t \mid c_i) + w\left[v_T(x,t \mid c_i) - v_T(x,t \mid c_i^u)\right]
\]

- **蒸馏目标**：从噪声 patch \(x_t\) 出发，用 CFG 引导的教师速度数值积分得到 \(x_{t+\Delta t}^{\text{teacher}}\)，计算区间平均速度 \(\bar{v}_T = (x_{t+\Delta t}^{\text{teacher}} - x_t)/\Delta t\)。学生以起始时间、区间长度和引导尺度为条件，学习该平均速度：

\[
\mathcal{L}_{\text{GS}} = \mathbb{E}\left[\|v_S(x_t, t, \Delta t \mid c_i, w) - \bar{v}_T\|_2^2\right]
\]

- **推理**：单次学生前向直接映射 \(x_{t+\Delta t} = x_t + \Delta t\, v_S(\cdot)\)，不需要单独的无条件分支；同一学生支持不同步数预算。
- **核心思想**：引导移除和步数减少不是两个顺序蒸馏阶段，而是在同一目标中联合学习。

## 6. 主要结论与发现

- **总体性能**：CuteTTS 以约 0.2B 参数在 LibriSpeech 和 Seed-TTS 基准上取得与领先系统相当的 WER 和 SIM；蒸馏学生质量接近基础模型，但推理成本显著下降。
- **效率提升**：在配对协议下，CuteTTS-distill 将平均首音频延迟降低 23.3%，平均 RTF 降低 40.8%；P50 从 48.7 ms 降至 37.1 ms，P95 从 52.3 ms 降至 40.8 ms。
- **表示粒度**：更高 VAE 帧率提升重建质量，但固定 patch=1 时会导致 WER 快速上升；固定 LM token 率下，适度增大 patch（如 12.5 Hz、patch=2）可显著提升 SIM/UTMOS，但过大 patch 会使扩散头负担增加、WER 上升。
- **语义对齐**：对 VAE 重建几乎没有负面影响，但显著降低 TTS 的 WER，说明语义对齐使连续表示更容易被因果 backbone 建模。
- **说话人条件**：移除显式说话人嵌入大幅降低说话人相似度；仅加到扩散头即可恢复大部分损失；AdaLN 与全局 token 注入无一致优劣。
- **蒸馏鲁棒性**：在 4、2、1 NFE 下，蒸馏模型保持低 WER 和高 SIM，尤其在极低步数下明显优于基础模型，且 UTMOS 始终更高。

## 7. 优点

- **紧凑高效**：约 0.2B 参数即可与更大规模系统竞争，且支持流式生成，首音频延迟低至约 37 ms（蒸馏版）。
- **方法创新**：将 CFG 移除和多步求解器集成到单一区间条件学生中，推理时单分支、少步数即可维持质量。
- **系统设计完整**：语义对齐 VAE、显式说话人条件、patch 级自回归和流匹配头分工明确，兼顾重建保真与低速率自回归可预测性。
- **实验较全面**：覆盖多个公开基准、多类基线、主观盲评、效率基准和多种消融，尤其对表示率与 patch 大小联合效应的分析具有洞察。
- **消融有针对性**：对语义对齐、说话人条件注入方式等做了受控比较，并引入独立说话人嵌入模型减少评价偏差。

## 8. 不足与局限

- **训练资源披露不足**：未报告训练所用 GPU 数量、型号和总训练时间，难以评估实际算力成本和可复现性。
- **训练数据不可公开**：依赖 550,000 小时内部多语言数据，外部难以直接复现训练；数据分布对模型质量的影响也无法独立验证。
- **主观评测规模有限**：仅 50 条样本、7 名标注者，且与某些基线的自然度比较中平局率高，结论稳定性可能不足。
- **蒸馏策略相对保守**：CuteTTS-distill 仅更新扩散头，未联合优化 backbone；蒸馏在极低 NFE 下虽优于基础模型，但绝对质量随步数下降仍可能受限。
- **效率评测场景单一**：仅在单块 RTX 4090、固定 50 请求、batch=1 下测量，未报告 CPU 或真实流式并发下的表现；部分基线（如 VibeVoice-Realtime）因不支持任意参考声音克隆而使用默认声音，比较不完全对等。
- **潜在评估偏差**：说话人相似度主评估器与说话人编码器蒸馏教师同源，尽管用 WeSpeaker 做了独立验证，但在与其他系统横向比较时仍可能存在偏差。
