## 摘要
语音大语言模型的最新进展展现了其在理解复杂音频任务方面的卓越能力。尽管取得了这些进展，长上下文推理仍受到KV缓存巨大内存需求的严重制约。现有以文本为中心的压缩方法在此场景下力不从心，常常破坏语音连续性或丢弃关键语义线索。为此，我们提出VoxZip，一个无需训练、两阶段的语义锚定KV缓存压缩框架。第一阶段利用自动语音识别（ASR）转录作为显式语义锚点，对音频token进行时间对齐、压缩和融合，显著减少初始KV缓存，同时提升token信息密度。为进一步提高压缩率，第二阶段采用基于时间衰减累计注意力的动态过滤策略，以淘汰非必要token并缓解早期token偏置。在Qwen3-Omni上针对六个不同音频基准的综合评估证明了我们方法的优越性。VoxZip在长音频推理中表现出色，并在短时任务上持续保持高保真感知。值得注意的是，在长上下文场景下，即便进行高达20倍的激进KV缓存压缩，其仍能保持未压缩基线90%以上的性能。此外，在4倍压缩比下，VoxZip使推理吞吐量提升1.9倍，同时峰值内存开销降低3.3倍。代码和模型将发布于 https://github.com/MM-Speech/VoxZip。

## Abstract
Recent advancements in Speech Large Language Models have demonstrated remarkable capabilities in understanding complex audio tasks. Despite this progress, their long-context inference remains severely bottlenecked by prohibitive KV cache memory demands. Existing text-centric compression methods struggle here, often disrupting speech continuity or discarding crucial semantic cues. To address this, we propose VoxZip, a train-free, two-stage semantic-anchored KV cache compression framework. The first stage uses automatic speech recognition (ASR) transcriptions as explicit semantic anchors to temporally align, compress, and fuse audio tokens, significantly reducing the initial KV cache while elevating token information density. To further improve the compression ratio, the second stage employs a dynamic filtering strategy based on temporally decayed accumulated attention to evict non-essential tokens while mitigating early-token bias. Comprehensive evaluations on Qwen3-Omni across six diverse audio benchmarks demonstrate the superiority of our approach. VoxZip excels in long-audio reasoning and consistently maintains high-fidelity perception on short-form tasks. Notably, it sustains over 90\% of the uncompressed baseline performance even under an aggressive 20x KV cache compression in long-context scenarios. Furthermore, at a 4x compression ratio, VoxZip yields a 1.9x increase in inference throughput alongside a 3.3x reduction in peak memory overhead. Code and models will be available at https://github.com/MM-Speech/VoxZip.

## 1. 核心问题与整体含义

- **研究动机**：语音大语言模型（Speech LLMs, SLLMs）在长上下文音频推理中面临严重的 KV cache 内存瓶颈，主要来自音频 token 数量庞大、时间冗余高、信息密度低。
- **核心问题**：现有以文本为中心的 KV cache 压缩方法直接迁移到音频场景时，容易破坏语音连续性或丢失关键语义线索；音频 token 的注意力分布稀疏、分散，难以用纯注意力分数可靠定位关键语义锚点。
- **整体含义**：提出一种免训练、两阶段的语义锚定压缩框架 VoxZip，在不牺牲长音频理解与短任务感知能力的前提下，大幅降低 KV cache 内存和推理开销。

## 2. 方法论

### 2.1 核心思想

VoxZip 采用两阶段压缩策略：

1. **语义锚定音频压缩（Stage 1）**：利用 ASR 转录文本作为显式语义锚点，对音频特征进行时间对齐、分组池化和跨模态融合，提升 token 信息密度。
2. **时间衰减 KV cache 淘汰（Stage 2）**：在解码阶段基于时间衰减的累积注意力分数动态淘汰低信息 token，缓解早期 token 偏差。

### 2.2 Stage 1：语义锚定音频压缩

- 使用 ASR 模型（Whisper-Turbo）生成带时间戳的转录，仅保留置信度大于 0.3 的片段。
- 根据时间戳将原始音频特征序列切分为：
  - **语义音频区间**：与转录文本对应的连续声学特征段；
  - **背景音频区间**：未被转录覆盖的部分，保留原始特征。
- 对每个语义区间：
  - 将音频特征按时间均匀划分为与文本 token 数相同的组；
  - 对每组进行元素级平均池化，得到压缩音频表示；
  - 将压缩后的音频特征与对应的文本嵌入逐元素相加，得到**融合语义锚定表示**。
- 最终按时间顺序拼接融合语义段与背景段，形成压缩输入序列；语义区间的长度可压缩至原始约 0.25 倍。

### 2.3 Stage 2：时间衰减 KV cache 淘汰

- 每层独立计算时间衰减累计注意力分数：

  \[
  A^{(t)} = \gamma \cdot [A^{(t-1)}, 0] + \text{Softmax}\left(\frac{q_t K_t^\top}{\sqrt{d}}\right)
  \]

  其中 \(\gamma\) 为衰减系数（论文设为 0.95），用于惩罚早期 token 的累计优势。
- 缓存分区：
  - 始终保留前 \(T=4\) 个 attention sink token；
  - 始终保留最近窗口 token（占缓存预算 20%）；
  - 中间历史 token 按 top-\(N\) 时间衰减分数选取。
- 最终更新 KV cache 为三部分拼接，实现动态、有界的历史缓存。

## 7. 优点

- **免训练、可即插即用**：无需额外训练成本，适合直接部署到现有 SLLM。
- **语义锚定设计**：将 ASR 文本作为高密度语义引导，有效缓解音频注意力稀释问题，并在极低缓存预算下保持性能。
- **两阶段协同**：第一阶段减少初始 KV cache 并加速 prefill，第二阶段动态淘汰低信息 token，二者共同实现高压缩比。
- **时间衰减机制**：显式抑制早期 token 累计偏置，提升长上下文稳定性。
- **保留副语言信息**：通过融合压缩音频而非仅依赖文本，较好兼顾语义与声学感知。
- **实验全面**：覆盖长/短音频、多个基准、极端压缩率、效率和多组消融，验证较扎实。
