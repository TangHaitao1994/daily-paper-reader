## 摘要
口语语言为在稠密遥感影像中指定任意目标提供了一种自然、免持的交互方式，然而现有的指称遥感图像分割基准仅接受书面表达。为弥补这一空白，我们引入了 \dataset：一个基于 RISBench 的语音查询基准，在保留原始图像、掩码与数据划分的同时，增加了具有不同口音与音色的语音。其困难评估集结合了旋翼噪声、风噪和混合干扰，并设置了三种信噪比水平。我们还提出了 \model，一种高效的双边网络，它融合了保持边界的视觉路径、保留 token 的语音编码、核线性跨模态注意力以及分辨率细化头。该设计在两个尺度上利用语音对视觉特征进行条件化，而无需显式构造密集的语音-视觉亲和矩阵，随后利用高分辨率视觉特征恢复精细边界。在干净测试划分上，采用 Swin-Base 的 \model 实现了 62.09% 的平均交并比（mIoU）和 68.22% 的整体交并比（oIoU），分别比最强的音频适配遥感基线高出 5.38 和 2.08 个百分点。该模型在困难集上仍保持最佳 mIoU，为 54.09%。据我们所知，这是首个面向遥感图像的全句语音查询指称分割基准与模型研究。代码将公开发布。

## Abstract
Spoken language offers a natural, hands-free interface for specifying an arbitrary target in dense remote-sensing imagery, yet existing referring remote-sensing image segmentation benchmarks accept only written expressions. To bridge this gap, we introduce \dataset, a spoken-query benchmark derived from RISBench that adds accent- and voice-diverse speech while preserving the original image, mask, and data splits. Its hard evaluation sets combine rotor, wind, and mixed interference with three signal-to-noise levels. We also propose \model, an efficient bilateral network that combines a boundary-preserving visual path with token-preserving speech encoding, kernel linear cross-modal attention, and a resolution refinement head. The design conditions visual features at two scales without materializing a dense speech--visual affinity matrix, then restores fine boundaries using high-resolution visual features. On the clean test split, \model with Swin-Base achieves 62.09\% mean intersection over union (mIoU) and 68.22\% overall intersection over union (oIoU), outperforming the strongest audio-adapted remote-sensing baseline by 5.38 and 2.08 percentage points, respectively. It retains the best hard-set mIoU at 54.09\%. To the best of our knowledge, this is the first benchmark and model study of full-sentence spoken-query referring segmentation for remote-sensing imagery. The code will be made publicly available.

## 2. 论文提出的方法论

### 2.1 VoiceAeroRef 数据集构建

- **来源**：从 RISBench 获取原始图像-表达-掩码三元组；RISBench 来自 DOTA-v2 与 DIOR 混合遥感影像。
- **质量筛选**：剔除 6 条只包含标点“.”、无语义内容的训练表达，最终得到 **52,466 个有效三元组**：
  - 训练：26,294
  - 验证：10,013
  - 测试：16,159
- **受控语音合成**：
  - 使用 8 种神经 TTS 语音，构成 **4 种口音 × 2 种性别** 的因子设计（美国/英国/澳大利亚/印度，各含男声/女声）。
  - 每个训练表达保存 8 条录音；**每个 epoch 每个源样本随机抽取其中一条**，避免将视觉样本量人工扩大 8 倍。
  - 验证集与测试集每个表达只分配 1 条干净语音，并保证各类别数量均衡（测试每类 2019–2020 条）。
- **困难评估集**：
  - 在测试集干净语音上叠加三类干扰：**旋翼噪声、风噪、旋翼+风混合噪声**。
  - 名义信噪比：**15 dB、7.5 dB、0 dB**，每句话额外加入 ±1.5 dB 随机扰动。
  - 九种条件尽量均匀分配，每个测试源只出现一次，不将测试集扩大 9 倍。

### 2.2 AeroReformer2 模型架构

- **双边视觉编码器**：
  - 浅层 detail path 保留 **1/8 分辨率**边界证据；
  - 层级 context path 提取 **1/4、1/8、1/16、1/32** 多尺度语义特征；
  - 主干可选 ResNet-101 或 Swin-Base，细节路径使用深度可分离卷积。

- **语音编码与 token 保留**：
  - 使用冻结的 **wav2vec 2.0 base** 将波形编码为帧级 token 序列 \(A \in \mathbb{R}^{T \times D_a}\)，不将整句压缩为单个向量，以保留名词、属性、空间关系等局部信息。

- **置信度门控 token 记忆（CGTM）**：
  - 对每个语音 token 学习一个标量置信度 \(g_t\)：
    \[
    g_t = \sigma(W_2 \,\text{SiLU}(W_1 \,\text{LN}(a_t)))
    \]
  - 有效权重 \(w_t = m_t g_t\)，其中 \(m_t\) 是 padding mask。
  - 置信度同时用于：
    - 调制跨注意力统计量；
    - 全局音频 FiLM 分支：
      \[
      \bar{a} = \frac{\sum_t w_t a_t}{\sum_t w_t + \epsilon}, \quad
      V' = V \odot (1 + \gamma(\bar{a})) + \beta(\bar{a})
      \]
      其中 \(\gamma, \beta\) 初始化为 0。

- **语音-视觉核线性注意力（SV-KLA）**：
  - 采用 ELU+1 正特征映射：
    \[
    q_i = \phi(W_q v_i), \quad k_t = \phi(W_k a_t), \quad u_t = W_v a_t, \quad \phi(x) = \text{ELU}(x)+1
    \]
  - 先累积固定大小的语音充分统计量：
    \[
    S = \sum_{t} w_t k_t u_t^T, \quad z = \sum_t w_t k_t
    \]
  - 再对每个视觉 query 进行条件化：
    \[
    y_i = \frac{q_i^T S}{q_i^T z + \epsilon}
    \]
  - 该操作不构造 \(N \times T\) 的密集语音-视觉亲和矩阵；注意力核复杂度约为 \(O((N+T)d^2)\)，而传统 softmax 为 \(O(NTd)\)。

- **双尺度双边路由**：
  - 在 **1/16** 尺度用 SV-KLA 进行粗粒度语义定位；
  - 上采样后与 **1/8** 上下文特征相加，再进行第二次 SV-KLA 细粒度定位；
  - 与 detail path 的 1/8 特征融合，经视觉核注意力全局细化；
  - 最终在 **1/4 分辨率细化头**中结合上采样语义特征、骨干 1/4 上下文和独立高分辨率细节路径，恢复精细物体边界；不在 1/4 网格上做跨模态注意力。

- **训练目标**：
  - 二元交叉熵 + soft Dice 损失。
