## 摘要
全双工语音系统必须决定何时进入、保持或放弃会话发言权，即便在多位说话人重叠或发出不取得发言权的反馈语时也是如此。现有评测研究双人话轮转换或端到端智能体行为，但缺乏在多方场景下对真实发言权转移与易混淆非事件进行统一、受控的评测。我们提出 MultiPartyTurnBench（MPTB），一个包含 240 段合成生成、按声道分离的对话基准，覆盖两到五位说话人及六种交互类型。MPTB 评测两个互补任务：话轮结束（EOT）检测区分真实的话轮完成与暂时停顿，打断（INT）检测区分成功的发言权接管与不取得发言权的语音。精确的事件条件标注支持使用假阳性约束召回率和带符号延迟进行因果评测。在声学、语义和话轮预测基线中，我们发现明显的不对称性：学习系统在 4.3–11.8% 的假阳性率下达到 82.5–92.6% 的 EOT 召回率，而 INT 检测要么漏检接管，要么产生过多误激活。这种不对称性延伸到五个全双工智能体：它们在进入话轮上达到 86.1–95.8% 的平衡准确率，但在选择性打断处理上表现接近随机（46.9–54.7%）。Gemini-3.8-Live 对 97.7% 的反馈语让步，而 MiniCPM-o-4.5 仅对 1.4% 的真实打断让步。这些发现表明，选择性发言权控制是可靠多方语音交互中一个独特且尚未解决的挑战。

## Abstract
Full-duplex speech systems must decide when to enter, hold, or relinquish the conversational floor, even as multiple speakers overlap or backchannel without taking it. Existing evaluations study dyadic turn-taking or end-to-end agent behavior, but lack a unified, controlled evaluation of genuine floor transitions against confusable non-events in multi-party settings. We introduce MultiPartyTurnBench (MPTB), a benchmark of 240 synthetically generated, channel-separated conversations spanning two to five speakers and six interaction types. MPTB evaluates two complementary tasks: End-of-Turn (EOT) detection distinguishes genuine turn completion from temporary holds, while Interruption (INT) detection distinguishes successful floor takeovers from non-floor-taking speech. Exact event-conditioned annotations enable causal evaluation using false-positive-constrained recall and signed latency. Across acoustic, semantic, and turn-projection baselines, we find a stark asymmetry: learned systems achieve 82.5-92.6% EOT recall at 4.3-11.8% false-positive rates, while INT detection suffers from missed takeovers or excessive false activations. This asymmetry extends to five full-duplex agents which achieve 86.1-95.8% balanced accuracy on turn entry, yet perform near chance (46.9-54.7%) on selective interruption handling. Gemini-3.8-Live yields to 97.7% of backchannels, whereas MiniCPM-o-4.5 yields to only 1.4% of genuine interruptions. These findings establish selective floor control as a distinct, unresolved challenge for reliable multi-party voice interaction.

# MultiPartyTurnBench 论文详细总结

## 1. 论文的核心问题与整体含义

- **研究背景与动机**：全双工语音系统（full-duplex speech systems）需要在实时多人对话中持续做出三项关键决策——何时**进入发言权**（enter the floor）、**保持发言权**（hold）或**放弃发言权**（relinquish/yield）。这一决策不能仅依赖语音活动检测（VAD），因为：
  - 说话人可能**暂停但未放弃发言权**（mid-turn pause / hold）；
  - 听者可能发出**反馈语**（backchannel，如“嗯”“对”）但并不试图接管发言权；
  - 多人场景中多个听者可能同时重叠发言、插话或试图打断，但只有部分成功取得发言权。

- **现有研究的空白**：
  - 双人（dyadic）基准（如 TurnBench、SID-Bench）研究话轮结束与打断检测，但缺乏多人场景的覆盖；
  - 自然多方语料库（如 TEIDAN、AVCC、VoxConverse）侧重下一说话人预测或话语权转移分析，但不评测 EOT/INT 事件检测；
  - 全双工智能体基准（如 Full-Duplex-Bench、FD-Bench、MultiTalkBench 等）评测端到端的对话行为，但不单独评测底层的话语权判别能力。

- **本文的研究问题**：能否在**多方受控场景**下，统一评测两类互补的因果判别任务：
  1. **EOT（End-of-Turn）检测**：真实的话轮结束 vs. 暂时停顿（说话人保留发言权）；
  2. **INT（Interruption）检测**：成功的发言权接管 vs. 反馈语等不改变发言权的语音。

- **整体含义**：论文旨在建立一个统一、受控、因果式的评估框架，揭示多方语音交互中**选择性地处理打断/话语权控制**这一尚未解决的系统性问题。


## 2. 论文提出的方法论

### 2.1 核心思想

- 构建一个**受控合成基准**（MultiPartyTurnBench, MPTB），在语音合成**之前**就显式定义话语权状态（floor state）和事件时间线，从而获得**精确的事件级标注**。
- 将发言权控制分解为两个互补任务，并用**事件条件化的正样本与难负样本**进行评测，即：
  - EOT 正样本：TURN-yield（当前说话人放弃发言权）；EOT 难负样本：TURN-hold（暂停后同一人继续）。
  - INT 正样本：INTERRUPTION（听者成功接管）；INT 难负样本：BACKCHANNEL 和 NONCONTENT（笑声等）。
  - 未成功的打断尝试（NON-FLOOR-TAKING INT.）因结果模糊被排除在因果评分之外。

### 2.2 事件分类体系（Taxonomy）

| 事件 | 话语权结果 | EOT 角色 | INT 角色 |
|---|---|---|---|
| TURN-yield | 放弃发言权 | **正** | — |
| TURN-hold | 保留发言权 | **难负** | — |
| TURN-interrupted | 被成功打断 | 排除 | — |
| INTERRUPTION | 发言权转移 | — | **正** |
| NON-FLOOR-TAKING INT. | 保留发言权 | — | 排除 |
| BACKCHANNEL | 保留发言权 | — | **难负** |
| NONCONTENT（笑声）| 不变 | — | **难负** |

### 2.3 对话生成管线（5 个阶段）

1. **事件条件对话生成**：用 LLM（GPT-4.1）生成带有受限事件标签（TURN / CLAIM_FLOOR / VOCALIZE_NO_CLAIM）的多方对话脚本，不指定精确时间戳或话语权结果。
2. **话语权状态编排（Floor-state orchestration）**：确定性离散事件编排器解析符号动作，将其实现为 hold / yield / interruption / backchannel 等具体事件，并基于 AMI 语料库的真实时序统计分配话轮时长、间隙、暂停和重叠。
3. **说话人渲染（Speaker rendering）**：用 Kokoro-82M TTS 独立合成每位说话人的语音，使用性别平衡且开发/测试集分离的 24 个声音。
4. **声学场景渲染**：加入环境噪声、MUSAN 音效和远处干扰语音作为“打扰事件”，用于压力测试假阳性检测；不影响基准正事件。
5. **通道组装与发布**：输出带噪声道、干净声道、标注事件日志、渲染元数据及随机种子。

### 2.4 评估协议

- **因果式预测**：系统只能利用截至预测时刻的音频；分数经过阈值的上升沿触发离散事件检测，并施加 2 秒不应期。
- **事件匹配**：每个正样本在 [t−0.25 s, t+3.0 s] 窗口内与最早的未匹配预测一一对应；难负样本按时间跨度评分，任何检测落入跨度内均计为假阳性（FP）。
- **指标**：
  - 召回率（Recall）= TP/(TP+FN)
  - 假阳性率（FPR）= FP/(FP+TN)
  - 带符号延迟（signed latency）Δt = t_pred − t_gold（正值=延迟，负值=提前）
- **工作点选择**：在开发集上选择满足 FPR ≤ 10% 的最大召回阈值，冻结后用于测试集；若测试 FPR > 15% 则标记为超预算。
- **全双工智能体的行为诊断**：额外报告平衡准确率 bACC = (Recall + 1 − FPR)/2 和行动偏差 Abias = Recall + FPR − 1。


## 3. 实验设计

### 3.1 数据集与场景

- **MPTB 规模**：240 段合成对话，总计 6.89 小时，按 N∈{2,3,4,5} 说话人数量 × 6 种交互类型（Casual、Task-Oriented、Instructional、Collaborative、Argumentative、Narrative）交叉平衡。
- **划分**：48 个开发对话 + 192 个测试对话，开发/测试使用不重叠的 TTS 声音（8 vs. 16）。包含 3,422 个 EOT 正样本和 241 个 hold 难负样本；367 个 INT 正样本和 1,481 个非发言权接管难负样本。
- **人工验证**：对全部 240 个对话、6,116 个候选事件进行 3 人独立标注，验证生成标签的感知有效性。

### 3.2 离线基线（12 个系统，3 类）

- **声学 VAD**：RMS Energy、WebRTC VAD、Silero VAD
- **语义端点头（Semantic endpointers）**：Smart Turn v2、Kyutai SVAD、Mimi Endpointer
- **话轮预测模型（Turn-taking models）**：VAP、MuVAP、DualTurn、WavLM-Large anchor、Turn-1-Mini、ESPnet Turn-Taking

### 3.3 全双工智能体评估（5 个系统）

- 对 **GPT-Live-1、Gemini-3.8-Live、MiniCPM-o-4.5、Realtime-Venus、Step-Audio3-Realtime** 在 120 个交互场景上各重复 3 次（1,800 次试验）。
- 设计 **START 探针**（区分真实 EOT vs. mid-turn hold 停顿）和 **STOP 探针**（区分真实打断 vs. 反馈语），要求智能体在可观察的行为层面做出决策。

- 用 **TurnBench 双人子集**（12 个对话）和 **AMI 四人会议子集**（15 个会议，约 7.1 小时）验证部分兼容的离线检测器，以考察合成到真实的泛化差异。

## 6. 主要结论与发现

- **EOT 与 INT 之间存在显著的不对称性**：学习系统可达到 82.5–92.6% 的 EOT 召回率（FPR 4.3–11.8%），但最强的 INT 检测召回率仅 56.2%；部分系统获得高 EOT 召回但 INT 召回极低。
- **高召回率不等于选择性**：声学 VAD（如 Silero）在 EOT 上召回 97.2% 但 FPR 达 93.5%，在 INT 上召回 85.4% 但 FPR 89.2%，无法区分真实话语权转移与一般语音活动。
- **说话人数量影响是模型特异的**：EOT 检测大体稳定；INT 检测不同模型呈现相反趋势（Kyutai 随 N 增加下降，MuVAP/DualTurn 上升），但没有任何模型在 5 人场景下超过 50% INT 召回。
- **交互类型对 INT 影响远大于 EOT**：Kyutai 在合作式对话中 INT 召回 47.0%，在指令式对话中 77.5%；不同模型的最难交互类型各不相同。
- **全双工智能体的行为证实离线发现**：五个智能体的 START 平衡准确率可达 86.1–95.8%，但 STOP 均接近随机（46.9–54.7%）。
  - **Gemini-3.8-Live** 几乎无差别让步（对 97.7% 反馈语让步，偏倚 +0.98）；
  - **MiniCPM-o-4.5** 几乎不让步（仅对 1.4% 真实打断让步，偏倚 −0.99），暴露两种相反的失败模式。
- **合成到真实具有一定泛化性**：在真实四人 AMI 会议中 VAP 仅检测到 35.9% 的打断（FPR 5.3%），即使做了片内阈值调优，说明打断检测的自然多方挑战不是合成语音特有的伪影。


## 7. 优点

- **事件条件化的精确标注与因果评测**：在语音合成前由确定性编排器生成标签，避免了从波形事后推理的标注偏差；使用 FPR 约束的因果评分，模拟实时决策。
- **难负样本设计巧妙**：引入 hold 暂停作为 EOT 难负、backchannel/笑声作为 INT 难负，成功将“语音活动”与“话语权变化”区分开。
- **覆盖多说话人数量与交互类型**：因子式平衡设计允许分别考察说话人数量和对话风格的影响。
- **离线检测与在线智能体行为的双重验证**：将离线检测结果与实际全双工智能体的 START/STOP 行为关联，揭示出聚合指标无法反映的相反失败模式。
- **丰富的分析与附录**：提供了人工验证、误差解剖、交互类型与说话人数量的细粒度分析、跨语料验证、全双工协议细节以及可复现性映射。


## 8. 不足与局限

- **合成语音的外部效度有限**：MPTB 使用 TTS 合成语音，无法完全模拟自然对话中的韵律、犹豫、时序适应和话语权协商模糊性；合成与真实语音之间的难度方向并非一致（不是简单的高估或低估），因此在 MPTB 上的分数应视为受控诊断而非自然对话错误率的真实估计。
- **语言与人口统计学覆盖有限**：仅限英语，且口音多样性受限于 TTS 声音池，未系统覆盖不同语言、地区口音或社会文化背景下的话轮转换约定与打断行为模式。
- **真实语音验证范围有限**：仅使用 15 个四人 AMI 会议和双人 TurnBench 子集，且真实语音的事件标签来自人工分段与规则映射，而非独立的 MPTB 分类体系标注；跨语料的性能差异无法归因于单一的说话人数量或合成语音因素。
- **全双工智能体评估的混淆因素**：Gemini 的 STOP 行为主要由提供商级 barge-in 策略驱动，而非模型自身的对话理解能力，这可能使“选择性打断处理接近随机”的结论部分反映提供商策略而非模型底层能力；部分智能体（如 Step-Audio-3）存在很少的有效 STOP 试验（24/180），影响统计稳健性。
- **离线与在线关联分析较弱**：模型级别的秩相关不显著（Spearman ρ = −0.20 和 0.316），事件级别虽有关联但并未充分解释，表明离线检测结果与在线智能体行为之间的对应关系仍需更深入考察。
- **实验数量虽多但单点对比有限**：部分分析格子的负样本数较少（如每个交互类型仅 21–38 个 EOT hold 负样本），FPR 的按类型估计可能不可靠。
