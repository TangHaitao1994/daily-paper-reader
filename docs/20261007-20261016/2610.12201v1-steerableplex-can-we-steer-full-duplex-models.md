## 摘要
全双工语音模型能够同时听和说，实现自然交互，但随着对话历史增长，它们变得越来越难以控制。当用作用户模拟器时，这种缺乏控制可能导致它们偏离预设场景，并产生不可靠的评估结果。我们引入了 SimIF-Bench（模拟器指令遵循基准），它评估对话模型是否保持在预设场景内，并按所需顺序完成多个目标。该基准显示，当前的开源全双工模型难以遵循这些约束。然后我们引入一种基于分组奖励解耦归一化策略优化（GDPO）的训练配方，使全双工模型能够在持续对话中遵循文本指令，同时保持其话轮转换能力。通过将得到的 SteerablePlex 连接到一个异步后端语言模型（该模型监控对话并在需要时提供指令），我们构建了一个更可控的全双工用户模拟器，它比现有开源模型和 GPT-Realtime 更可靠地遵循多阶段约束。

## Abstract
Full-duplex speech models can listen and speak simultaneously, enabling natural interaction, but become increasingly difficult to control as the conversation history grows. When used as user simulators, this lack of control can cause them to deviate from prescribed scenarios and produce unreliable evaluation outcomes. We introduce SimIF-Bench (Simulator Instruction-Following Benchmark), which evaluates whether a conversational model stays within a prescribed scenario and completes multiple goals in the required order. The benchmark reveals that current open-source full-duplex models struggle to follow such constraints. We then introduce a Group Reward-Decoupled Normalization Policy Optimization (GDPO)-based training recipe that enables a full-duplex model to follow textual instructions during an ongoing conversation while maintaining its turn-taking ability. By connecting the resulting SteerablePlex to an asynchronous backend language model that monitors the conversation and provides instructions when needed, we build a more controllable full-duplex user simulator that follows multi-stage constraints more reliably than existing open-source models and GPT-Realtime.

  2. **SteerablePlex**：一个可在对话运行过程中通过文本指令被“实时引导”的全双工模型，并配合异步后端 LLM 形成 Actor–Director 架构，提升可控性。

## 2. 论文提出的方法论

### 2.1 SimIF-Bench 基准设计

- 复用 Full-Duplex-Bench v2 的 200 个分阶段对话场景和交互式模拟设置。
- 将待评估模型作为“考官”，固定 PersonaPlex 作为“考生”。
- 每次通话最长 120 秒，对话会被转写并交给 LLM 裁判。
- 评估维度包括：
  - 主题一致性（topic adherence，1–5 分）
  - 自然度（naturalness，1–5 分）
  - 目标完成率（goal completion）
  - 精确目标顺序完成率（exact ordered completion）
- 类别型判断采用多数投票，自然度采用中位数，并要求裁判引用转写文本作为证据。

### 2.2 Actor–Director 架构

- **Actor**：SteerablePlex，作为前端全双工模型，持续处理语音生成、倾听和话轮转换。
- **Director**：一个异步文本 LLM，通过外部流式 ASR 和模型内部文本流来跟踪任务、目标和对话状态。
- 每 2 秒 Director 更新一次目标状态，并生成候选指令，同时返回 `send`、`wait` 或 `none`，决定是否立即注入指令、延迟注入或忽略。

### 2.3 指令注入机制

- SteerablePlex 基于 PersonaPlex，包含用户音频、模型音频和模型文本三条同步流。
- 运行时指令通过现有 tokenizer 编码，并用特殊 start/end-of-instruction token 包裹后插入模型文本流。
- 指令插入期间，两侧音频流输入静音 token，对话时间不前进。
- 这种设计利用预训练模型对文本流的语义理解能力，使模型更容易学会“被划定的文本片段是指令”，而不需要学习全新的控制模态。

### 2.4 训练数据准备

- 使用 Fisher 数据集，由 Qwen3-32B 为每个对话轮次生成简短可执行指令。
- 最终策划出 **9,417 个 RL 样本**，总计 **130.8 小时** rollout 时间。
- 基于 Behavior-SD 流程合成 **2,000 个重叠语音对话**，使用来自 Full-Duplex-Bench v2 的 200 个场景派生指令。
- 合成数据总计 **84.1 小时**立体声音频，其中 200 个对话作为 held-out。

### 2.5 GDPO 训练与奖励设计

- **GDPO** 扩展 GRPO 到多奖励场景：
  - 对每个奖励维度在组内独立标准化：  
    \(z_{i,d} = \frac{r_{i,d} - \mu_d}{\sigma_d}\)
  - 对无定义或标准差为 0 的维度置零。
  - 加权组合：  
    \(e_{A_i} = \sum_d w_d z_{i,d}\)
  - 再次在组内标准化得到最终优势 \(A_i\)。
- 训练目标：
  \[
  L_{\text{RL}}(\theta) = \frac{1}{G}\sum_{i=1}^{G} \left[-A_i \log \pi_\theta(y_i|h) + \beta D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}})\right]
  \]
  其中 \(y_i\) 同时包含文本和音频 token，KL 项用于防止模型偏离基础 PersonaPlex 策略过远。
- **奖励组成**：
  - 目标完成奖励：由 LLM 裁判对模型在指令到达后的语音进行 `none`、`partial`、`full` 评分。
  - 自然度奖励：评估模型是否以符合语境的自然方式完成行为，而不是机械插入内容；出现自我回答、替对方说话或像外部助手发言则得 0 分。
  - 话轮转换奖励：包含重叠惩罚、抢占话轮惩罚、响应延迟惩罚和反馈音 F1，防止模型通过抢话或不自然停顿来刷分。

## 6. 论文的主要结论与发现

- 当前开源全双工模型在 SimIF-Bench 上目标完成率和精确顺序完成率都较低，说明“能自然对话”不等于“能可靠执行多阶段脚本”。
- GPT-Realtime 是基线中最强的，但仍经常无法按顺序完成全部目标。
- PersonaPlex 自然度最高，但目标完成率最低，说明仅靠系统提示和自然交互训练难以保证场景控制。
- 任务无关训练的 SteerablePlex 已经能缩小与 GPT-Realtime 的差距，并在自然度与任务完成之间取得更好平衡。
- 领域内训练版 SteerablePlex 在目标完成率上达到 **91.4%**，精确顺序完成率达到 **47.5%**，分别超过 GPT-Realtime 的 **80.6%** 和 **32.5%**。
- 在 Full-Duplex-Bench 上，SteerablePlex 通过显

显式指令控制，在 Full-Duplex-Bench 的话轮转换指标上仍保持与 PersonaPlex 相当的竞争力；尤其是在反馈音 F1、平滑切换和打断成功率方面没有出现明显退化，说明实时指令注入并未破坏模型原有的全双工交互能力。  
- 综合来看，SteerablePlex 证明了将“文本指令流”作为运行时控制信号是可行的，Actor–Director 架构能够在不重新设计语音模型架构的情况下，显著提升多阶段脚本执行的可靠性；但精确顺序完成率仍然只有 47.5%，说明长对话中的状态追踪和顺序控制仍是开放难题。  
- 作者认为，这一结果支持将可控性作为全双工对话模型评估和训练的独立维度，而不是仅依赖自然度或话轮转换指标。

## 7. 局限性与未来工作

- **基准规模有限**：SimIF-Bench 仅使用 200 个场景，held-out 泛化测试只有 20 个场景，难以充分覆盖真实应用中多样的指令类型和对话扰动；未来可扩展场景数量、语言和交互模式。  
- **LLM 裁判偏差**：目标完成和自然度奖励依赖 Qwen3.8-27B 自动判断，虽然要求引用转写作为证据，但仍存在主观性和系统偏差，缺少人工评估校准。  
- **控制粒度与频率**：Director 每 2 秒更新并注入指令，频率固定；没有系统探索更细粒度或事件驱动的指令注入策略，也没有检验在极短话轮或高频打断下的稳定性。  
- **模型规模局限**：SteerablePlex 基于 7B 级 PersonaPlex，尚未验证该方法能否扩展到更大规模语音模型或多模态前端，也未测试跨语言场景。  
- **训练数据依赖**：RL 样本来自 Fisher 和合成对话，场景覆盖偏向英语电话对话；合成数据的质量和多样性可能限制模型对真实噪声、口音和复杂重叠语音的泛化。  
- **未来方向**：作者建议将 Director 与 Actor 联合微调、引入更长程记忆和自动纠错机制，以及开发更细粒度的顺序执行评估协议，进一步提升全双工模拟器的可靠性。
