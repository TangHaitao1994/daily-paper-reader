## 摘要
对话语音代理已取得显著进展，通过级联和端到端架构提供越来越自然的人机交互。然而，虽然近期基准广泛评估了二元互动和被动音频理解，但它们大多忽略了普遍存在的现实场景：多方对话。在这些场景中评估代理比在二元互动中更具根本性挑战，因为对话复杂度呈指数级增长。为使语音代理无缝融入人类群体动态，它们不仅需要生成符合语境的回应，还必须展现对开放轮流发言的细致理解。为弥补这一空白，我们提出了 Multiparty Bench (MP-Bench)，这是首个专门设计用于客观评估对话语音系统作为多方语境中积极参与者的基准。MP-Bench 从两个主要维度评估代理行为：轮流发言意识和回应适当性。此外，我们将基于理解的问答任务作为补充评估。通过基准测试 12 个语音代理，我们发现实时语音代理在多方理解上仅达到或低于 22%，在多方轮流发言上接近随机水平，暴露了实时语音代理在多方场景下面临的开放挑战。

## Abstract
Conversational voice agents have advanced significantly, offering increasingly natural human-machine interactions through both cascaded and end-to-end architectures. However, while recent benchmarks extensively evaluate dyadic interactions and passive audio comprehension, they largely overlook a prevalent real-world scenario: multi-party conversations. Evaluating agents in these settings is fundamentally more challenging than in dyadic interactions due to the exponentially greater conversational complexity. For voice agents to integrate seamlessly into human group dynamics, they must not only generate contextually appropriate responses but also demonstrate a nuanced understanding of open turn-taking. To address this gap, we introduce Multiparty Bench (MP-Bench), the first benchmark specifically designed to objectively evaluate conversational speech systems as active participants within multi-party contexts. MP-Bench assesses agent behavior along two primary dimensions: turn-taking awareness and response appropriateness. Additionally, we incorporate comprehension-based question-answering tasks as a complementary evaluation. By benchmarking 12 voice agents, we find that real-time voice agents stay at or below 22% on multiparty comprehension and remain near chance on multiparty turn-taking, exposing an open challenge for real-time voice agents under multiparty scenario.

## 2. 论文提出的方法论

### 2.1 核心设计思想
- 将语音代理置于**四人群聊**中（3 个模拟人类说话人 + 代理），通过**受控的合成对话**精确控制对话状态，从而获得**客观、可自动评估**的 ground truth。
- 任务设计确保**必须依赖音频线索**（如声纹、音高、说话人身份）才能解决，避免仅靠转录文本就能“作弊”。
- 评估维度分为**理解任务**和**行为任务**，行为任务进一步覆盖**显式轮流发言、隐式轮流发言、负向轮流发言**三种条件。

### 2.2 两个核心场景

- **Discussion（讨论场景）**
  - 三个模拟人类围绕一个事实性问题展开争论（如“埃菲尔铁塔含天线有多高？”）。
  - 对话结束时，其中一人**显式点名**“AI Assistant”，要求代理评判谁的回答正确。
  - 用于评估显式轮流发言 + 多方理解能力。

- **Turn-based Game（轮流游戏场景）**
  - 一个人类介绍游戏规则并进行角色分配：分成两组，每组有 Leader 和 Follower。
  - 核心规则：当某组 Leader 发言时，**对方组的 Follower** 必须立即回应；代理在其中担任某个 Follower 角色。
  - 游戏内容刻意简单（随机词、递增/递减数字），以**隔离轮流发言能力**，避免复杂推理干扰。
  - 用于评估**隐式**（根据上下文判断该自己说）和**负向**（不该自己说时必须保持沉默）轮流发言。

### 2.3 任务类型与评估指标

- **理解任务**：音频结尾有人向代理提一个关于前文的理解性问题，代理的回答与 ground-truth 比较。
  - 指标：**Overall Accuracy**、**Speaker Name Accuracy**（专门衡量说话人归属，随机基线 33.3%）。
- **行为任务**：评估代理在音频结束后的行为：
  - 是否正确地发言或保持沉默：**Turn-Taking Accuracy**（Turn-based Game 中随机基线 50%）。
  - 发言内容是否适当：**Appropriateness Accuracy**（要求正确的轮流行为 + 有效回应）。
- **响应延迟**：从输入音频结束到代理第一个生成词开始的时间，基于 ASR 词级时间戳计算。

### 2.4 评估流程与自动评分

- 输入音频流式送入语音代理。
- 代理的语音输出使用 **NeMo Parakeet 流式 ASR** 转写，并利用词级时间戳判断是否在输入结束后有响应。
- 生成文本由 **GPT-5 作为 LLM-as-a-judge** 进行评分。
- 人类评估验证 LLM 评分的可靠性（Krippendorff’s α = 0.745，Cohen’s κ = 0.646）。

### 2.5 数据集构建流程
1. 由 LLM 生成对话文本，使用 **ElevenLabs 对话 API** 合成高质量多说话人音频。
2. 精心挑选**声学特征差异明显**的说话人组合，保证说话人可分离。
3. 对生成对话进行**过滤**：
   - 规则过滤：每个参与者至少被提及一次，以便从音频建立声纹-身份映射。
   - LLM 过滤：仅保留“无说话人标签时文本 LLM 无法恢复全部说话人身份，但提供匿名说话人 ID 时能恢复”的对话，确保任务必须依赖音频，同时存在理论上可解的上界。
4. 生成 QA 对和游戏回合，再进行 LLM 过滤与人工验证。
5. 最终得到 **927 个任务**（543 个理解任务、384 个行为任务），来自 256 个对话实例（每个场景 128 个）。

## 3. 实验设计

### 3.1 数据集与场景
- **MP-Bench**：927 个任务，平均音频时长 45.6 ± 11.5 秒，平均每任务 8.4 ± 2.1 个发言轮次。
- 场景：Discussion（128 个对话实例）和 Turn-based Game（128 个对话实例）。
- 每个任务固定 3 个模拟人类说话人 + 代理，共 4 个参与者。

### 3.2 对比的模型（共 12 个语音代理 + 文本 LLM 基线）

- **实时语音代理（10 个）**
  - 专有全双工 API：GPT-Realtime、Gemini-2.5 Live、Gemini-3.1 Live
  - 开源全双工流式模型：Moshi、PersonaPlex、Freeze-Omni、Ultravox
  - 半双工端到端语音 LM：GLM-4-Voice、Covo-Audio
  - 另有 DuplexCascade（表格中出现，但正文未重点介绍）
- **非实时语音代理（2 个）**
  - Qwen3-Omni、Gemini-3.1-Pro（处理完整音频后生成文本）
- **文本 LLM 参考基线（2 种配置）**
  - Gemini-3.1-Pro（ASR-only）：只给 ground-truth 转录，不给说话人标签。
  - Gemini-3.1-Pro（SpkD-ASR）：给 ground-truth 转录 + 匿名说话人标签，模拟“完美说话人分离”的级联系统上界。

### 3.3 主要结果概述
- **理解任务（Discussion）**：非实时 Gemini-3.1-Pro 表现最好（Overall 73.30%，Speaker Name 78.28%）；实时最佳 Covo-Audio 为 Overall 32.60%，Speaker Name 37.37%；多数实时模型 Speaker Name 低于 33.3% 随机基线。
- **行为任务（Discussion，显式轮流）**：多个实时模型 Turn-Taking Accuracy 超过 90%，如 GPT-Realtime、GLM-4-Voice、Covo-Audio 均达 99–100%。
- **行为任务（Turn-based Game，隐式/负向轮流）**：几乎所有实时和非实时模型 Turn-Taking Accuracy 接近 50% 随机基线（46–53%），Appropriateness Accuracy 普遍在 20–50% 之间。
- **文本 LLM 基线**：SpkD-ASR 在 Turn-based Game 达到 98.44% Turn-Taking Accuracy 和 98.44% Appropriateness，证明任务可解，瓶颈在于从音频恢复说话人归属。

## 5. 实验数量与充分性

- **主要实验**：覆盖 12 个语音代理 + 2 个文本 LLM 配置，共 14 个评估设置，包含理解与行为两类任务、三种轮流条件。
- **消融实验**：
  1. **单说话人游戏消融**：将 Turn-based Game 简化为 1 个说话人与代理直接游戏，评估 GPT-Realtime 和 Gemini-2.5 Live，结果表明两者 Turn-Taking Accuracy 为 76.0% 和 68.0%，显著高于随机，证明多方失败并非游戏规则遵守问题。
  2. **多方感知提示消融**：对 5 个实时模型对比默认系统提示与“多方感知”提示，发现提示仅对 Discussion 场景部分有效，对 Turn-based Game 无明显改善，说明问题无法通过简单提示解决。

## 6. 论文的主要结论与发现

- **实时语音代理在多方理解上普遍较弱**：最佳实时系统 Covo-Audio 的 Overall Accuracy 仅 32.60%，多数模型的 Speaker Name Accuracy 低于 33.3% 随机基线，与非实时模型（Gemini-3.1-Pro 达 73.30%/78.28%）差距巨大。
- **显式轮流发言相对容易，隐式/负向轮流发言普遍失败**：在 Discussion 场景中，多个实时模型可达到 90% 以上的显式轮流准确率；但在 Turn-based Game 中，几乎所有模型（实时和非实时）都接近 50% 随机水平。
- **瓶颈在于从音频恢复说话人归属**：文本 LLM 在获得匿名说话人标签后几乎完美解决隐式/负向轮流（98.44%），而仅有转录时接近随机（49.22%），说明当前语音代理的核心缺陷是缺乏可靠的说话人归属能力。
- **失败并非源于游戏规则复杂或提示不足**：单说话人消融和多方感知提示消融证明，多方失败可归因于多方动态本身的复杂性。
- **LLM 评判与人类判断高度一致**：支持了自动评估方法的有效性。
- **总体结论**：多方感知是当前对话语音代理缺失的基础能力，需要下一代模型重点突破。

## 7. 优点

- **填补空白**：首个将语音代理作为多方对话活跃参与者进行评估的基准，区分理解与行为、显式/隐式/负向轮流。
- **客观可控**：使用合成音频和结构化任务，能够获得精确的 ground truth，避免真实对话中轮流行为的标注困难。
- **强制音频依赖**：通过构造“文本无法解决、音频可解决”的任务，真实考察声学理解能力，防止仅靠语言先验“蒙混过关”。
- **评估体系较完整**：结合 ASR 时间戳检测响应、LLM-as-a-judge 评分、人类评估验证，指标设计合理（含随机基线对比）。
- **消融实验严谨**：从规则难度、提示、声音相似度、评判器偏差等多个角度排除混淆因素，增强了结论可信度。
- **公开资源**：提供代码仓库，便于复现和后续研究。

## 8. 不足与局限

- **合成音频与真实场景差距明显**：无重叠语音（0% vs. AMI 的 24.5%）、无背景噪声、无长时间停顿、无犹豫或口误，与真实多方会议存在领域差距。
- **评估范围较窄**：每个任务只评估一个决策点（音频结束后的响应），不评估多轮持续参与、打断、回声道等真实互动行为；全双工模型在音频播放期间的发

言/打断行为未被评估，无法反映真实全双工交互中的动态调整能力。

- **语言与领域覆盖有限**：全部为英语、受控合成对话，未涉及多语言、方言、噪声、远场、会议等真实场景变化。
- **固定参与者数量**：所有任务均为 3 个模拟人类 + 代理，未探索更多或更少参与者的情况，真实多方对话人数可变。
- **自动评分依赖外部系统**：ASR 错误和 LLM 评判偏置可能影响结果，尽管已进行人类验证，但未覆盖全部任务。
- **模型适配与时效性**：部分开源模型可能需要额外适配全双工流式接口，其能力可能未被完全发挥；结果仅反映当前版本，快速迭代可能使结论过时。
- **数据集构建依赖 LLM 与 TTS**：对话文本由 LLM 生成、语音由 ElevenLabs 合成，可能引入语言模板化和声学不自然性，与真实人类多方对话仍有差距。

总体而言，MP-Bench 是多方对话语音代理评估的重要一步，但其结论需在更真实、更多样化的环境中进一步验证。未来工作应扩展至真实录音、连续多轮互动和更丰富的说话人动态。
