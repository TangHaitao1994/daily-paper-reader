## 摘要
我们提出语音记忆，一种仅推理的代理语音识别方案：在流式处理时，一个冻结的校正器读取单个每领域memory.md文件，并对每个话语决定是作用于假设还是弃权并保留1-best结果。异步地，一个分数门控优化器通过有限编辑修订该文件，仅当编辑严格提升保留集分数时才接受该编辑。从经典ASR-LM框架扩展而来，我们称这种分离为侦听-思考架构；两个角色仅通过记忆耦合，因此权重不变，学习到的技能保持可审计和可移植。约束被证明是该循环发现的有效技能：无约束的生成式错误纠正（GER）会过度纠正，在金融新闻上高达64%的编辑会破坏正确令牌，而语音记忆将这一比率降至35%。在十个HyPoradise领域中使用开放校正器，语音记忆将加权词错误率从8.36%降至7.52%（添加三个上下文示例后为7.47%），且未使任何数据集退化至其1-best基线以下；增益集中在可恢复余量最大的地方，包括航空旅行指令（8.40%降至3.40%）和嘈杂远场语音（CHiME-4，12.69%降至10.46%）。该记忆可跨校正器类型迁移，并在推理路径上增加零参数。我们提供了演示和示例代码以供未来研究。

## Abstract
We present Voice Memory, a inference-only scheme for agentic speech recognition: at stream time, a frozen corrector reads a single per-domain memory.md and decides per utterance whether to act on the hypothesis or abstain and keep the 1-best. Asynchronously, a score-gated optimizer revises that file through bounded edits, accepting an edit only when it strictly improves a held-out score. Extended from classical ASR-LM framework, we refer this split the listener-thinker architecture; the two roles are coupled only through the memory, so no weights change and the learned skill stays auditable and portable. Restraint turns out to be the operative skill this loop discovers: unconstrained generative error correction (GER) over-corrects, breaking correct tokens on up to 64% of its edits on financial news, and Voice Memory, reduces this rate to 35%. Across ten HyPoradise domains with an open corrector, Voice Memory, lowers weighted word error rate from 8.36% to 7.52% (7.47% with three added in-context examples) without regressing any dataset below its 1-best baseline; gains concentrate where recoverable headroom is largest, including air-travel commands (8.40% to 3.40%) and noisy far-field speech (CHiME-4, 12.69% to 10.46%). The memory transfers across corrector families and adds zero parameters to the inference path. A demo and example code are provided for future studies.

  在代理语音识别（agentic speech recognition）设定下，校正器的关键问题不再是『能否修复错误』，而是『是否应该修改假设』。

## 2. 论文提出的方法论
### 2.1 核心思想：Voice Memory（语音记忆）
- 采用**听者－思考者（listener‑thinker）架构**：  
  - **听者（同步路径）**：冻结的校正器在流式推理时读取一个领域专属的记忆文件 `memory.md`，对每个话语决定是执行纠正（act）还是弃权保留 1‑best 结果（abstain）。  
  - **思考者（异步路径）**：一个独立的优化器利用验证集上分数门控的编辑循环，对记忆文件进行有限增删改，仅接受严格提升留存分数的编辑。  
- 所有模型权重保持冻结，自适应知识完全存储在**一小段人类可读的 Markdown 文本**中（通常 <10 KB）。

### 2.2 关键技术细节
- **决策形式化**：  
  校正被建模为每话语的动作选择：  
  - \( H \) 为 n‑best 假设列表，\( h_1 \) 为 1‑best。  
  - 校正器 \( M_\theta \) 根据记忆 \( s \) 产生输出 \( \hat{y} \)：  
    \[
    \hat{y}= 
    \begin{cases} 
    M_\theta(H,s) & \text{if } a=\text{act} \\ 
    h_1 & \text{if } a=\text{abstain}
    \end{cases}
    \]
- **优化循环**（参见算法 1）：  
  1. 在训练集上 rollout，收集成功与失败样本。  
  2. 优化器基于样本和预算 \( \ell_e \) 生成候选新记忆 \( s' \)。  
  3. 在选择集上评分，若 \( \text{Score}(M, s', D_{sel}) \) 严格高于当前最佳，则接受更新；否则加入拒绝池。
- **关键指标**  
  - **可恢复信息比 \( \rho \)**：量化校正关闭 1‑best 与 oracle 之间差距的比例。  
    \[
    \rho = \frac{\text{WER}_{1\text{-best}} - \text{WER}_{\hat{y}}}{\text{WER}_{1\text{-best}} - \text{WER}_{\text{oracle}}}
    \]
    \( \rho = 1 \) 完美恢复；\( \rho < 0 \) 为有害校正。  
  - **有害编辑率（HER）**：所有 token 编辑中有害编辑（破坏正确 token）的比例，用于衡量过度纠正。

## 7. 优点
- **纯推理自适应**：无权重更新，无需训练基础设施，符合设备端边缘推理场景。
- **可审计与可移植**：外部化为明文记忆文件，人类可读，可跨模型家族复用，易于版本控制和溯源。
- **参数零增长**：推理路径不引入额外参数，仅增加一个极小文本文件的读取。

- **方法简洁、优雅**：将自适应问题转化为文本记忆的编辑优化，思路新颖，并提供了开源代码与演示。
