## 摘要
我们提出 VibeVoice-ASR-BitNet，这是 VibeVoice-ASR 的压缩变体，专为边缘 CPU 上的实时推理而优化。我们根据每个阶段的计算特性进行异构量化：VAE 声学标记器使用全流水线 INT8 量化（I8_S）并结合 kernel 融合和 SIMD 优化，而自回归语言模型采用 BitNet 风格的三元权重（I2_S）。为了在激进压缩下保持准确率，我们采用渐进式量化感知训练策略。在推理方面，我们在 ggml 框架内为 ARM 和 x86 平台实现了定制的 SIMD kernel 和融合算子，仅需使用 3 个 CPU 线程即可实现 RTF < 1 的实时识别。与 FP16 基线相比，VibeVoice-ASR-BitNet 在相近模型大小（约 1.6 GB）下比 Whisper.cpp 快 1.6~2.3 倍，且仅有适度的准确率下降。

## Abstract
We present VibeVoice-ASR-BitNet, a compressed variant of VibeVoice-ASR optimized for real-time inference on edge CPUs. We apply heterogeneous quantization tailored to the computational characteristics of each stage: the VAE acoustic tokenizer uses full-pipeline INT8 quantization (I8_S) with kernel fusion and SIMD optimization, while the autoregressive language model adopts BitNet-style ternary weights (I2_S). To preserve accuracy under aggressive compression, we employ a progressive quantization-aware training strategy. For inference, we implement custom SIMD kernels and fused operators within the ggml framework targeting both ARM and x86 platforms, achieving real-time recognition with RTF < 1 using as few as 3 CPU threads. VibeVoice-ASR-BitNet is 1.6-2.3x faster than Whisper.cpp at comparable model sizes (~1.6 GB), with only modest accuracy degradation compared to the FP16 baseline.

## 2. 论文提出的方法论

### 2.1 模型架构与压缩策略
- **基础架构**：沿用 VibeVoice-ASR 的设计，包含一个 7 阶段 ConvNeXt 的 VAE 声学分词器（含声学编码器和语义编码器，将 24 kHz 音频下采样 3200 倍至 7.5 Hz）以及一个自回归语言模型解码器。
- **关键调整**：为降低边缘部署的内存压力，将原始 7B 参数的 Qwen2.5-7B 解码器替换为 1.5B 参数的 Qwen2.5-1.5B。

### 2.2 异构量化（Heterogeneous Quantization）
根据两个组件的计算瓶颈差异，采用不同的量化方法：

- **I8_S：VAE 标记器的全流水线 INT8 量化**
  - VAE 标记器属于 IO 密集型（激活数据量远大于权重，尤其在前几阶段），权重量化（如 W8A32）几乎无法加速。
  - 因此采用**全流水线 INT8**：权重、激活、中间缓冲区和算子边界全程保持 INT8 格式，消除精度转换开销，并利用 AVX2/NEON 原生指令加速。
  - 将 GELU 激活替换为 ReLU 以适配 INT8 运算，并通过渐进式训练恢复精度。

- **I2_S：语言模型的三元权重量化**
  - 自回归解码阶段是**权重带宽受限**（每生成一个 token 需读取全部 1.5B 参数，但仅一个激活向量）。
  - 采用 BitNet 风格的三元权重 { -1, 0, +1 }（2 比特存储），权重压缩 8 倍；激活在线量化为 INT8。
  - 嵌入层和 LM 头保留 6 比特（Q6_K）以避免过大精度损失。
  - 计算时，三元权重在线解包为 INT8，再复用与 I8_S 相同的 `maddubs` SIMD 流水线。

### 2.3 渐进式量化感知训练（Progressive QAT）
- **VAE 标记器训练**（三阶段）：
  1. 将 GELU 替换为 ReLU 后短暂微调。
  2. 插入伪量化节点，利用线性渐变的混合参数 α 执行渐进式量化预训练：  
     \(\hat{x} = (1-\alpha) \cdot x + \alpha \cdot \text{FakeQuant}(x)\)，α 从 0 线性增加到 1。
  3. α=1 后继续以完全量化状态微调，稳定收敛。直接 QAT 无法收敛。
- **语言模型训练**：冻结已训练好的 INT8 VAE 标记器，然后对三元权重的 LM 解码器进行大规模预训练和监督微调两阶段训练。

### 2.4 推理优化
- **算子融合**：在 ggml 框架内实现了 `im2col_asym`、`mul_mat_add_relu`、`add_scaled`、`rms_norm_scaled` 等融合 kernel，减少中间张量在内存中的往返读写。
- **定制 SIMD kernel**：为 I8_S 和 I2_S 设计了统一的 SIMD 乘法-加法内核（基于 AVX2 的 `_mm256_maddubs_epi16` 和 NEON 的 `smull/sadalp`），支持多 tiling 策略以最大化寄存器利用率。

## 6. 论文的主要结论与发现
- **实时性与速度**：VibeVoice-ASR-BitNet 仅需 3 线程即可达到 RTF < 1，在约 1.6 GB 模型规模下，比 Whisper.cpp 快 1.6~2.3 倍，低线程数下优势更明显。
- **压缩率与精度平衡**：整体压缩 2.9 倍（从 4.62 GB 到 1.58 GB），但相比 FP16 基线，WER 仅绝对上升 1~4%，且是多语言模型中唯一完全运行在 CPU 上的方案，在 MLC 英语、AMI、VoxPopuli 等基准上达到可比最优。
- **异构量化有效性**：I8_S 有效释放了 VAE 的内存 IO 瓶颈，I2_S 将 LM 解码的权重带宽压力降至 1/8，算子融合与 SIMD 内核进一步挖掘了 CPU 潜力。

## 7. 优点
- **针对性设计**：精准识别出 VAE 和 LM 完全不同的计算瓶颈（IO limited vs. weight-bandwidth limited），分别设计 I8_S 全流水线和 I2_S 三元权重，实现高效异构压缩。
- **训练策略创新**：提出的渐进式 α-blending QAT 有效解决了直接 INT8 量化训练不收敛的问题，并公开了 GELU→ReLU 替换及冻结 VAE 联合训练的流程。
- **推理系统完整性**：从量化方案、训练方法到基于 ggml 的 kernel 融合、SIMD 优化再到开源实现，形成了一个完整的端到端边缘 CPU 部署方案。
- **强实证性能**：在真实硬件上，仅用 3 个 CPU 线程即实现实时识别，并与业界常用框架 Whisper.cpp 进行了直接对比，展示了显著的速度优势。

## 8. 不足与局限
- **架构通用性未验证**：异构量化策略仅在 VibeVoice-ASR 上验证，是否适用于其他 VAE-LM 或 encoder-decoder 架构（如 Whisper、Qwen-Audio）尚是未知。
