## 摘要
近年来可控语音生成需要具有细粒度标注的训练数据，涵盖说话人特质、韵律、情感、副语言线索、声学场景和上下文。现有工作流通常依赖人工校正、付费托管多模态服务或固定处理链，这因标注成本、外部服务依赖或跨阶段恢复能力较弱而限制了大规模数据处理。我们提出 SpeechAnnotator，一个完全基于开源模型和工具构建的、可本地部署的上下文感知多智能体框架。支撑性前端模块首先获得说话人感知片段和最终片段转录，而先验证据提取器附加异构的片段级线索。随后，三个专门智能体通过共享状态协作：规划智能体将局部音频证据、说话人历史、相邻片段和录音级上下文转换为字段特定契约；标注智能体对可直接观测属性执行契约引导的多模态预测；审查智能体运行有界审查循环，检查证据支持和跨片段一致性，仅对缺乏支持或不一致的字段触发重新标注。为解决现有评测资源在孤立任务和窄领域测试集上的碎片化问题，我们引入 SpeechAnnotator-Bench（SA-Bench），包含 8.87 小时、覆盖九种来源格式的人工标注音频，以及 SpeechAnnotator-Eval（SA-Eval），后者分为用于说话人感知时间线恢复的 Timeline-Eval、用于有限集合属性的 Closed-Eval 和用于开放式属性的 Open-Eval。实验和消融研究表明，SpeechAnnotator 为商业音频能力系统提供了一种可本地部署的替代方案，同时有界审查循环通过证据和上下文感知的字段级恢复改进了多维标注。

## Abstract
Recent controllable speech generation requires training data with fine-grained annotations of speaker traits, prosody, emotion, paralinguistic cues, acoustic scenes, and context. Existing workflows often rely on manual correction, paid hosted multimodal services, or fixed processing chains, which limits large-scale data processing through annotation cost, external-service dependence, or weak cross-stage recovery. We introduce SpeechAnnotator, a locally deployable, context-aware multi-agent framework built entirely from open-source models and tools. Supporting frontend modules first obtain speaker-aware segments and final segment transcripts, while prior evidence extractors attach heterogeneous segment-level cues. Three specialist agents then collaborate through shared state: the Planning Agent converts local audio evidence, speaker history, neighboring segments, and recording-level context into field-specific contracts; the Labeling Agent performs contract-guided multimodal prediction for directly observable attributes; and the Review Agent runs a bounded review loop that checks evidence support and cross-segment consistency, triggering relabeling only for unsupported or inconsistent fields. To address the fragmentation of existing evaluation resources across isolated tasks and narrow-domain test sets, we introduce SpeechAnnotator-Bench (SA-Bench), containing 8.87 hours of human-annotated audio across nine source formats, together with SpeechAnnotator-Eval (SA-Eval), which separates Timeline-Eval for speaker-aware timeline recovery, Closed-Eval for finite-set attributes, and Open-Eval for open-ended attributes. Experiments and ablations show that SpeechAnnotator provides a locally deployable alternative to commercial audio-capable systems, while the bounded review loop improves multidimensional annotation through evidence- and context-aware field-level recovery.

## 2. 论文提出的方法论

### 2.1 总体框架

- **SpeechAnnotator** 是一个完全基于开源模型和工具的上下文感知多智能体框架，可本地部署。
- 整个流程分为四部分：前端模块、先验证据提取、多智能体标注、确定性输出处理。
- 所有中间产物（增强波形、说话人时间线、片段音频、最终转录、先验证据、字段契约、预测、审查记录、最终 JSON）都以 **segment key** 连接在共享状态中。

### 2.2 前端模块

- **FullSubNet**：语音增强，提高鲁棒分割和声学分析质量。
- **MOSS-Transcribe-Diarize**：估计说话人同质区间、说话人标识和初始转录。
- **Qwen3-Omni**：细化 MOSS 的初始转录。
- **片段表模块**：统一边界、说话人、片段音频和转录，形成规范记录。
- 在固定时间线评测设置下，使用参考边界、参考说话人和参考转录重建片段表，从而隔离属性标注与时间线误差。

### 2.3 先验证据提取器

- **DataSpeech**：估计音高、能量、响度、语速等声学统计量。
- **Emotion2vec**：在原始音频上提取情感表示。
- **声音事件检测（SED）**：提取非语音、背景声、场景线索。
- 这些异构证据按 segment key 附加到共享状态，供规划与标注使用。

### 2.4 三智能体协作与共享状态

- **Planning Agent（规划智能体）**：
  - 观察片段表、转录、先验证据、全局录音摘要、说话人历史、相邻片段。
  - 判断每个字段可采纳的证据、证据优先级、上下文范围和冲突呈现方式。
  - 写出轻量级 **字段特定契约（field-specific contract）**，记录标注目标、可采纳证据、上下文范围和冲突处理约束。
- **Labeling Agent（标注智能体）**：
  - 基于 Qwen3-Omni 实现，接收原始片段音频、转录、选定证据、允许的上下文和字段契约。
  - 对可直接观测属性输出初始预测。
- **Review Agent（审查智能体）**：
  - 基于 Qwen3.6-27B，受 AudioToolAgent 和 Audio-Mind 启发。
  - 验证预测是否有保留证据支持，并与说话人历史、相邻片段、相关字段一致。
  - 对不支持或不一致的字段，生成字段级重标注请求，仅重标注受影响字段，不重跑前端和无关证据提取。
  - 循环有上限（bounded revision budget），记录审计轨迹。

### 2.5 输出处理

- 确定性输出模块标准化说话人标识、规则化说话人级属性、规范化 schema 字段。
- 在审查后的状态下构建 caption 和 contextual inference，并序列化为最终 JSON。

### 2.6 基准与评测协议

- **SA-Bench**：8.87 小时、中文主导、九种来源格式的人工标注音频。
- **SA-Eval** 包含三部分：
  - **Timeline-Eval**：用 CER、cpCER、tcpCER 分别衡量词汇、说话人归属和时间对齐。
    - `cpCER` 在说话人置换中搜索最小错误率。
    - `tcpCER` 进一步加入字符时间戳约束，要求说话人一致且时间对齐有效。
  - **Closed-Eval**：对有限集合属性（perceived gender、perceived age）使用规范化精确匹配。
  - **Open-Eval**：对开放式自然语言属性，使用 Qwen3.6-27B 的 last-layer hidden states，按 attention mask 做 mean pooling，再 L2 归一化，最后用 clipped cosine similarity 评分。不引入生成式 judge 模型。

## 6. 论文的主要结论与发现

- **时间线恢复**：SpeechAnnotator 取得最低 CER（12.42%）和最低 tcpCER（33.69%），说明在说话人感知转录和时间对齐上具有竞争力；cpCER 为 28.16%，略高于 Qwen3.5-Omni-plus 的 26.31%。

- **最强字段**：在 tone、pitch、speed、rhythm、texture、pronunciation、paralinguistic cues 7 个字段上取得第一。
- **类别优势**：在 Prosody and Delivery 和 Voice Quality and Articulation 两个类别均排名第一。
- **消融贡献**：
  - 去掉 Review Loop 降低 0.85 点。
  - 去掉先验证据降低 1.20 点。
  - 去掉记录级和跨段上下文降低 1.48 点。
  - 表明上下文规划最重要，先验证据和审查循环也有稳定贡献。

  - Emotion 只有 62.85%，微弱或混合情感难以从局部韵律判断。
  - Perceived age 为 75.57%，远低于 Seed2.0 Lite 的 92.20%。

## 7. 优点

- **开源、本地可部署**：不依赖付费托管 API，适合大规模数据处理和隐私敏感场景。
- **有界审查循环**：只重标注不支持或不一致的字段，避免重跑整条管道，节省计算并保留审计轨迹。
- **字段级契约机制**：根据字段类型路由不同证据和上下文，兼顾声学、语义和跨段一致性。
- **统一基准设计**：SA-Bench 和 SA-Eval 将时间线恢复、封闭式属性和开放式语义属性放在同一 schema 下评测，避免任务碎片化。
- **确定性语义评估**：Open-Eval 使用冻结 hidden states 和 cosine similarity，不引入生成式 judge 模型，减少评估随机性和模型偏差。
- **实验公平性**：固定时间线设置隔离了转录/归因误差；消融实验干预变量清晰。

## 8. 不足与局限

- **领域和语言覆盖有限**：基准以中文主导音频为主，未证明跨语言、跨文化场景的泛化能力。
- **客观性/场景字段表现弱**：environment、background

等声学场景字段的预测明显受限于短片段中稀疏的非语音线索，且容易被转录语义主导；emotion 与 perceived age 等需要更强先验知识或长期上下文建模的字段也表现不佳，反映出多智能体证据路由对这类高度抽象属性的增益有限。  
- **评估协议的同源偏差风险**：Open-Eval 使用 Qwen3.6-27B 的隐藏状态作为语义相似度度量，虽然避免了生成式 judge 的随机性，但评估模型与标注/审查智能体共享同一底座，可能对系统自身的输出模式更宽容，影响评分的客观性。  
- **对比基线可能未达到最优**：黑盒商业系统被要求一次性输出全部片段字段，未针对迭代修正或长上下文推理进行专门提示工程，因此其分数可能低估了商业系统的真实能力。  
- **基准多样性与规模有限**：SA-Bench 仅包含 8.87 小时、中文主导音频，场景和说话人类型覆盖有限，缺少多语言、多方言、强噪声、远场等复杂条件，外部效度仍需验证。  
- **资源透明度不足**：论文未报告推理耗时、显存峰值、每百小时处理成本或失败重试率，无法定量支持“本地部署比付费 API 更具成本优势”的论断，也难以为实际部署提供容量规划依据。  
- **统计严谨性可加强**：实验虽然报告了 5 次运行的均值±标准差，但没有进行显著性检验或置信区间分析，难以判断与商业系统间的分数差异是否具有统计意义。

总体而言，SpeechAnnotator 在固定时间线的属性标注上与头部商业系统接近，并在多个韵律、音质字段上取得领先，证明了开源多智能体 + 先验证据路由的可行性；但声学场景、情感和年龄等需要更强世界知识或长程建模的字段仍是短板，且资源与成本透明度不足限制了其实际部署价值的评估。
