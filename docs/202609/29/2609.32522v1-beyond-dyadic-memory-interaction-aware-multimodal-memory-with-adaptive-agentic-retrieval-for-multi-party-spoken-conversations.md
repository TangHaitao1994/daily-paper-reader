## 摘要
长期记忆使智能体能够跨会话积累信息并进行推理，但现有研究主要关注二元文本或图文对话，对多方语音对话中的长期记忆探索不足。该场景要求保留对话内容、跨会话识别参与者，并记录谁对谁说话。为此，我们提出VoxPolyMem，一个交互感知的多模态记忆框架，将增量说话人识别与包含交互记忆、事实记忆和参与者画像的记忆层级相结合。我们将检索形式化为序贯决策，智能体基于累积证据改写查询并选择检索工具和记忆层级，以填补信息空白。我们进一步引入证据增益GRPO（EG-GRPO），利用逐轮信用分配鼓励互补性证据获取。我们还构建了VoxPolyBench，用于评估多方语音对话中的记忆演化、个性化回答、记忆检索与推理，以及交互推理与归属。VoxPolyMem在VoxPolyBench上取得了85.0的总体得分，比最强的评估基线高出23.6分。在Mem-Gallery和H2HMem-Multi上，其得分分别为89.6和74.4，均比最强的公开记忆基线高出超过8分。这些结果凸显了其在多方多模态交互中提供持续、个性化辅助的潜力。代码和数据集可在 https://voxpolymem.github.io/VoxPolyBench/demo/ 获取。

## Abstract
Long-term memory enables agents to accumulate information and reason across sessions, yet existing research primarily focuses on dyadic text or image-text conversations, leaving long-term memory for multi-party spoken conversations underexplored. This setting requires preserving conversational content, identifying participants across sessions, and retaining who speaks to whom. To this end, we propose VoxPolyMem, an interaction-aware multimodal memory framework combining incremental speaker identification with a memory hierarchy comprising interaction memory, fact memory, and participant profiles. We formulate retrieval as sequential decision-making, where an agent rewrites queries and selects retrieval tools and memory layers based on accumulated evidence to address information gaps. We further introduce Evidence-Gain GRPO (EG-GRPO), which uses round-wise credit assignment to encourage complementary evidence acquisition. We also construct VoxPolyBench to evaluate memory evolution, personalized answering, memory retrieval and reasoning, and interaction reasoning and attribution in multi-party spoken conversations. VoxPolyMem achieves an overall score of 85.0 on VoxPolyBench, surpassing the strongest evaluated baseline by 23.6 points. On Mem-Gallery and H2HMem-Multi, it scores 89.6 and 74.4, respectively, exceeding the strongest evaluated public memory baselines by over 8 points each. These results highlight its potential for persistent, personalized assistance in multi-party multimodal interactions. Code and datasets are available at https://voxpolymem.github.io/VoxPolyBench/demo/

## 2. 论文提出的方法论

### 2.1 总体框架
VoxPolyMem 由三部分组成：输入处理与说话人识别 → 交互感知记忆构建 → 智能体记忆检索与回答。

### 2.2 在线说话人识别
- 使用 **ECAPA-TDNN** 提取每段音频的声纹嵌入，并进行 L2 归一化。
- **增量身份匹配**：将当前语音与已有匿名说话人声纹比较，若余弦相似度超过阈值 \( \tau_{\text{match}} \)，则归入已有 ID；否则创建新 ID。
- **置信门控 EMA 更新**：只有当相似度超过更高阈值 \( \tau_{\text{update}} \) 时，才用指数移动平均更新声纹，避免不确定匹配污染声纹。
- **身份调和**：会话结束后，基于累积声纹证据保守合并因声学变化而产生的碎片化 ID，无需预先知道说话人数量。

### 2.3 交互感知的多模态分层记忆
论文构建三类记忆：

- **交互记忆 \( M_{\text{int}} \)**：以**有向图**形式保存每条消息及其说话人、受话人、时间、文本、图像等信息。边包括“说话人 → 消息”和“消息 → 受话人”。
- **事实记忆 \( M_{\text{fact}} \)**：存储自包含事实，字段包括内容、说话人、受话人、时间，并保留指回原始对话轮次的 `refer_id`。
- **参与者画像 \( M_{\text{prof}} \)**：存储姓名、别名、关联声纹嵌入、背景与偏好等信息。

- 使用 LLM 基于当前轮及前 3 轮上下文，**联合提取事实、参与者属性、受话人和时间信息**，并将匿名说话人 ID 与真实姓名/别名关联。

### 2.4 可训练的自适应检索智能体
检索被形式化为**序贯决策过程**：

- 状态 \( s_t \)：查询、提问者身份、已保留证据、动作历史、剩余预算。
- 动作 \( a_t \)：选择记忆层（交互/事实/画像）、检索工具、改写后的查询、可选说话人/受话人过滤条件。
- 工具包括：向量检索、BM25 文本检索、文本到图像检索、图像到图像检索。
- 使用 **RRF 融合、去重、上下文选择**更新留存证据；LLM 判断是否证据足够或最多执行 3 轮检索。

### 2.5 Evidence-Gain GRPO（EG-GRPO）
- 奖励设计为**逐轮证据增益**：只奖励**新获取并保留在上下文中的支持证据**，此前已保留的支持证据不再重复计分。
- 奖励由两部分组成：
  - **覆盖率项**：新支持 ID 数占全部支持 ID 的比例；
  - **排序项**：按记忆在上下文中的排名进行折扣，鼓励关键证据排在前列。
- 每个状态采样 \( K=8 \) 个候选动作形成 GRPO 组，按组内均值和标准差计算 advantage。
- 训练时仅更新“层选择、工具选择、查询改写、过滤条件”的动作 token；答案模型固定。
- 训练需要支持轮次标注作为监督，推理时不可用。

- **主结果领先明显**：

- **组件贡献明确**：
  - 删除事实记忆和参与者画像导致所有基准下降；
  - 删除交互关系对 VoxPolyBench 影响最大；
  - 单轮检索下降明显，说明多轮检索比查询改写的作用更关键。
- **EG-GRPO 优于其他策略优化方法**：
  - 在三个基准上得分和召回均领先；
  - 平均检索轮数更低（1.2–1.3 轮，对比 w/o RL 的 1.6–1.7 轮）。
- **说话人识别具备跨数据集迁移能力**：在 IEMOCAP 上达到 95.0%，在 AMI 上达到 87.9%。
