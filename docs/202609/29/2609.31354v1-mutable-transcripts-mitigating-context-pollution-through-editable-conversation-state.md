## 摘要
当代大语言模型（LLM）聊天系统将对话历史视为不可变的轮次序列，该序列定义了模型的工作上下文。然而，真实交互中的用户意图并非静态：它会通过纠正、细化和约束变化而演变。这种动态意图与静态对话记录之间的不匹配可能导致上下文污染，即过时或无关的信息持续存在并继续影响后续回复。我们提出可变对话记录（mutable transcripts），这是一种新的交互范式，使用户能够通过自然语言编辑请求修改先前的轮次，从而使对话历史本身可以被更新而不是仅被追加。这将对话记录从被动记录重构为对话状态的可编辑表示。我们展示了一个工作原型，将记录级修订集成到标准聊天界面中，并通过一项受控用户研究（n=17）以及对代表性交互场景的说明性记录分析评估其可行性。参与者在清晰度、信心和易用性方面显著偏好可变对话记录而非标准聊天，并且重新开始对话的意愿降低。对代表性用户研究对话的记录分析表明，可变对话记录能够缩短对话长度并消除过时的保留上下文。这些发现提供了初步证据，表明用户驱动的对话历史修订可以改善交互质量，并有助于维持更当前的用户意图表示。源代码和原型可在 https://github.com/QxLabIreland/ReChat 获取。

## Abstract
Contemporary large language model (LLM) chat systems treat conversation history as an immutable sequence of turns that defines the model's working context. However, user intent in real interactions is not static: it evolves through correction, refinement, and shifting constraints. This mismatch between dynamic intent and static transcripts can result in context pollution, where outdated or irrelevant information persists and continues to influence subsequent responses. We introduce mutable transcripts, a new interaction paradigm that enables users to revise prior turns through natural language edit requests, allowing the conversation history itself to be updated rather than appended. This reframes the transcript from a passive record into an editable representation of conversational state. We present a working prototype that integrates transcript-level revision into a standard chat interface and evaluate its feasibility through a controlled user study (n=17) and an illustrative transcript analysis of representative interaction scenarios. Participants significantly preferred mutable transcripts over standard chat across measures of clarity, confidence, and ease of use, with reduced intent to restart conversations. Transcript analysis of representative user study conversations shows that mutable transcripts can reduce conversation length and eliminate obsolete retained context. These findings provide initial evidence that user-driven revision of conversational history can improve interaction quality and help maintain a more current representation of user intent. The source code and prototype can be accessed at https://github.com/QxLabIreland/ReChat

## 1. 论文的核心问题与整体含义

- **研究背景**：当前主流 LLM 聊天系统（如 ChatGPT、Gemini 等）将对话历史视为“不可变序列”，每次新提问都会把完整历史作为上下文发给模型。  
- **核心矛盾**：真实用户意图是动态演进的——用户会纠正错误、调整约束、改变方向，但系统只允许“追加”新轮次，无法真正修改或删除已经存在的历史信息。  
- **问题表现**：过时、矛盾或不再相关的信息会持续残留在上下文中，形成“上下文污染（context pollution）”，继续误导模型后续回复。  
- **研究动机**：现有方案（上下文截断、自动摘要、检索增强记忆等）大多是“系统驱动”的优化，用户缺少直接、可控的机制使对话状态与当前意图保持一致。  
- **论文含义**：提出“可变对话记录（mutable transcripts）”这一新交互范式，把对话记录从“被动日志”转变为“可编辑的对话状态表示”，允许用户用自然语言直接修订历史，从而缓解上下文污染，提升长对话的连贯性和用户信心。

## 2. 论文提出的方法论

- **核心思想**：  
  - 将对话历史视为可编辑的状态，而不是只读的日志。  
  - 用户通过自然语言编辑指令（edit request）对完整历史进行修订，系统据此重写对话记录，使过时或矛盾信息被删除或更新。  
  - 保持传统聊天界面隐喻，仅新增“Edit History”模式选择器，降低交互摩擦。

- **形式化定义**：  
  - 可变对话记录可表示为函数 \( T' = f(T, e) \)，其中 \( T \) 是原始对话记录，\( e \) 是自然语言编辑指令，\( T' \) 是修订后的对话记录。

  - 默认模式下，用户输入被追加到现有记录，完整历史发送给模型生成回复。  
  - 在“Edit History”模式下，用户输入被解释为编辑指令，系统构造包含完整历史和修改说明的 prompt，调用 LLM 生成修订后的完整对话记录，然后用新记录替换原记录并重新渲染界面。

## 3. 实验设计

- **研究类型**：受控用户研究（controlled user study） + 说明性对话记录分析（illustrative transcript analysis）。  
- **参与者**：n = 17，自愿参加，无补偿；15/17 为研究或软件开发领域的技术专业人员。研究获伦理审查批准，参与者签署知情同意。  
- **任务场景**：三个代表性任务，分别对应三类转录级操作：  
  1. 追溯纠正（Retroactive Correction）  
  2. 约束注入（Constraint Injection）  
  3. 上下文修剪（Context Pruning）  
- **实验条件**：  
  - Condition A：标准聊天界面（不可变历史）。  
  - Condition B：可变对话记录界面（带“Edit History”模式）。  
- **实验设计**：  
  - 采用反平衡的受试者内设计（counterbalanced within-subjects design）：10 人 A→B，7 人 B→A，以控制顺序效应。  
  - 每个参与者对每个任务分别在两种条件下完成操作，并回答五个 Likert 量表问题（1-7 分）。  
- **评估指标**：  
  1. **Transcript Cleanliness**（记录清洁度，是否无过时信息误导后续回复）  
  2. **State Clarity**（状态清晰度，是否容易理解当前生效的假设/约束）  
  3. **Confidence**（信心，是否相信聊天机器人会持续遵循更新后的约束）  
  4. **Restart Intent**（重启意图，愿意重新开始对话而非继续的可能性；分数越低越好）  
  5. **Ease of Use**（易用性，应用修正是否容易）  
- **对比方法**：  
  - 主要对比是“标准聊天（append-only）”与“可变对话记录（mutable transcripts）”。  
  - 没有与分支式编辑（branching，如 ChatGPT/Claude 的编辑分支）、自动摘要、检索增强等基线方法做直接实证比较。论文明确表示这些是未来工作。  
- **记录分析（Transcript Analysis）**：

  - 记录清洁度更高，过时信息更少。

  - 易用性更好，修正操作更便捷。

- **记录结构分析**：  
  - 可变对话记录平均将轮次从 8 减少到 4（-50%），总 token 从 581 减少到 238（-59%）。

- **总体结论**：用户驱动的对话历史修订是一种有前景的交互方向，可以改善人机交互质量，帮助保持更当前的用户意图表示，并减少上下文污染。

## 8. 不足与局限

- **样本与人群偏差**：n=17 且大多数为技术专业人员，结果可能无法推广到普通用户或非技术场景。

- **客观评估不足**：主要依赖自我报告 Likert 量表，缺乏任务成功率、响应质量、长期记忆等客观指标；记录分析仅 3 对示例，不能提供统计上的一般化结论。

- **安全与信任问题**：可编辑历史可能被恶意利用进行提示注入、追溯篡改，并让用户难以追踪模型行为变化的原因；论文未提出具体防护方案。

- **适用性限制**：在需要不可变记录的场景（如法律、审计敏感领域）可能不适用；论文承认该范式不适合所有对话场景。
