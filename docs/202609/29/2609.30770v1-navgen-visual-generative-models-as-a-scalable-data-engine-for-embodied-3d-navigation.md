## 摘要
通用机器人模型越来越依赖大规模、多样化的数据集。然而，对于具身三维导航，现有数据源面临一个根本性权衡：仿真数据能够大规模生成，但往往存在视觉上的仿真到真实差距；真实世界飞行数据能提供逼真观测，但采集成本高昂。本文研究另一条路径：利用高保真视觉生成模型作为具身三维导航的可扩展数据引擎。我们提出了 NavGen，一种文本到视频的数据生成流程，可生成室内外场景中多样化的视觉语言导航（VLN）片段。我们还提出了一种风格多样化方法，可扩展难以且成本高昂采集的长尾数据。由此得到的数据集包含约 40 万个导航片段。我们在多个指标上将我们的数据集与现有无人机导航数据集进行评估，发现基于我们的数据训练的模型通常随规模提升，优于基于现有数据集训练的模型。为验证真实世界可迁移性，我们在世界-动作模型范式下将训练好的模型部署到真实飞行实验中。最终模型在不同导航任务和环境中达到 75% 的成功率。

## Abstract
General-purpose robot models increasingly rely on large and diverse datasets. For embodied 3D navigation, however, existing data sources face a fundamental trade-off: simulated data can be generated at scale but often suffer from the visual sim-to-real gap, whereas real-world flight data provide realistic observations but are costly to collect. This paper studies another direction: the use of high-fidelity visual generative models as scalable data engines for embodied 3D navigation. We introduce NavGen, a text-to-video data generation pipeline that produces diverse vision-language navigation (VLN) episodes across indoor and outdoor scenes. We also propose a style-diversification method that scales up long-tail data that are difficult and costly to collect. The resulting dataset contains approximately 400K navigation episodes. We evaluate our dataset against existing UAV navigation datasets across multiple metrics, and find that the model trained on our data generally improves with scale, outperforming those trained on existing datasets. To validate real-world transferability, we deploy the trained model in world-action-model paradigm to real-world flying experiments. The final model achieves a 75\% success rate across different navigation tasks and environments.

## 2. 论文提出的方法论

### 2.1 多样化文本到视频生成（300K 常见任务样本）

- 从一个包含 100 万对象的数据库（Cap3D）中筛选出 30 万个目标对象，保证对象级多样性。
- 将样本分配到预定义的运动类别，保持运动分布均衡。
- 使用 **Qwen3.6-27B** 作为具身导航专家，围绕目标对象生成详细的导航事件描述，包括环境风格、背景物体、空间布局等。
- 用开源的 **Wan2.2 14B T2V** 模型以四步扩散生成视频，每个样本在 A100 上约需 36 秒。

### 2.2 运动重平衡与风格多样化

- **运动重平衡**：
  - 生成模型可能不严格遵循提示，导致运动分布偏差。
  - 使用 **Pi3** 解码视频的整体运动方向并赋予运动标签。
  - 识别左右不平衡（用水平镜像修正）和前后不平衡（用时间反转修正），无需额外生成即可改善分布均衡。
- **风格多样化（长尾数据扩展）**：
  - 对难以生成的长尾任务（如穿过狭窄空间、绕目标飞行），使用能力更强的闭源模型 **Seedance API** 生成 10K 高质量样本。
  - 提取每个视频的首帧，用 **Qwen3.6-27B** 生成风格多样化描述（保留主体形状、改变周围物体和环境风格）。
  - 用 **Qwen-Image-Edit** 编辑首帧；用 **MoGe-2** 将原始视频转换为深度视频提供结构引导；用 **LTX-2.3 ICLoraPipeline** 基于参考视频生成新视频。
  - 最终将 10K 长尾样本扩展为 100K。

### 2.3 视频过滤与描述

- 自动评估管线过滤：丢弃 **VBench** 分数低于阈值或导航等级低于 L2 的样本，并从新采样的描述重新生成。
- 重新标注：将生成视频均匀下采样到 11 帧，输入 **Qwen3.6-27B** 生成视频级事件描述；额外提供 Pi3 解码的整体运动方向作为运动线索，提高描述质量。

### 2.4 训练系统设计

- 采用 **NavDreamer** 的视频预测与动作解码范式，基座模型为轻量 **Wan2.2 5B**。
- **双向长视频生成（Clean-Prefix History Conditioning）**：
  - 训练时随机将前 k 个潜在 token 替换为干净的真实观测，k 从均匀分布采样；k=1 对应图像到视频（I2V），k>1 对应视频到视频（V2V）。
  - 被替换的 token 不参与损失，其余 token 在双向注意力下进行去噪；对历史帧施加少量噪声增强，防止过度依赖完美前缀。
- **监督微调（SFT）**：使用 flow matching 目标，预测速度场 \(u_t = \epsilon - z_0\)；先在 640×384 分辨率、33 帧的稀疏视频上训练。
- **步骤蒸馏**：
  - 先以简化连续时间一致性模型（sCM）预热 2.5K 步；
  - 再使用 DMD2 风格的分布匹配蒸馏，结合对抗损失（GAN loss）提升视觉质量；
  - 最终将去噪步数从 30 步降至 4 步，并移除无分类器引导（CFG）。
- **轻量 VAE**：替换标准 VAE，将编码+解码时间从约 1 秒降至约 0.1 秒。
- 推理优化后单段视频生成仅需 0.7 秒，对应 **47 FPS**。
