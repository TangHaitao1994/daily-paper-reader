## 摘要
串联语音到语音架构将响应式语音前端与异步文本后端耦合。在 KAME 中，大语言模型（LLM）作为后端，在用户仍在说话时向语音前端提供候选响应作为引导。普通对话录音捕获最终响应，但不会捕获后端在用户话语期间本应提供的引导。用模拟器 LLM 生成缺失引导会在真实对话上训练时增加大量数据准备开销。我们提出随机化中间引导，它直接从对话语料库派生引导，而不是模拟后端 LLM 的行为。在训练期间，目标响应提供信息性引导，而随机采样的响应在话语期间提供可能不相关的更新。这种组合旨在教会前端选择性地使用后端信息。在合成对话上，用此方法训练的 KAME 达到了与 LLM 生成的和基于相似性的基线相当的响应质量。在 3.8k 小时真实对话上训练，与合成数据 KAME 相比改善了流畅的话轮转换和音频评判自然度，同时保持了对 Moshi 的响应质量优势。这些结果表明，随机化引导提供了一条实用途径，可将串联模型的响应质量优势与从真实语音中学到的自然对话行为结合起来。

## Abstract
Tandem speech-to-speech architectures couple a responsive speech frontend with an asynchronous text backend. In KAME, a large language model (LLM) serves as the backend, supplying candidate responses as guidance to the speech frontend while the user is still speaking. Ordinary conversation recordings capture the eventual response but not the guidance the backend would supply during the user's utterance. Generating the missing guidance with a simulator LLM adds substantial data-preparation overhead when training on real conversations. We propose randomized intermediate guidance, which derives guidance directly from the conversation corpus rather than simulating backend LLM behavior. During training, target responses provide informative guidance, while randomly sampled responses provide potentially irrelevant updates during the utterance. This combination aims to teach the frontend to use backend information selectively. On synthetic dialogues, KAME trained with this recipe achieves response quality comparable to that of the LLM-generated and similarity-based baselines. Training on 3.8k hours of real conversations improves smooth turn-taking and audio-judge naturalness over synthetic-data KAME while retaining a response-quality advantage over Moshi. These results show that randomized guidance offers a practical route to combining the response-quality benefits of tandem models with natural conversational behavior learned from real speech.

## 1. 论文的核心问题与整体含义

- **研究背景**：实时口语对话系统需要在“高质量响应”与“自然交互”之间取得平衡。
  - 全双工语音到语音（S2S）模型（如 Moshi）支持低延迟、灵活的话轮转换，但知识与推理能力有限。
  - 级联系统（ASR → LLM → TTS）能利用强大文本 LLM，但顺序流水线引入延迟，破坏对话流畅性。
- **核心问题**：串联（tandem）架构将响应式语音前端与异步文本后端耦合，例如 KAME 在用户说话时由后端 LLM 周期性提供候选响应作为“引导”。但普通对话数据只包含用户话语和最终响应，**不包含后端在用户说话期间应提供的中间引导**。
- **现有解决方案的瓶颈**：KAME 使用模拟器 LLM 生成逐步收敛到目标响应的引导流，但**每一条训练数据都需要一次 LLM 模拟**，在扩展到大规真实对话语料时成为数据准备瓶颈，阻碍了利用真实语音学习自然对话行为。
- **整体含义**：本文提出一种无需 LLM 模拟的引导构造方法，使 tandem S2S 模型能够直接在大规模真实对话上训练，从而同时获得高质量响应与自然对话行为。

## 2. 论文提出的方法论

### 核心思想
- 用**随机化中间引导**替代模拟器 LLM 生成的引导：训练时引导流由“信息性目标响应”和“可能不相关的随机响应”混合构成，训练前端模型**区分并选择性利用有用信息**。

### 关键技术细节
- **KAME 背景**：推理时异步 LLM 以 2 Hz 频率根据部分用户输入生成候选响应，称为“引导流”（原论文称“oracle stream”）。
- **原 KAME 的 LLM 生成引导**：模拟器 LLM 在用户话语的不同完成度下，生成从初步估计逐渐语义接近目标转录 y 的序列，最终以 y 结束。
- **随机化中间引导（本文方法）**：
  - 对每个响应片段，**最后一个目标响应更新位置保留目标转录 y**（信息性引导）。
  - 其余引导位置用**从训练语料库随机采样**的响应文本填充（潜在不相关引导）。
  - 采样规则：
    - 建立响应文本池，按 token 序列去重；
    - 排除当前对话中出现的所有响应文本；
    - 仅保留长度在目标 y 的 **0.5～2 倍**之间的候选；
    - 每个片段按需无放回均匀采样。
- **真实对话应用**：
  - 使用 Silero VAD 检测语音区域；
  - 使用 pyannote speaker-diarization-3.1 做说话人分离；
  - 去除多说话人/重叠片段，用 Sidon 增强，DNSMOS P.835 过滤（OVRL ≥ 3.0）；
  - 使用 faster-whisper large-v3-turbo 转录并获取 token 级时间戳；
  - 按语言概率 ≥ 0.85、平均对数概率 ≥ −0.4 过滤转录；
  - 同一录音同一通道、恰好两个说话人的片段按时间顺序拼接，构成对话样本；
  - 目标转录同时作为训练目标和目标响应引导，其他响应文本从其他轮次采样作为随机中间引导。

## 6. 论文的主要结论与发现

- **响应质量**：随机化引导在 spoken MT-Bench 上达到 6.09，与 Similarity-based（6.14）、LLM-generated（5.54）相当，显著优于 Target-only（5.12）。说明加入“不相关引导”有助于训练模型选择性使用后端信息。
- **真实数据训练收益**：在 3.8k 小时真实对话上训练的 KAME：
  - 音频自然度从合成数据 KAME 的 4.05 提升到 4.79，接近 Moshi 的 5.29；
  - 平滑话轮转换成功率从 40.62% 提升到 50.88%；

  - 响应质量 MT-Bench 为 5.04，仍远高于 Moshi 的 1.96，但略低于合成数据 KAME 的 5.54。
- **核心结论**：随机化中间引导提供了一条**实用、可扩展**的路径，使 tandem S2S 模型能直接从真实对话中学习自然对话行为，同时保留对全双工基线（Moshi）的响应质量优势。

## 7. 优点

- **方法简单、成本低**：完全避免每例 LLM 模拟，可直接从语料库构造引导，适合大规模数据训练。
- **负采样思想巧妙**：用随机不相关响应充当负样本，鼓励前端模型不盲从引导，只有信息相关时才利用。
- **数据利用创新**：首次将真实对话大规模用于 tandem 架构训练，弥补了合成数据在自然交互上的不足。
- **评估维度全面**：同时考察响应质量、对话行为（话轮转换、打断、停顿）和语音自然度，而不仅看内容质量。
- **对比公平**：统一预训练模型、推理后端和评估协议，增强了结果的可信度。
