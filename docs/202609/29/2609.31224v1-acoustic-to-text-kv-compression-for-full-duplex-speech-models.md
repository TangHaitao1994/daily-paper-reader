## 摘要
全双工语音语言模型会持续累积声学键值（KV）状态，使长时间交互内存开销很大。在监听期间，模型可以在下一个音频单元到达前处理完当前单元；我们将该剩余时间间隔称为监听时间余量。我们提出声学到文本 KV 压缩，通过引入转录侧信道在该间隔内将输入语音转换为紧凑的文本记忆。在推理时当缓存超过目标预算时，较早的声学状态被逐出，而转录文本与近期的声学上下文保留。我们使用 LoRA 在转录片段上以交叉熵训练该侧信道。为保留监听与说话行为，我们对原始模型在原生预测位置上的 token 级输出分布应用知识蒸馏。在十分钟的 LongSpeech 会话上，与不进行逐出的同一模型相比，我们的 MiniCPM-o 4.5 实现将峰值流式 KV 缓存大小降低了 64.6%。所提方法在转录、时间问答和摘要上也优于基线。Full-Duplex-Bench 评估进一步显示其停顿处理、话轮转换和打断性能具有可比性。

## Abstract
Full-duplex speech language models continuously accumulate acoustic key-value (KV) states, making long-running interactions memory-intensive. During listening, the model can finish processing an audio unit before the next arrives; we term the remaining interval listening-time slack. We propose acoustic-to-text KV compression, which introduces a transcription side channel to convert incoming speech into compact textual memory within this interval. When the cache exceeds a target budget during inference, older acoustic states are evicted while transcripts and recent acoustic context remain. We train the side channel with LoRA using cross-entropy on transcription segments. To preserve listening and speaking behavior, we apply knowledge distillation to the original model's token-level output distributions at native prediction positions. On ten-minute LongSpeech sessions, our MiniCPM-o 4.5 implementation reduces peak streaming KV-cache size by 64.6% compared with the same model without eviction. The proposed method also improves transcription, temporal question answering, and summarization over the baseline. Full-Duplex-Bench evaluations further show comparable pause-handling, turn-taking, and interruption performance.

## 1. 论文的核心问题与整体含义

- **研究背景**：全双工语音语言模型（full-duplex speech language models）需要在持续听音的同时生成回复，长时间交互会不断累积声学表示的 key–value（KV）状态。
- **核心矛盾**：语音的声学表示比文本占用更多序列位置，因此长期语音交互会导致 KV 缓存持续膨胀，峰值显存占用高；而只在输入完成后再压缩，无法降低流式处理过程中已经产生的峰值内存。
- **研究动机**：需要在流式处理过程中主动控制 KV 缓存峰值，同时保留过去语音中的有效信息，并维持实时听、说与打断能力。
- **整体含义**：本文提出一种“边听边转写、边压缩声学缓存”的方法，把早期语音内容压缩为文本记忆，从而在保持交互性能的同时显著降低长时语音任务的内存开销。

## 2. 方法论

- **核心思想**：利用全双工语音模型在监听期间的“时间余量”（listening-time slack），引入一个**转录侧信道**，把输入语音增量转写为紧凑的文本记忆。当 KV 缓存超过预算时，逐出较旧的声学状态，但保留转录文本和近期声学上下文。

- **关键技术细节**：
  - 基础模型为 MiniCPM-o 4.5，以 1 秒为一个 duplex unit 处理语音。
  - 每个 unit 中，在原生 `<|listen|>` 或 `<|speak|>` 决策之后，插入由 `<|asr start|>` 和 `<|asr end|>` 包裹的转录片段。
  - 转录片段保留在语言模型上下文中，但**不进入语音解码器输入，也不作为 spoken output**。
  - 推理时，模型自行预测是否打开侧信道；若预测 `<|asr start|>`，则贪心解码最多 64 个文本 token，直到 `<|asr end|>` 或控制 token 出现。
  - 声学状态逐出策略：当 KV 位置超过预算 \(B\)（主实验为 4K）时，从最旧 unit 开始逐出声学和结构 KV 状态，但**保护最近 5 个 unit 的 retention window**，以容纳转写延迟。
  - 保留内容：transcript tokens、模型生成的回复文本、系统前缀；逐出内容：unit marker、audio tokens、native decision、ASR 分隔符等。
  - Position IDs 继续递增，即使发生逐出，剩余 key 仍保留原始 rotary position，无需重新编码。

- **训练方案**：
  - 使用 LoRA（rank 16, α=32）微调注意力层和前馈层，新增 43.7M 参数，占语言模型的 0.53%。
  - 转写监督：使用 Montreal Forced Aligner 的词级对齐，结合 0.5 秒 emission delay 构造目标转录片段。
  - 行为保持：将原始冻结模型作为 teacher，在原生预测位置计算 token 级 KL 散度，避免转录训练破坏原生的听、说与话轮行为。
  - 总损失函数为：
    \[
    L = L_{ASR} + L_{native} + L_{dec} + L_{turn}
    \]
    其中：
    - \(L_{ASR}\)：转录 token 及分隔符的 masked cross-entropy；
    - \(L_{native}\)：所有有效的原生预测位置上的 KL 散度平均；
    - \(L_{dec}\)：按 listen / speak / other 分组后重新加权的第一决策位置损失；
    - \(L_{turn}\)：按 turn-end / turn-continuation 分组的损失，强调话轮边界。
  - 训练数据仅为短转写语音，不需要长时语音或全双工交互数据。

## 6. 主要结论与发现

- 在 MiniCPM-o 4.5 上，本文方法将十分钟流式任务的**峰值 KV 缓存从 11.35K 降至 4.02K**，相对无逐出版本减少 **64.6%**。
- 相比原生流式基线，本文方法显著降低 WER：**12.9 vs 96.9**；时间问答准确率从 30% 提升到 **42%**；摘要 BLEU 从 2.7 提升到 **11.01**，ROUGE-1 从 27.3 提升到 **49.0**。
- 与外部 ASR cascade 相比，本文方法在时间 QA 和摘要上具有可比性，且**不需要独立 ASR 模型**。
- Full-Duplex-Bench 结果显示，停顿处理、话轮转换和打断性能与基线基本相当；但没有蒸馏的版本会严重破坏交互行为，例如几乎每轮都抢话、提前开口。
- 4K budget 下，平均单 unit 处理时间 461 ms，未出现 deadline miss，证明方法可以实时运行。

## 7. 优点

- **巧妙利用监听时间余量**：将原本空闲的计算时间用于增量转写，不额外引入独立 ASR 服务。
- **记忆表示极紧凑**：文本记录约每秒 3 个序列位置，而声学历史约 17 个，压缩效率高。
- **兼顾记忆压缩与行为保持**：通过 token 级知识蒸馏和分组平衡损失，在引入新能力的同时尽量保留原生全双工交互行为。
- **工程可落地性强**：LoRA 微调参数量小，仅 0.53% 的语言模型参数；推理在同一骨干网络中完成。
- **实验证据充分**：同时评估了长时理解、KV 压缩、实时延迟和交互行为，并有预算消融与蒸馏消融。
- **无需长时全双工训练数据**：只用短转写语音即可实现十分钟级别任务，训练成本相对较低。

## 8. 不足与局限

- **模型单一**：只在 MiniCPM-o 4.5 上验证，换用其他全双工模型时效果未知。
- **语言与场景覆盖有限**：训练和评估主要基于英语 LibriSpeech / LongSpeech，未覆盖多语言、方言、噪声、重口音或多人交替场景。
- **转写误差风险**：转写文本作为长期记忆，其错误可能累积并影响后续问答或摘要；WER 距离大型 ASR 仍有差距。
- **预算选择依赖经验**：4K KV budget 和 5 unit retention window 是否适用于不同语速、不同设备或更长会话仍需验证。
