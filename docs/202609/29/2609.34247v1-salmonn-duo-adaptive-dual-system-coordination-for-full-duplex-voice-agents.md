## 摘要
全双工语音大语言模型（LLMs）支持低延迟、自然的语音交互。然而，现实世界中的智能体还必须使用工具并执行审慎推理——这些操作的可变延迟和计算成本与实时对话严格的时序要求相冲突。为了调和这些需求，我们提出了 SALMONN-duo，一种受认知双过程理论启发的自适应双系统语音智能体。SALMONN-duo 通过将一个始终在线、快速思考的全双工语音 LLM（系统1）与一个强大的异步慢速思考 LLM 智能体（系统2）配对，将实时交互与审慎计算分离。除了处理实时交互外，系统1学习何时直接回答、何时委托，在后端执行期间保持响应，并将返回的信息无缝整合到正在进行的对话中，而不会暴露工具痕迹或丢失对话上下文。在单轮口语问答（QA）和多轮对话上的评估表明，自适应委托显著提高了知识密集型和多跳推理问题的准确率，而知识边界感知训练避免了不必要的系统2调用。在 τ-Voice 的定制版本上，SALMONN-duo 进一步展示了其在现实业务场景中通过多轮交互完成基于环境、受策略约束的任务的能力。最后，成本感知强化学习进一步增强了在问答和对话任务中任务性能与后端使用之间的权衡，同时在 τ-Voice 上提高了任务成功率和响应安全性，且委托率的增加在可接受范围内。

## Abstract
Full-duplex speech large language models (LLMs) enable low-latency, natural voice interaction. However, real-world agents must also use tools and perform deliberative reasoning-operations whose variable latency and computational cost conflict with the stringent timing requirements of real-time conversation. To reconcile these demands, we propose SALMONN-duo, an adaptive dual-system voice agent inspired by dual-process theories of cognition. SALMONN-duo separates real-time interaction from deliberative computation by pairing an always-on, fast-thinking full-duplex speech LLM (system 1) with a powerful asynchronous slow-thinking LLM agent (system 2). Beyond handling real-time interaction, system 1 learns when to answer directly and when to delegate, remaining responsive during backend execution and seamlessly integrating returned information into the ongoing dialogue without exposing tool traces or losing conversational context. Evaluations on single-turn spoken question answering (QA) and multi-turn conversations demonstrate that adaptive delegation substantially improves accuracy on knowledge-intensive and multi-hop reasoning questions, while knowledge-boundary-aware training avoids unnecessary system 2 invocations. On a customized version of $τ$-Voice, SALMONN-duo further demonstrates its ability to complete environment-grounded, policy-constrained tasks through multi-turn interactions in realistic business scenarios. Finally, cost-aware reinforcement learning further enhances the trade-off between task performance and backend usage across the QA and conversation tasks, while improving task success and response safety on $τ$-Voice with an acceptable increase in the delegation rate.

## 1. 论文的核心问题与整体含义

- **核心矛盾**：全双工语音大语言模型（LLM）能够实现低延迟、自然的语音交互，但现实世界中的语音智能体还需要调用工具、执行多步推理等审慎计算。这些操作的延迟与计算成本变化大，与实时对话严格的时序要求存在根本性冲突。
- **研究动机**：现有工作要么为每个请求都调用后端（成本高），要么仅根据指令类型简单决定是否调用工具，缺少对委派效用（utility）的显式优化；同时，开源语音智能体在现实多轮、任务导向对话中的工具使用能力评估不足。
- **整体思路**：受认知心理学“双过程理论”（快思考/慢思考）启发，提出 **SALMONN-duo**——将实时交互与审慎计算分离，由一个始终在线的快速全双工语音前端（系统1）和一个异步、强大的慢速后端智能体（系统2）组成。系统1学习何时直接回答、何时委派，并在后端执行期间保持响应，将返回结果自然融入对话。

## 2. 论文提出的方法论

- **系统设计**
  - **系统1（前端）**：基于 SALMONN-omni，包含流式语音编码器（SPEAR）、LLM 骨干（Llama-3.1-8B-Instruct）和流式语音合成器（CosyVoice2-0.5B）。移除回声流（echo stream）以缩短序列、支持更长任务。系统2的输出通过每个时间块插入 `N=100` 个 token 提供给前端。
  - **系统2（后端）**：可插拔设计，可以是单个 LLM 智能体，也可以是协调多个专家智能体/工具的编排层。文本后端使用流式 ASR（gpt-realtime-whisper）转录用户语音以构建对话历史。
  - **委派机制**：系统1只负责决定是否委派，不解释意图、不执行任务。对比了两种设计：
    - 在 LLM 隐藏状态上加委派头（delegation head）；
    - 将特殊 token `DELEGATE` 作为前端响应的一部分直接生成。
  - 实验表明 **delegation token 机制更优**，对模型原始能力影响最小，且 AUROC 和 Answer–Reference Agreement Rate 更高，因此被采用。

- **知识边界感知的监督微调（SFT）**
  - 针对知识问答：先用系统1的 LLM 骨干对每个问题生成多个 rollouts，根据回答正确性决定标签——如果模型自己答不对，则训练目标以 `DELEGATE` 开头，并生成合适的填充句（filler）以保持响应性。
  - 多轮对话数据生成：采用用户模拟器、助手模拟器和监督器三个角色，分别由 gemma-4-26B-A4B-it、Llama-3.1-8B-Instruct、Qwen3.6-27B 扮演。流程包括主题设定、逐轮生成与监督、参考引导修复（reference-guided repair）、过滤与序列化。
  - 对 τ-Voice 任务：用 gpt-5.2-2025-12-11 同时扮演用户、助手和后端模拟器，后端内部状态和工具使用对用户和助手隐藏；还使用了 Gao et al. (2026) 发布的数据。

- **成本感知的群组相对策略优化（Cost-aware GRPO）**
  - 用于改善委派效用，缓解 SFT 的暴露偏差和知识边界变化。
  - **知识问答奖励**：偏好顺序为 `直接正确 > 委派正确 > 直接错误 = 委派错误`，实验中比较了不同的 `r_del,cor`（0.65、0.80、0.90），固定 `r_dir,cor=1`，错误为 0。
  - **任务导向对话奖励**：除任务成功奖励外，引入**安全奖励**（惩罚幻觉和政策违规）与**成本奖励**（当系统2返回参考信息却没有实际调用工具时，分数从 1 逐次扣 0.2，最低到 0）。权重分别为 1、1、0.5。
  - 理由：二元的任务成功奖励过于稀疏，在组大小 G=4 时训练信号不足；幻觉和政策违规是任务失败的常见原因。

- **后端延迟模拟**
  - 知识问答遵循 MoshiRAG 的策略，基于前导响应时长采样后端检索延迟。
  - 任务导向对话中，一次委派可能涉及多次后端 LLM 调用，假设每次调用延迟服从 `U(1.5, 2.5)` 秒，总延迟为 N 次独立采样之和。

## 6. 论文的主要结论与发现

- **委派机制**：将 `DELEGATE` token 直接纳入前端响应，优于基于隐藏状态的 delegation head，能在保持模型原始能力的同时获得更好的委派决策质量。
- **自适应委派有效性**：SALMONN-duo 在知识密集型和多跳推理问题上显著提升准确率，且在简单基准（如 Llama Questions）上委派率低，在困难基准（如 HotpotQA、HaluEval）上委派率高；相比之下 MoshiRAG 几乎总是调用后端，VoiceChat 很少调用，均缺乏灵活性。
- **多轮对话中**：模型能选择性委派，获得比固定委派策略更高的委派效用。
- **成本感知 GRPO**：进一步改善知识问答的 AUROC 和答案-参考一致性，几乎在所有委派预算下提升性能-成本权衡；在 τ-Voice 上，加入安全奖励可显著降低幻觉率、提高政策合规率，成本奖励能在保持高任务通过率的同时恢复有效委派率，防止过度依赖系统2。
- **用户打断处理**：成本感知 GRPO 提升了响应顺序正确率（81.9→87.8），打断问题准确率略有下降（77.2→74.7），但总体可接受。
- **延迟与 ASR 敏感性**：模型对系统2返回延迟不敏感（与 MoshiRAG 相比更稳定）；ASR 错误会影响后端参考质量，但只要核心语义可恢复，最终回答准确率可基本保持。

## 7. 优点

- **首次开源工作显式建模双系统协调中的委派效用**，填补了现有语音智能体研究空白。
- **设计简洁**：系统1只负责“是否委派”的二元决策，遵循 KISS 原则，保持前端轻量并保留全双工交互能力。
- **知识边界感知的数据构造**：基于模型自身回答正确性自动生成委派标签，多轮对话使用多角色异源 LLM 生成，降低单一模型家族的知识盲区。
- **成本感知 GRPO 结合安全奖励**，有效缓解稀疏奖励问题，同时抑制幻觉和政策违规，而非单纯追求任务成功率。
- **评估维度丰富**：覆盖单轮、多轮、环境接地任务、用户打断、延迟和 ASR 敏感性，并提供真实部署案例。
- **可插拔后端**：系统2可以是单个 LLM 或多智能体编排层，易于扩展和替换。

## 8. 不足与局限

- **ASR 假设较强
