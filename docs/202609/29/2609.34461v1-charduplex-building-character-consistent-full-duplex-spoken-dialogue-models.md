## 摘要
全双工语音模型正将语音交互从传统的轮流发言模式推向新阶段，然而自然对话不仅取决于智能体何时说话，还取决于它作为对话角色的行为方式。我们提出 CharDuplex，一个角色驱动的全双工语音模型，将实时语音交互与基于人设条件的行为结合起来。我们首先将 GLM-4-Voice 改造为常开的双流架构，并对模型进行全双工会话训练。然后通过全自动流水线从开源角色描述构建角色条件对话数据，用于角色条件监督微调。模型进一步通过我们提出的 FDGym 进行优化，其中由 LLM 模拟的用户动态与模型交互，从而在持续演化的多轮交互中进行强化学习。在 SpeechRole-Eval 上，CharDuplex 在所评估的开源模型中取得了最高平均分，同时与闭源系统保持竞争力。它还展现出具有竞争力的通用语音智能和强大的全双工交互能力。CharDuplex 展示了一套实用的训练方案，用于构建不仅具有交互性、而且角色一致的全双工语音助手。

## Abstract
Full-duplex speech models are moving voice interaction beyond conventional turn-taking, yet natural conversation is shaped not only by when an agent speaks, but also by how it behaves as a conversational character. We present CharDuplex, a character-driven full-duplex speech model that combines real-time spoken interaction with persona-conditioned behavior. We first adapt GLM-4-Voice to an always-on dual-stream architecture and train the model for full-duplex conversation. Then a fully automated pipeline constructs character-conditioned dialogue data from open-source character descriptions for character-conditioned supervised fine-tuning. The model is further refined with the proposed FDGym, where an LLM-simulated user dynamically interacts with the model, enabling reinforcement learning over evolving multi-turn interactions. On SpeechRole-Eval, CharDuplex achieves the highest average score among the evaluated open-source models, while remaining competitive with closed-source systems. It also demonstrates competitive general speech intelligence and strong full-duplex interaction capabilities. CharDuplex demonstrates a practical training recipe for building full-duplex voice assistants that are not only interactive, but also character-consistent.

## 2. 论文提出的方法论

### 2.1 全双工架构改造

- 以 **GLM-4-Voice** 为基础，将其串行会话流改造为**常开双流架构**：
  - **用户语音流** `Q = (q1, …, qT)`：由冻结的 **WhisperVQ** 编码为 12.5 Hz 离散 token；
  - **响应流** `Y = (y1, …, yT)`：包含文本 token、控制 token（`<PAD>`、`<BOS>`、`<EOS>`）。

- 两路 token 嵌入在帧级别求和后送入因果 LLM backbone，实现同步处理。

- **轮级文本–语音对齐**  
  响应流格式如下：
  ```
  <PAD>…<PAD> <BOS> 响应文本 <PAD>…<PAD> <EOS>
  ```
  模型在倾听时预测 `<PAD>`，开始回答时输出 `<BOS>` 与文本，语音继续期间预测 `<PAD>`，结束或被打断时输出 `<EOS>`。这样无需文本 token 与语音逐词对齐，也能支持正常结束和被打断两种终止方式。

### 2.2 角色条件数据构造流水线

自动流水线分为三个阶段：

- **阶段1：生成–验证循环**
  - **生成器 LLM**：给定角色描述、场景与目标，生成多轮对话草稿，并标注回传（backchannel）、用户思考停顿（thinking pause）、打断（interruption）事件。
  - **验证器 LLM**：分别检查：
    1. **事实支撑**：角色说出的私有/当前事实是否由角色背景或前文支持；
    2. **对话一致性**：结论是否可从已有信息推出，前后是否矛盾；
    3. **事件特定检查**：打断点、说话人、边界是否合理，删除被截断内容后对话是否仍然成立。
  - 局部错误做 turn/span 级修改，严重错误重新生成；事件注解与文本分离，不干扰 TTS。

- **阶段2：语音合成与质量控制**
  - 使用 **Qwen3-TTS** 为每个说话人用固定参考音色合成语音；
  - 用 **WavLM** 说话人验证器计算合成音频与参考音频相似度；
  - 相似度低于 0.5 的片段重试最多 3 次，仍不达标则保留最高分并标记。

- **阶段3：对齐与音频构建**
  - 使用 **Qwen3-ForcedAligner** 获得词级时间戳；
  - 音频调度器在共享时间轴上分别构造用户/助手两个声道，插入沉默、叠加回传、在打断处截断并淡出助手音频，丢弃被截断的续说内容；
  - 最终训练样本包含：角色描述、双通道音频、转录文本、时间标注。

### 2.3 监督训练

- 三个阶段：
  1. **通用全双工训练**：在约 530K 小时语音续说 + 70K 小时指令问答 + 20K 小时 ASR-QA 数据上训练 backbone，学习双流表示；
  2. **角色条件 SFT**：继续训练，系统提示为角色描述，目标为完整响应流，损失函数：
     \[
     L_{\text{text}} = -\sum_{t=1}^{T} \log p_\theta(y_t \mid c, q_{\le t}, y_{<t})
     \]
  3. **语音生成模块训练**：冻结 backbone，单独训练从响应文本到语音编解码 token 的自回归 Transformer，并用 CosyVoice2 流式解码器合成波形。

### 2.4 FDGym：实时交互式强化学习

- **动机**  
  传统 RL 使用预先录制好的用户语音，无法模拟“模型当前回复不同，用户下一句也就不同”的连锁反应。FDGym 将 LLM 用户模拟器嵌入 rollout 循环，让后续用户语音真正依赖模型当前输出。

- **Rollout 机制**
  - 每轮从角色提示和首句用户语音开始；
  - 使用 **160 ms** 为单位的仿真时钟 tick；
  - 每个 tick，用户侧提供该时间段语音，CharDuplex 处理累积输入并推进响应流；
  - 模型已经“说出来”的部分才暴露给模拟器，暴露速度按估计语速 3.4 词/秒计算；
  - 模拟器可中途打断模型；
  - rollout 时关闭波形解码、保留 KV cache，记录用户文本/音频、模型响应、时间戳和 token 对数概率。

- **奖励设计**
  - `r_int`：LLM 评估交互自然度、连贯性、响应性；
  - `r_char`：LLM 评估角色一致性、语气、行为约束；
  - `r_resp`：正常用户轮结束后到模型开始响应的延迟，基于 `g(d; D_resp=2s)` 计算；
  - `r_yield`：用户打断后到模型停止说话的延迟，基于 `g(d; D_yield=0.64s)` 计算；
  - 未响应或未让渡则该项为 -1；
  - 总奖励：
    \[
    R(\tau, c) = r_{\text{int}} + r_{\text{char}} + r_{\text{resp}} + r_{\text{yield}}
    \]

- **策略优化**  
  使用 **GRPO**：
  - 每组共享角色和首句用户输入，采样 8 条轨迹，共 4 组 32 条；
  - 组内奖励标准化得到优势函数：
    \[
    A_i = \mathrm{clip}\left( \frac{R_i - \bar R}{\max(\sigma_R, \epsilon_{\text{num}})}, -A_{\max}, A_{\max} \right)
    \]
  - 概率比：
    \[
    \rho_{i,t} = \frac{\pi_\theta(y_{i,t}|s_{i,t})}{\pi_{\theta_{\text{old}}}(y_{i,t}|s_{i,t})}
    \]
  - 截断策略损失：
    \[
    L_{\text{policy}} = -\frac{1}{N}\sum_{i,t} \min\left( \rho_{i,t}A_i,\; \mathrm{clip}(\rho_{i,t},1-\varepsilon,1+\varepsilon)A_i \right)
    \]

## 6. 论文的主要结论与发现

- **角色一致性大幅提升**  
  - CharDuplex 在 SpeechRole-Eval 平均分 0.785，为所测开源模型最高；
  - 相比 PersonaPlex 平均分提高 **0.134**；
  - 在四个维度上全面超越 PersonaPlex，其中 **人格一致性 +0.186**、**知识一致性 +0.203**，提升最明显；
  - CharDuplex-SFT 已经表现良好，说明数据和 SFT 有效；FDGym 在所有

FDGym 在所有四个角色一致性指标上均带来进一步提升，尤其在响应相关维度上使延迟惩罚明显下降，说明交互式 RL 在 SFT 基础上继续改善了“何时说”与“说多久”的行为，同时未损害角色一致性。

- **通用语音智能基本保持稳定**  
  CharDuplex 在 VoiceBench 系列多数数据集上与 GLM-4-Voice 水平接近，部分任务有轻微波动，但未出现因角色条件训练或 RL 导致的系统性退化。这表明模型在获得强角色一致性的同时，仍保留了通用语音理解、推理与问答能力。

- **全双工交互能力获得增强**  
  在 Full-Duplex-Bench 上，CharDuplex 相比 SFT 版本在回传响应、平滑轮流、用户打断后的让渡等维度均有改善。尤其是用户中途打断时，模型停止说话的延迟下降，说明 FDGym 中的 `r_yield` 奖励确实引导模型学会了更及时地让渡话轮。

- **消融实验支持关键设计选择**  
  附录中的消融结果显示：
  - 去掉 timing rewards（`r_resp` 和 `r_yield`）后，模型响应延迟和让渡延迟明显上升，全双工交互指标变差；
  - 去掉对话验证器后，知识一致性和对话连贯性下降，说明自动验证环节对数据质量至关重要。

- **总体结论**  
  CharDuplex 通过“角色条件 SFT + FDGym 响应相关 RL”的组合，成功在保持实时全双工交互和通用语音智能的前提下，显著提升角色一致性。相比固定对话数据训练，FDGym 让用户模拟器根据模型当前输出动态生成后续语音，更接近真实交互分布，是缩小训练与部署差距的关键。
