## 摘要
自然口语交互所需的不仅是流式自动语音识别、语言生成和语音合成：系统必须能够对重叠说话做出反应，而不会在每一次确认性回应时都取消；在话轮尚未确定之前就要准备响应；并确保被取消的音频不能进入对话历史。我们提出 Voice-Light，一个全双工级联语音智能体，结合了即时声学启动、共享流式 ASR 编码器的因果适配器、可逆播放控制以及私有的推测性响应生成。结构化工具调用与可听的桥接语音并发执行，而浏览器确认使实际渲染的音频成为持久历史的权威来源。在 1,673 个真实对话静音候选项上的锁定评估发现，一个较早的学习完成检查点保持了 2.70% 的误截断率，但话轮结束召回率仅为 12.53%，而 Silero 时序策略为 95.60%。因此，部署系统保留了混合控制器，而不是宣称以学习策略替代。在三次由操作员进行的即兴麦克风会话中，36 个被测响应话轮从最终 VAD 端点到第一个服务器音频的中位时间为 758 毫秒；其中 21 个话轮低于 800 毫秒。这些会话是一项带有测量工具的案例研究，而非受控用户评估。我们发布了支持该结果的合成数据、模型工件、评估代码与摘要、源代码和部署配置。

## Abstract
Natural spoken interaction requires more than streaming ASR, language generation, and speech synthesis: a system must react to overlap without canceling on every acknowledgment, prepare a response before a turn is certain, and ensure canceled audio cannot enter conversation history. We present Voice-Light, a full-duplex cascaded voice agent that combines immediate acoustic onset, a causal adapter sharing a streaming ASR encoder, reversible playback control, and private speculative response generation. Structured tool calls execute concurrently with audible bridge speech, while browser acknowledgments make rendered audio authoritative for durable history. Locked evaluation on 1,673 real-conversation silence candidates found that an earlier learned completion checkpoint preserved a 2.70% false-cutoff rate but reached only 12.53% end-of-turn recall, compared with 95.60% for a Silero timing policy. The deployed system therefore retains a hybrid controller rather than claiming a learned-policy replacement. Across three unscripted operator-run microphone sessions, 36 measured response turns had a 758 ms median from final VAD endpoint to first server audio; 21 turns were below 800 ms. These sessions are an instrumented case study, not a controlled user evaluation. We release the synthetic data, model artifacts, evaluation code and summaries, source code, and deployment configuration supporting the result.

### 1. 论文的核心问题与整体含义

Voice-Light 论文针对自然口语对话系统中的核心交互难题：系统不能仅依赖串行的 ASR→LLM→TTS 流水线，而必须解决以下问题：

- **重叠说话处理**：当用户在助手播放期间开始说话，系统需要立即反应，但不能因为每一声短促的确认性回应就取消当前生成。
- **话轮不确定性**：系统需要在用户话轮尚未完全确定时提前准备响应，同时避免将未确定的工作泄漏为可听内容。
- **取消音频的持久性**：被取消的音频绝不能进入对话历史，否则会污染上下文。
- **生成与历史的一致性**：只有真正被用户听到的音频才应成为持久对话状态。

整体含义是：构建一个**全双工级联语音代理**，既保留级联架构（ASR、LLM、TTS 的边界暴露了类型化工具、播放状态和取消机制），又在关键环节引入因果性、可逆性和私有推测，以实现自然、低延迟、可解释的全双工交互。论文的贡献定位为**系统与评估贡献**，而非提出新的 SOTA 话轮转换模型。

### 2. 论文提出的方法论

**核心设计原则**：  
*不确定的工作可以提前开始，但只有在通过显式因果检查后才能变为可听或持久。*  
这条原则贯穿三个子问题：话轮推断不得窥视未来音频、推测生成在提升前保持私有、对话历史只包含浏览器确认可听的音频。

**系统架构与数据路径**：

- 浏览器以 16 kHz PCM 流式麦克风数据，通过 WebSocket 传输，并确认已渲染的音频范围。
- **Silero VAD** 提供最早的声学起始信号。
- **流式 Nemotron ASR 编码器**（FastConformer-RNNT, 0.6B）持续产生转录，并通过前向钩子暴露选定层特征给因果适配器，无需加载第二个语音骨干。
- **因果话轮适配器**（约 183k 可训练参数）从 Nemotron 编码器的第 6、12、18、24 层提取特征：
  - 每个 1024 维特征被归一化并投影到 32 维；
  - 多流融合为 64 维；
  - 经过残差因果深度可分离卷积和单层 64 维单向 GRU；
  - 结合助手说话状态，输出完成/让步证据、交互事件（如抢话、非地面反馈）和未来活动预测；
  - 卷积与循环状态增量持久化，并与 ASR 流同步重置。
- **混合控制器**：结合声学起始、学习证据、转录修订和播放状态，执行可逆决策。
- **推测生成**：在 80 ms 低语音概率后，适配器有额外 80 ms 机会开启推测响应候选；候选文本和 PCM 携带生成标识符，保持私有，只有在转录修订检查（大小写、标点、空格、撇号变化保留；词汇变化失效）和话轮检查通过后才可提升为可听。
- **工具执行**：结构化工具（计算、当前时间、网络搜索）与桥接语音并发执行；浏览器中已缓冲的桥接语音可先行播放，工具结果通过同一个助手生成中的第二次 TTS 话语输出。桥接语音结束前必须关闭工具等待，以避免中间停顿（原文提到复用单一 TTS 会话会导致“deterministic mid-preamble stall”）。
- **可逆播放控制**：
  - 用户开始说话时，浏览器在 450 ms 内将播放渐弱至 -15 dB，并在 500 ms 内暂停；此反应可逆。
  - 抢话概率超过 0.82 可提交中断与取消。
  - 非地面反馈概率超过 0.82 在短语音突发结束后可恢复同一生成，不添加用户话轮。
  - 模糊重叠有界：持续语音 900 ms 后提交抢话，短结束突发保守视为非地面反馈。
- **历史权威性**：持久助手历史仅由浏览器确认渲染的音频范围构建；已取消的生成词仅作为诊断证据，不进入上下文。

### 6. 论文的主要结论与发现

- **学习话轮完成策略未能替代时序基线**：在锁定 V1 真实对话测试上，Voice-Light 历史检查点保持 2.70% 假截断率，但 EOT 召回仅 12.53%，而 Silero 为 95.60%。部署因此保留混合控制器。
- **合成到人类迁移失败**：合成话轮预训练 AUROC 0.9260（合成验证） vs 0.5646（人类验证）；人类微调后仅提升至 0.5972，说明领域转移严重。
- **工具协议可被学习但有限**：微调后在共享生成器 holdout 上表现显著提升（如简洁桥接从 7.6% 到 94.3%），但这不代表真实工具智能或事实检索能力。
- **推测生成能隐藏部分下游延迟**：36 轮中位 final-VAD 到首服务器音频 758 ms，21/36 低于 800 ms；13 轮完整 trace 中，9 轮提升推测的延迟中位 667 ms vs 非提升 1,513 ms，但这是观察性相关，非因果估计。
- **系统可复现部署**：发布了合成数据、模型工件、评估代码与摘要、源代码和部署配置。

### 7. 优点

- **坦诚的负结果与证据边界**：明确承认学习策略未达门限，并基于测量改变设计，而非用原始模型证明成功。
- **可逆混合控制设计**：声学起始立即反应但可逆，学习证据仅作为条件性信号，超时提供兜底，避免过度取消和停滞。
- **共享编码器架构**：因果适配器复用流式 ASR 编码器特征，避免加载第二个 0.6B 模型，节省计算。
- **私有推测生成**：生成带标识符、取消屏障和重定基准样本位置，确保取消工作不污染历史。
- **浏览器确认历史**：持久对话状态只来自实际渲染的音频，保证生成文本与真实听到内容一致。
- **丰富的可复现性工件**：序列化模式拒绝额外字段、清单记录种子/哈希/配置、锁定评估文件带内容哈希和检测器来源、完整的构建与验证命令。
- **工具与桥接语音并发**：允许桥接语音先行播放，工具结果作为同一生成中的二次 TTS，减少等待感。

### 8. 不足与局限

- **评估规模与统计脆弱性**：V1 测试仅 11 个对话、37 个 HOLD 案例，任一错误改变假截断 2.70 个百分点；同一对话内候选相关，置信区间未知。
- **部署模型未经充分离线验证**：部署的 step-750 适配器未在 V1 锁定测试上评估，其 floor-take 与 backchannel 头部未用独立标注数据校准。
- **人类标注审计缺失**：V2 排除了 216 个模糊案例，计划中的独立人工标签审计未完成。
- **部署研究外部效度低**：仅 3 个会话、1 名操作员、英语、受控网络与声学环境；不是用户研究，无法推广到用户、口音、噪声、回声或不同 GPU 类型。
- **合成评估偏差**：工具 holdout 与训练共享生成器和模式，不能证明事实准确性、真实搜索或通用工具智能。
- **训练源重叠风险**：Smart Turn 对比可能因训练数据重叠而不公平。
- **语言与领域限制**：系统主要为英语设计；人类音频受原许可条款限制，不可公开分发。
- **冷启动与成本**：冷启动约 32–55 秒，不适合突发高频访问。
- **延迟目标未达成**：原定 250–600 ms 工程目标未一致满足，800 ms 只是实用参考。
- **事实生成依赖**：依赖小型语言模型和外部检索，存在事实性风险。
