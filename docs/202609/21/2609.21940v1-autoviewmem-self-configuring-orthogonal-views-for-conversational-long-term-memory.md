## 摘要
长期记忆对于大语言模型智能体在长时间交互中保持一致性和个性化至关重要。现有记忆系统通常依赖固定粒度或静态模式，但当偏好、事件、约束和时间更新等异构信息被嵌入单一混合表示时，这些设计就会遇到困难。由此产生的语义干扰使得 top-K 检索对噪声敏感，并常常导致相关证据排序不佳。我们提出了 AutoViewMem，一个数据驱动的框架，它在索引之前将长期会话记忆组织成自配置、低重叠的语义视图。AutoViewMem 从交互轨迹中发现候选视图，选择紧凑的互补视图集，并使用这些视图指导写入时进行具有来源依据的记忆结构化提取。这种表示优先的设计将语义解耦从检索时移至写入时，使得标准 top-K 相似性搜索无需显式路由或迭代检索即可检索到聚焦的证据。我们进一步应用离线整合来提高记忆的紧凑性和一致性。在 LoCoMo 和 PersonaMem 基准上的实验，无论使用 Qwen3-8B 还是 Qwen3-14B 骨干，都表明 AutoViewMem 相较于强大的记忆基线改善了长程问答和个性化，同时保持了简单的推理流程。

## Abstract
Long-term memory is essential for large language model (LLM) agents to maintain consistency and personalization over extended interactions. Existing memory systems typically rely on fixed granularities or static schemas, but these designs struggle when heterogeneous information, such as preferences, events, constraints, and temporal updates, is embedded in a single mixed representation. The resulting semantic interference makes top-K retrieval sensitive to noise and often leaves relevant evidence poorly ranked. We present AutoViewMem, a data-driven framework that organizes long-term conversational memory into self-configuring, low-overlap semantic views before indexing. AutoViewMem discovers candidate views from interaction traces, selects a compact complementary view set, and uses these views to guide write-time structured extraction of provenance-grounded memories. This representation-first design moves semantic disentanglement from retrieval time to write time, allowing standard top-K similarity search to retrieve focused evidence without explicit routing or iterative retrieval. We further apply offline consolidation to improve memory compactness and consistency. Experiments on the LoCoMo and PersonaMem benchmarks, under both Qwen3-8B and Qwen3-14B backbones, show that AutoViewMem improves long-horizon question answering and personalization over strong memory baselines while preserving a simple inference pipeline.

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）智能体在长期陪伴、个性化助手、企业支持等场景中需要长期记忆，以维持一致性和个性化。交互时间跨度长，远超有限上下文窗口；即便使用长上下文模型，直接输入全部历史也会因话题漂移、用户状态演变和长尾重要信息而被噪声淹没。
- **核心问题**：现有长期记忆系统主要关注记忆粒度或存储、检索管理，通常依赖固定粒度或静态 schema。但长期对话天然是异构的——偏好、计划、事实、事件、时间更新常共存于同一对话片段。当这些混合内容被嵌入单一表示空间时，会产生**语义干扰**，使 top-K 相似度检索对噪声敏感，相关证据排序不佳。
- **整体含义**：本文提出一种“**表示优先**”的视角：与其单纯调整粒度，不如在索引之前就将记忆组织成自配置、低重叠的语义视图，把语义解耦从**检索时**前移到**写入时**。这样无需复杂查询期路由或迭代检索，标准 top-K 检索即可获得聚焦证据，同时保持简单推理管线。

## 2. 方法论

### 2.1 视图定义与总体架构

- **视图（view）**：一个轻量级 schema，包含名称、槽位（slots）和提取模板，用于指导 LLM 从对话中抽取结构化事实。文中的“正交”是实用意义上的互补、低重叠，不是严格的线性代数正交。
- **记忆项（memory item）**：每个记忆项携带结构化字段、视图标签、时间戳和**来源指针（provenance）**，以支持证据级评估和后续审计。
- **总体流程**：两阶段架构——在线视图归纳与写入 + 离线整合。在线阶段从交互流中自适应地发现视图，并用选中的视图指导结构化提取；离线阶段通过图聚类和 LLM 判定进行去重与合并，提高紧凑性和一致性。查询时仅对单一向量索引做标准 top-K 检索。

### 2.2 在线自适应记忆学习

在线学习采用“发散—收敛”策略，包含三个阶段：

- **阶段 1：视图发现**
  - 对话按块（chunk）流式到达。系统不把每个块当作孤立记忆写入，而是先累积弱信号（重复实体、稳定偏好、反复出现的约束等）。
  - 每 `N = 50` 个块，由 LLM 从最近交互轨迹中提出 `10` 个候选视图。每个候选视图包含名称、槽位和提取模板，可直接用于写入时的抽取指令。

- **阶段 2：视图收敛**
  - 候选视图存在噪声和冗余。先按指令字符串去重，再用与记忆索引相同的大模型编码器对每个候选视图做稠密编码。
  - 使用**行列式点过程（DPP）**从候选集中选择 `K = 10` 个紧凑且互补的活跃视图。具体地，对 ℓ2 归一化后的视图嵌入 `z_i` 构造 L-ensemble 核：
    \[
    L_{ij} = q_i (z_i^\top z_j) q_j
    \]
    其中 `q_i` 为均匀质量项。DPP 选择最大化子集行列式 `det(L_S)`，从而鼓励选择低相似度、互补的视图。
  - 每个选中种子视图再扩展其 top-30 最近邻，并由 LLM 汇总为规范化的提取指令。
  - 视图不强制互斥，重叠投影会在下游通过来源身份去重处理。

- **阶段 3：自适应提取**
  - 给定选中的活跃视图集，对每个对话块，LLM 在每个视图下评估该块，仅当证据与该视图相关时返回结构化事实。同一证据可投影到多个互补视图。
  - 生成的记忆项携带视图标签、时间戳和来源指针，写入统一向量索引。
  - 查询时对所有记忆项做标准 top-K 稠密检索，在 token 预算内合并并轻量去重后交给 LLM 生成。若多个检索项共享同一证据，只计第一个命中，避免多视图投影虚增覆盖指标。

### 2.3 离线记忆整合

- **目的**：在线提取偏向响应速度和召回，离线整合提升紧凑性和语义一致性。该阶段异步运行，不改变查询期接口。
- **流程**：
  1. 通过规范化文本/结构化表示的哈希，移除完全重复项，合并元数据（视图标签、出现次数、来源）。
  2. 构建无向相似度图：当 `cos(e_i, e_j) ≥ 0.9` 时建立边。连通分量作为候选整合批次；过大分量通过逐步提高阈值（如 0.90 → 0.999）递归拆分。
  3. 相似度只**提出候选**，不强制合并。对每个簇，由 LLM 根据三种情况重写为一条或多条规范记录：
     - **包含**：一条记忆包含另一条；
     - **互补**：非重叠事实可合并；
     - **相似但独立**：相似项表达不同事实，保持分离。
  4. 规范记录保留合并后的来源信息，便于审计或回退。

## 6. 论文的主要结论与发现

- AutoViewMem 在 LoCoMo 上取得**最佳总体 Judge 分数**，并在 F1、BLEU-1 上总体领先外部记忆基线；在 Qwen3-8B 下 Judge 甚至超过 Full History，在 Qwen3-14B 下与 Full History 差距很小。
- 在 PersonaMem-32k 上，AutoViewMem 在两个骨干下均取得**最佳总体准确率**，相对于最强基线提升超过 5 个百分点（Qwen3-14B 下），优势主要集中在需要综合的能力上（泛化、偏好推荐、建议、原因回忆），且随模型规模增大而扩大。
- 消融表明：**多视图组织**是主要收益来源；单视图结构化效果最弱。**离线整合**对查询效果有显著影响：去掉后 Judge 下降，no-positive rate 从 5.14% 升至 9.83%。DPP 选择主要作为多样性先验，随机选择在词法指标上尚可，但 no-positive rate 升高。
- 检索预算敏感性显示 AutoViewMem 在小预算下明显优于 Mem0，说明写入时聚焦使早期检索上下文噪声更少。
- 核心结论：将语义解耦从检索时前移到写入时，是提升长期记忆检索质量的有效路径；无需复杂查询期控制，即可实现更稳定的证据检索。

## 9. 可能的改进方向

- **降低写入成本**：可采用更轻量的视图归纳策略，例如定期、批量或基于触发条件（词汇和新实体出现）触发的视图更新；对简单或重复块采用缓存模板或规则抽取，减少 LLM 调用次数。
- **增强鲁棒性**：引入视图质量评估与回退机制，当视图归纳或提取置信度较低时退回到原始块检索或保守写入；对抽取事实进行验证或人工确认机制，降低记忆污染风险。
- **扩展评估维度**：在更多语言、多参与者、长周期真实对话数据集上验证；增加人类评估和多 judge 一致性；报告多次运行方差和统计检验。
- **混合检索与写入**：在保持写入时解耦优势的同时，可在查询期结合轻量重排或查询意图识别，进一步优化 top-K 结果，而非完全依赖写入时组织。
- **可解释性与审计**：利用来源指针和视图标签，提供检索结果的证据链展示，帮助用户理解模型为何引用某条记忆；增加记忆修正、过期和遗忘机制。
- **离线整合的增量更新**：使离线整合能够增量运行，避免在图聚类和 LLM 合并时对全量记忆库重复计算，提升长周期运行效率。
- **多模态与感知记忆**：当前工作仅处理文本对话，未来可扩展到图像、语音等多模态交互中的长期记忆组织，并利用视觉或听觉信号辅助视图归纳。

## 10. 总体评价

AutoViewMem 提出了一个明确且有价值的观点：长期记忆系统的核心瓶颈不仅是“存什么、检索什么”，更在于“如何组织表示以降低语义干扰”。通过将结构化解耦从检索时前移到写入时，它用相对简洁的管线（在线视图归纳 + 自适应提取 + 异步整合 + 标准 top-K 检索）在多个基准上取得了有竞争力的结果，并提供了证据级诊断和消融支撑。其自配置视图和 DPP 选择机制具有一定通用性，能够在无需人工 schema 的情况下适应对话演变。不过，该方法的实际部署成本、鲁棒性和跨场景泛化能力仍需要更多验证。总体而言，该工作为长期记忆研究提供了一个有启发性的“表示优先”范式，尤其适合追求简单检索接口但希望保持高证据质量的场景。
