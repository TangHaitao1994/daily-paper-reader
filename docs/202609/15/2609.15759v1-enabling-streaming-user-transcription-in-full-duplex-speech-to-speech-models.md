## 摘要
全双工语音到语音（S2S）模型通过允许同时听和说，实现自然对话式人工智能。然而，这类模型通常缺乏固有的用户语音转录能力，而这对对话记录、无障碍功能和质量监控等应用至关重要。在本文中，我们提出一种高效方法，在现有双工 S2S 模型中添加流式 ASR 能力：引入一个轻量级 ASR 头，与智能体文本头并行。我们的方法只需极少的额外参数，无需对基础 S2S 模型进行重大架构改动，即可实现实时用户转录，同时保留全双工对话能力，包括话轮转换和插话处理。实验结果表明，在双工 S2S 框架内，我们的方法在 HuggingFace Open ASR 排行榜上取得了 10.21% 的流式平均 WER。此外，我们表明，相同架构作为独立流式 ASR 模型训练时，与当前 SOTA 模型相比取得了有竞争力的结果（7.73% WER）。我们将开源训练和推理代码，以促进联合流式 ASR 与 S2S 建模的进一步研究。

## Abstract
Full-duplex speech-to-speech (S2S) models enable natural conversational AI by allowing simultaneous listening and speaking. However, these models typically lack inherent user speech transcription, which is essential for applications such as conversation logging, accessibility features, and quality monitoring. In this work, we propose an efficient method to add streaming ASR capabilities to an existing duplex S2S model by introducing a lightweight ASR head in parallel to the agent text head. Our approach requires minimal additional parameters and no significant architectural changes to the base S2S model, enabling real-time user transcription while preserving full-duplex conversational capabilities including turn-taking and barge-in handling. Experimental results demonstrate that our method achieves streaming average WER of 10.21% on the HuggingFace Open ASR Leaderboard within the duplex S2S framework. Additionally, we show that the same architecture trained as a standalone streaming ASR model achieves competitive results (7.73% WER) compared to current SOTA models. We will open-source our training and inference code to facilitate further research in joint streaming ASR and S2S modeling.

  - 传统级联 ASR–LLM–TTS 系统天然能提供用户转录，但延迟较高，且难以在端到端建模中纳入副语言信息。

- **整体含义**

  - 该方法无需对基础 S2S 模型做重大架构改动，能够在保持全双工对话能力（如话轮转换、插话处理）的同时输出用户文本。

## 2. 方法论

- **基础双工 S2S 架构**  
  - 用户语音首先由 **600M 参数 Parakeet 流式语音编码器**编码，生成 **80ms 帧率**的连续嵌入。  
  - 主干 LLM 为 **NVIDIA Nemotron-Nano-9B-v2-Base**，一个 9B 参数 decoder-only 语言模型。  
  - 模型采用**多通道下一 token 预测**，同时生成用户文本和智能体文本；用户与智能体的 embedding 时间对齐后相加，连同用户语音编码一起输入 decoder-only LLM。  
  - 训练包含**预训练阶段**和**监督微调 SFT 阶段**；SFT 阶段使用多样数据源，并加入背景噪声增强（概率 0.5，SNR 范围 -30 dB 到 60 dB）。

- **流式 ASR 头设计**  
  - 在智能体文本头之外，**并行引入一个流式 ASR 模块**，包含单独的 embedding 层和预测头。  
  - 两个层均从原始 LLM 主干的对应层初始化，使模型能够独立学习用户文本表示。  
  - ASR 头从 LLM 隐藏状态预测用户转录 token，与智能体响应生成并发执行。  
  - **只需一次解码即可同时产生用户文本和智能体文本**，二者共享 LLM 主干的上下文理解。  
  - 训练时加入 ASR 的下一 token 预测损失，与智能体文本损失联合优化。  
  - 对于独立流式 ASR 配置，则去掉智能体文本头，仅训练语音识别任务。

- **在线强制对齐**  
  - 使用 **torchaudio 的 CTC 强制对齐 API** 和 **MMS-FA 声学模型**进行在线词级时间戳对齐。  
  - 将文本 token 对齐到对应语音帧；实验中采用**左对齐**（token 对齐到每个词的开始）效果更好。  
  - 词之间用 `<pad>` token 填充无文本预测的帧；也尝试过独立 end-of-word token，但性能差异不明显。

- **关键延迟超参数**  
  - 用户文本延迟 \(d_u = 1.2s\)，控制流式 ASR 延迟。  
  - 智能体文本延迟 \(d_a = 0.16s\)，帮助模型学习可靠的响应时机。  
  - 二者用于平衡 ASR 质量与话轮转换响应速度。
