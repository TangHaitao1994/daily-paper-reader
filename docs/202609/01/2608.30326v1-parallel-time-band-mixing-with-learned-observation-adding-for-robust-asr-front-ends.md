## 摘要
语音增强常被用作鲁棒ASR的前端，但循环时序模块和跨频带模块会引入顺序依赖，降低并行效率。本文提出一种序列并行的分带增强前端，构建于并行时间-频带混合器（PTBM）块之上，消除了块内循环展开。PTBM在统一并行架构中整合带内时序混合与逐帧跨带注意力，实现跨时间和频率维度的高效上下文建模。该系统保留掩码加残差重建接口，并引入学习的观测添加（LOA）以抑制ASR敏感伪影，无需开发集调优。在DNS Challenge和CHiME-4上使用冻结Whisper后端的实验表明，与循环分带基线相比，所提前端一致降低词错误率，同时前端网络仅需0.96M参数和0.58 GMAC/s。

## Abstract
Speech enhancement is often used as a front-end for robust ASR, yet recurrent temporal and cross-band modules introduce sequential dependencies that reduce parallel efficiency. In this paper, we present a sequence-parallel band-split enhancement front-end built on a Parallel Time-Band Mixer (PTBM) block that eliminates within-block recurrent unrolling. PTBM integrates intra-band temporal mixing and per-frame cross-band attention within a unified parallel architecture, enabling efficient contextual modeling across both time and frequency dimensions. The system retains the mask-plus-residual reconstruction interface and introduces learned Observation-Adding (LOA) to suppress ASR-sensitive artifacts without development-set tuning. Experiments on DNS Challenge and CHiME-4 with frozen Whisper back-ends show that the proposed front-end consistently reduces word error rate relative to recurrent band-split baselines while requiring only 0.96 M parameters and 0.58 GMAC/s for the front-end network.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：语音增强（SE）常作为鲁棒自动语音识别（ASR）的前端，但现有基于循环神经网络的分带增强结构（如 BSRNN）在时间建模和跨频带建模上依赖循环展开，引入顺序依赖，降低并行效率，不利于高效推理与部署。
- **矛盾**：增强伪影可能损害 ASR 性能；前端又必须轻量高效。
- **研究目标**：设计一种序列并行的分带增强前端，既保持低失真和抑制伪影，又减少参数和计算量，同时无需开发集调优即可匹配冻结的 ASR 后端。

## 2. 方法论

### 2.1 核心思想

- 提出 **并行时间–频带混合器（PTBM）** 块，替代循环时间/跨带模块，消除块内循环展开。
- 保留分带结构（V4 频带划分）和掩码加残差重建接口。
- 引入 **学习的观测添加（LOA）**，自动预测混合系数，抑制 ASR 敏感伪影。

### 2.2 关键技术细节

- **分带与重建**：
  - 对复杂 STFT 频谱按非均匀 V4 配置划分 K=23 个频带。
  - 各频带拼接实部和虚部，经线性嵌入得到特征 \(Z^{(0)} \in \mathbb{R}^{B \times K \times T \times C}\)。
  - 输出端经频带全连接层预测复掩码 \(M\) 和复残差 \(R\)，增强频谱：\(\hat{S} = M \odot X + R\)。
- **PTBM 块**：
  - 两个并行分支：
    - **TCM（Temporal ConvMixer）**：层归一化 + 逐点瓶颈投影 + 门控膨胀深度可分离 1D 卷积（沿时间维）+ 逐点投影，用于带内时间混合。
    - **CBA（Cross-Band Attention Mixer）**：层归一化 + 逐点瓶颈投影 + 逐帧多头自注意力（K 个频带作为 token）+ 逐点投影，用于跨带交互。
  - **交互模块**：对两分支输出进行门控融合：
    \[
    G = \sigma(\text{Linear}([Z_{\text{time}}; Z_{\text{band}}])),
    \]
    \[
    Z_{\text{fuse}} = G \odot Z_{\text{time}} + (1-G) \odot Z_{\text{band}},
    \]
    \[
    Z^{(\ell)} = Z^{(\ell-1)} + Z_{\text{fuse}}.
    \]
- **LOA（Learned Observation-Adding）**：
  - 输入统计量：对数能量比 \(\rho_E\)、对数幅度谱差的均值 \(\mu_\Delta\) 和方差 \(\sigma^2_\Delta\)。
  - 两隐藏层 MLP（隐藏 64，sigmoid 输出）预测标量 \(\omega \in [0,1]\)。
  - 最终 ASR 输入：\(s_{\text{LOA}} = \omega x + (1-\omega)\hat{s}\)。
  - 训练分两阶段：先训练 SE 网络；冻结后，用网格搜索（步长 0.01）得到 oracle 权重，训练 LOA 回归该权重。
- **训练目标**：固定加权多分辨率 STFT 幅度损失 + SI-SNR 损失：
  \[
  \mathcal{L} = \mathcal{L}_{\text{MR-STFT}}(\hat{s}, s) + \lambda \mathcal{L}_{\text{SI-SNR}}(\hat{s}, s),\quad \lambda=1.0.
  \]

## 6. 主要结论与发现

- 所提出的 PTBM + LOA 前端在 **所有** 测试场景和 Whisper 后端尺寸下，WER 均低于带噪输入和两个循环分带基线。
- 在 DNS（无/带混响）和 CHiME-4 真实录音上均有一致改善，证明泛化能力超出了训练所用合成混合场景。
- 与 BSRNN 相比，在更低参数量（0.96 M vs 2.60 M）和更低 MACs（0.58 vs 1.84 GMAC/s）下取得更好 WER；与 Zhao et al. 相比，在相近或更低 MACs 下改善 WER。
- 消融表明：CBA 与 TCM 都对性能有贡献，去掉任一支路都会明显提升 WER；LOA 优于不使用 OA 和固定 OA，说明学习混合能自动抑制 ASR 敏感伪影。
- 增加 PTBM 块深度（L=6→12）带来显著收益，继续增大到 L=15 收益递减，故默认 L=12 兼顾精度和效率。
- 算子级分析表明，TCM 和 CBA 比 GRU 模块具有更低单次调用复杂度和序列并行能力，支撑整体 MAC 降低。

## 7. 优点

- **并行高效**：PTBM 完全消除块内循环依赖，TCM 和 CBA 均可序列并行，降低推理延迟适合部署。
- **结构紧凑**：参数量和计算量均低于循环基线，且性能更优。
- **无需开发集调优**：LOA 自动学习混合权重，提升跨条件部署灵活性。
- **兼顾时频建模**：同时显式建模带内时间和跨带依赖，且通过门控融合有效结合两种上下文。
- **实验设计合理**：使用冻结 Whisper 后端、多个尺寸，覆盖合成和真实数据，比较了相关基线，并提供消融和算子复杂度分析。
