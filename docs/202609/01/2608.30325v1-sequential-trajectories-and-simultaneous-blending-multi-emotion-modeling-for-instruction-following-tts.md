## 摘要
自然语言指令能够灵活控制合成语音，但情感TTS系统主要建模单一话语级情感，多情感控制仍未被充分探索。我们研究两个互补的多情感TTS任务：情感轨迹，其跨越多个有序情感阶段；以及情感混合，其中多种情感在整段话语中同时存在。这些任务暴露出监督不匹配：监督微调（SFT）并未显式评估情感特征，而单情感奖励既不能为轨迹完成提供结构感知反馈，也不能为混合提供配对感知反馈。我们提出 HybridEmo，一个后训练框架，先以 SFT 初始化这两个任务，然后通过分组相对策略优化，使用样本感知的混合奖励对语音 token 策略进行对齐。对于轨迹样本，分段对齐一致性结合平均证据和最弱阶段证据，以保持规定阶段的正确性与完整性。对于混合样本，基于 GMM 的奖励将离线情感空间中目标情感锚并集提供的帧级支持与话语级较弱目标边际相结合。两个分支共享 ASR 奖励，并在统一策略内进行路由。在 MultiEmo-Test 上，HybridEmo 显著提升了轨迹正确性和混合强度，且说话人相似度没有明显下降。人工评估更偏好 HybridEmo 而非 CosyVoice 3 和 EmoVoice-0.5B，与 Qwen3-TTS 相比偏好几乎持平。

## Abstract
Natural-language instructions enable flexible control of synthesized speech, yet emotional TTS systems primarily model a single utterance-level affect, leaving multi-emotion control underexplored. We study two complementary multi-emotion TTS tasks: emotion trajectory, which spans several ordered affective stages, and emotion blending, in which multiple emotions coexist throughout an utterance. These tasks expose a supervision mismatch: supervised fine-tuning (SFT) does not explicitly evaluate emotion features, while single-emotion rewards provide neither structure-aware feedback for trajectory completion nor pair-aware feedback for blending. We introduce HybridEmo, a post-training framework that initializes both tasks with SFT and then aligns the speech-token policy through Group Relative Policy Optimization using a sample-aware hybrid reward. For trajectory samples, segment-aligned consistency combines average and weakest-stage evidence to preserve the correctness and completeness of prescribed stages. For blending samples, a GMM-based reward combines frame-level support from the union of target-emotion anchors in an offline emotion space with an utterance-level weaker-target margin. Both branches share an ASR reward and are routed within a unified policy. On MultiEmo-Test, HybridEmo significantly improves trajectory correctness and blending intensity, without a noticeable degradation in speaker similarity. Human evaluation prefers HybridEmo to CosyVoice 3 and EmoVoice-0.5B, with nearly balanced preferences against Qwen3-TTS.

## 1. 论文的核心问题与整体含义

- **研究背景**：自然语言指令为语音合成（TTS）提供了灵活的控制方式，但现有情感 TTS 系统主要对整段语音建模单一 utterance 级情感，难以处理真实话语中更复杂的多情感模式。
- **核心问题**：论文正式定义两类互补的多情感 TTS 任务：
  - **情感轨迹（Emotion Trajectory）**：一段语音内按顺序出现多个情感阶段，如“开心→悲伤→愤怒”。
  - **情感混合（Emotion Blending）**：多种情感在整段语音中同时存在，如“愤怒⊗悲伤”。
- **监督不匹配**：传统监督微调（SFT）只做 token 级交叉熵拟合，并不显式评估情感模式是否被正确实现；而现有的单情感奖励无法提供轨迹所需的结构感知反馈，也无法评估混合中多个目标情感是否真正共存。
- **整体含义**：需要一个针对多情感结构设计的后训练框架，在保持语音可懂度和说话人相似度的前提下，让 TTS 模型学会精确实现有序情感阶段和并发情感混合。

## 2. 论文提出的方法论

- **总体框架：HybridEmo**
  - 基于 CosyVoice 3（0.5B），包含自回归语音 token LLM 和冻结的 flow-matching 声学生成器。
  - 两阶段训练：先用 SFT 初始化多情感生成能力，再用 **GRPO（Group Relative Policy Optimization）** 和样本感知混合奖励对齐语音 token 策略。

- **SFT 初始化**
  - 使用轨迹和混合演示数据，冻结 tokenizer 和声学生成器，只优化 LLM。
  - 优化 token 级交叉熵：  
    `L_SFT = -Σ_t log p_θ(z*_t | z*_<t, x, c_e)`

- **RL 对齐阶段**
  - 将自回归语音 token LLM 视为策略 `π_θ`。
  - 对每个输入采样 G 个 token 序列，经冻结声学生成器解码成波形；GRPO 基于组内相对优势更新策略，并施加 KL 约束。
  - 奖励函数按样本类型路由：
    - `R(ŷ, s) = w_asr · R_asr + (w_consi · R_consi，若 s=trajectory；w_gmm · R_gmm，若 s=blending)`

- **共享 ASR 奖励（R_asr）**
  - 使用 SenseVoice 转写合成语音，计算 WER。
  - `R_asr = clip[0,1](1 - tanh(3·ε_wer))`，在情感优化过程中保护内容准确度。

- **轨迹一致性奖励（R_consi）**
  - 对有序情感跨度 `T = {(x_k, e_k)}`，按文本长度比例近似划分语音段边界：
    - 段 k 的时间区间 `I_k` 基于字符长度比例 `ℓ_k` 计算。
  - 对每段用 emotion2vec+ large 得到目标情感后验 `p_k`。
  - 结合平均得分 `p̄` 与最弱阶段得分 `p_min`：
    - `R_consi = β·p̄ + (1-β)·p_min`
  - 防止高平均分掩盖某个失败阶段，保证轨迹的完整性和顺序性。

- **GMM 混合密度奖励（R_gmm）**
  - **离线锚点构建**：
    - 用基础 CosyVoice 3 合成单情感语音，筛选高置信度样本，提取帧级情感特征。
    - 经 LDA 降维、Isolation Forest 去除离群点后，为每个情感拟合一个 M 分量的全协方差 GMM。
  - **在线评分**：
    - 将混合候选语音帧特征投影到同一 LDA 空间，计算目标情感 A、B 的帧级密度 `p_A(u_t)`、`p_B(u_t)`。
    - 用对数-和-指数（LSE）定义非归一化联合支持：  
      `ℓ_mix(u_t) = LSE(log p_A(u_t), log p_B(u_t))`
    - 计算每个情感逐帧归一化贡献 `q_t,e`，得到较弱目标的 utterance 级平均占比 `m`。
    - 施加较弱目标边际正则化：  
      `s_raw = s_union - α·max(0, 1 - m/ρ)`
    - 对 `s_raw` 做运行均值和标准差标准化，再经 sigmoid 映射为有界奖励 `R_gmm`。
  - 该奖励鼓励两个目标情感在帧级同时获得支持，避免单一情感主导。

- **样本感知路由**：一个统一策略根据样本类型自动选择轨迹或混合奖励，两类样本共享 ASR 奖励。

## 3. 实验设计

- **数据集**：
  - **SFT 语料**：来自 Emilia 数据集的英文部分，共 124,096 条语音（383.6 小时）。使用 Qwen3-Omni-30B-A3B-Captioner 和 MiniMax-M2.5 进行情感标注、结构识别和自然语言指令生成。轨迹样本含 1–3 个情感阶段，混合样本含 2 个不同非中性情感。
  - **MultiEmo-RL**：用于 RL 的纯文本-指令样本，不含目标波形。包含 12,000 个轨迹样本和 2,400 个混合样本。
  - **MultiEmo-Test**：720 个测试条件，其中轨迹 600 个（1/2/3 阶段各 200），混合 120 个（覆盖 12 个情感对），每个条件配有来自 Seed-TTS 评测集的参考声音。

- **对比方法**：
  - CosyVoice 3（0.5B，基础模型）
  - EmoVoice-0.5B 和 EmoVoice-1.5B
  - Qwen3-TTS-12Hz-1.7B-VoiceDesign（作为外部能力参考，使用指定音色而非语音提示，设置不完全匹配）

- **评估协议**：
  - **自动指标**：轨迹情感正确性（1–5 分，含顺序完成）、轨迹自然度（仅 2–3 阶段）、混合强度（1–5 分）、混合自然度（1–5 分）；WER（whisper-large-v3）；UTMOSv2（自然度 MOS）；说话人相似度（ERes2Net 余弦相似度）。
  - **人工评估**：4 位训练有素的听者，对三组模型对进行两两比较，每组 20 个条件，共 80 个判断，考虑情感正确性、表现力、自然度和可懂度。

## 6. 论文的主要结论与发现

- **轨迹任务**：HybridEmo 将 1–3 阶段宏平均正确性从 3.24 显著提升至 3.33，在每个长度上都有提升；自然度从 2.40 提升至 2.50；WER 保持在 2% 以下；说话人相似度无显著下降。
- **混合任务**：混合强度从 3.47 提升至 3.71，自然度从 3.06 提升至 3.24；强度与 Qwen3-TTS 持平，自然度仅差 0.05；WER 为 0.37%，UTMOS 与 CosyVoice 3 几乎一致。
- **消融发现**：
  - SFT 单独只能提供有限提升；直接 RL（跳过 SFT）虽然部分情感得分提高，但 WER 上升，说明 SFT 初始化对 RL 稳定性和可懂度很重要。
  - 专项变体各有侧重：Trajectory-GRPO 在轨迹任务上略优于联合 HybridEmo，Blending-GRPO 在混合任务上优于 SFT；联合 HybridEmo 在混合任务上取得最佳效果，同时轨迹任务保持竞争力。
  - 移除较弱目标边际后，混合强度和自然度均下降，说明该正则项能有效抑制单一情感主导，改善混合质量。
- **整体**：将强化信号与任务结构匹配，可以在轨迹和混合场景中同时提升指令对齐的感知质量，且不牺牲可懂度、自然度和说话人相似度。

## 7. 优点

- **任务感知的奖励设计**：针对轨迹和混合两种结构分别设计奖励，而不是沿用单一情感或全局质量奖励，精准解决监督不匹配问题。
- **分段对齐一致性奖励**：结合平均与最弱阶段得分，避免高平均掩盖局部失败，有效检测缺失或错误阶段。
- **GMM 混合密度奖励**：用离线锚点刻画情感分布的多模态性，联合支持评分 + 较弱目标边际，鼓励真正共存而非序列切换或单情感塌缩。
- **样本感知路由**：统一策略内自动选择对应奖励分支，实现多任务联合训练。
- **共享 ASR 奖励**：在情感优化中持续保护内容准确度，WER 保持在低水平。
- **实验设计全面**：包含自动指标、消融、表示分析和人工评估，证据链条较完整。

## 8. 不足与局限

- **轨迹边界近似**：分段对齐基于文本长度比例，未使用真实时间戳或 forced alignment，可能在语音时长与文本长度不完全成正比时产生偏差，影响段级情感后验的准确性。
- **混合奖励依赖外部模型**：GMM 锚点完全由基础 CosyVoice 3 合成的单情感语音构建，且依赖 emotion2vec+ large 情感识别，这些模型的偏差和局限性可能传递到奖励信号。
- **数据构建依赖 LLM 标注**：SFT 和 RL 样本的情感标注及结构识别由 Qwen3-Omni 和 MiniMax-M2.5 自动完成，可能存在标注噪声或偏差，论文未进行人工校验。
- **训练设置与时长未完全公开**：只提到 GPU 数量和 epoch 数，没有报告实际训练总时长或收敛曲线；RL 仅训练 1 个 epoch，可能尚未充分探索最优策略。
- **模型基座单一**：只在 CosyVoice 3（0.5B）上验证，未在其他 TTS 架构（如 Qwen3-TTS、EmoVoice 的不同规模）上进行方法迁移性实验。
- **Qwen3-TTS 对比不完全公平**：外部参考模型使用指定音色而非语音提示，可能影响情感控制和音色一致性结论。
- **人工评估规模有限**：每个模型对仅 20 个条件和 4 位听者，样本量较小，结果可能存在方差。
- **应用限制**：混合任务只覆盖 12 个情感对，且均为非中性情感两两组合；未探索三种及以上情感混合或中性情感参与的情形。
