## 摘要
尽管 WhisperX 通过音频内批处理加速了语音转录，但它将音频片段相互隔离，丢失了连贯标点和术语转录所需的历史上下文。相反，标准 Whisper 顺序保留上下文，但推理速度慢且存在幻觉循环。为了兼顾两者优点，我们提出了上下文感知交错批处理。通过利用基于 VAD 的片段边界，我们的算法稳定了 Whisper 的文本条件化，使我们能够在批量音频片段之间安全地保持连续历史上下文。如长音频基准所示，该方法降低了词错误率（WER）并改善了专有名词转录，同时保持了高吞吐量推理速度。

## Abstract
While WhisperX accelerates speech transcription via intra-audio batching, it isolates audio segments, losing the historical context needed for coherent punctuation and terminology transcription. Conversely, standard Whisper retains context sequentially but suffers from slow inference and hallucination loops. To achieve the best of both worlds, we propose Context-Aware Interleaved Batching. By using VAD-derived segment boundaries, our algorithm stabilizes Whisper's text conditioning, allowing us to safely maintain continuous historical context across batched audio segments. As demonstrated on long-form audio benchmarks, this approach reduces Word Error Rate (WER) and improves proper noun transcription, all while maintaining high-throughput inference speeds.

## 2. 论文提出的方法论

### 2.1 核心思想

- 利用 **VAD 产生的自然静音边界** 切分长音频，避免 Whisper 内部时间戳解码的脆弱性。
- 将切分后的音频块按时间顺序划分为多个连续流，再在不同流之间做交错批处理。
- 在同一流内，把上一批次的解码文本作为当前批次的 **条件前缀**，实现跨批次历史上下文传播。
- 通过 **冷启动解析** 处理流起始块缺少前文的问题。

### 2.2 关键技术细节

- 设 VAD 分段序列为 \(s = [s_0, s_1, \dots, s_{N-1}]\)，目标硬件批大小为 \(B\)。
- 将序列划分为 \(B\) 个连续流，每个流长度 \(M = \lceil N/B \rceil\)。
- 第 \(b\) 个流定义为：
  \[
  S_b = [s_{bM}, s_{bM+1}, \dots, s_{bM+M-1}]
  \]
- 转录过程包含 \(M\) 轮批处理。第 \(m\) 轮批次为：
  \[
  B_m = \{ S_b[m] \mid b = 0,1,\dots,B-1 \}
  \]
- 每个流维护一个 **FIFO 滚动上下文缓冲区**，最多保留 224 个 token；上一轮解码出的 token 会追加到对应流的缓冲区，并作为当前片段的文本条件前缀。

### 2.3 冷启动解析

- 每个流的起始块（\(m=0\)）原本应依赖上一流的最后一块，但此时上一流最后一块尚未转录。
- 因此第一轮 \(B_0\) 先无条件转录。
- 当所有批次完成后，使用最后一批 \(B_{M-1}\) 生成的历史文本作为上下文，对 \(B_0\) 重新转录，保证流边界处的上下文一致性。

### 2.4 算法伪代码要点

- 提取 VAD 分段；
- 将分段分布到 \(B\) 个连续流；
- 按 round-robin 方式交错构造批次；
- 维护每个流的上下文 token 列表；
- 每个批次转录后更新对应流的上下文并截断到 224 token；
- 最后对初始批次做冷启动重转录；
- 展平批次并按时间排序返回最终分段。

## 3. 实验设计

### 3.1 数据集

- **Earnings-21**：公开长音频金融财报电话会议数据集，包含大量复杂金融术语、专有名词和连续语音，并提供严格的标点 ground truth。论文在 15 个长音频转录上评估。
- **MedicalLessons**：论文新提出的开源医学词汇教学数据集，包含 6 段 YouTube 医学课程录音，内容涉及医学前后缀、解剖术语等，ground truth 经人工验证。

### 3.2 Benchmark 与对比方法

- 对比方法：
  - **WhisperX+IB**（本文方法）
  - **WhisperX**（原版批处理）
  - **openai/whisper**（标准顺序 Whisper）

### 3.3 评估指标

- **WER**：标准词错误率，在整段转录级别计算。
- **F1**：基于 Levenshtein 对齐的标点准确率。
- **LLM Punctuation Score (LPS)**：使用 GPT-5.1 对语义层面标点结构打分，分数范围 1–3，避免对风格性标点过度惩罚。
- **Proper Noun Score (Pn)**：通过 LLM 分类器标记专有名词/技术术语，计算正确转录比例，满分 100。

### 3.4 实现细节

- 基础模型：`openai/whisper-large-v2`
- 计算类型：float16
- 解码策略：beam search（宽度 5，温度 0.0），失败时回退到 best-of-5 采样（温度 0.2–1.0）
- 批大小：Earnings-21 使用 16，MedicalLessons 使用 4
- WER 计算使用 `jiwer` 包
