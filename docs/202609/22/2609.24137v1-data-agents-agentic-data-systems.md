## 摘要
传统数据系统在人工智能时代面临深刻局限，依赖人工构建的流水线，缺乏对异构数据的语义理解，并采用僵化、被动的处理方式。为应对这些挑战，我们提出一种名为数据智能体的新范式，旨在以最少的人工干预管理、处理和分析数据。数据智能体自主执行广泛的数据相关任务，通过从手工设计转向自主编排、从字面操作转向语义解释、从被动处理转向主动处理，变革传统数据系统。我们的数据智能体系统包含六个组件：语义数据组织、语义算子、智能体流水线编排与优化、反馈驱动细化、记忆管理和主动适应。在此基础上，我们还开发了两个专用智能体：数据分析智能体和数据科学智能体。在真实基准上的实验表明，我们的数据智能体相比最先进方法取得了显著性能提升。我们指出了待解决的挑战，以指导未来构建完全自主数据系统的研究。

## Abstract
Traditional data systems face profound limitations in the AI era, relying on human-crafted pipelines, lacking semantic understanding of heterogeneous data, and operating through rigid, reactive processing. To address these challenges, we propose a new paradigm called the Data Agent, designed to manage, process, and analyze data with minimal human intervention. Data agents autonomously execute a wide range of data-related tasks, transforming traditional data systems by shifting from manual design to autonomous orchestration, from literal manipulation to semantic interpretation, and from reactive to proactive processing. Our Data Agent system includes six components: semantic data organization, semantic operators, agentic pipeline orchestration and optimization, feedback-driven refinement, memory management, and proactive adaptation. Building on this foundation, we also develop two specialized agents: the data analytics agent and the data science agent. Experiments on real benchmarks demonstrate significant performance gains of our data agent over state-of-the-art methods. We identify open challenges to guide future research in building fully autonomous data systems.

## 1. 论文的核心问题与整体含义

- **研究动机**：传统数据系统（如关系数据库、数据仓库、Airflow 等手工编排流水线）在 AI 时代面临三大根本性局限：
  1. **人工设计流水线**：数据清洗、集成、分析等流程依赖手工编码规则，领域迁移成本高、可扩展性差。
  2. **语义能力有限**：现有系统假设数据完整且结构化，缺乏对异构、噪声、语义丰富数据（如非结构化文本、半结构化表格）的理解与推理能力。
  3. **被动处理**：系统只能响应预定义查询或报表，无法主动发现趋势、异常或进行预测性维护，导致决策滞后。
- **整体含义**：本文提出 **Data Agent（数据智能体）** 新范式，旨在以最少人工干预自主完成数据发现、获取、管理、处理与分析，实现从数据到决策的闭环。该范式实现三个根本性转变：**从手工设计到自主编排**、**从字面操作到语义解释**、**从被动响应到主动处理**。论文还通过对比工业平台（AWS Glue）、LLM 编排栈（LangChain）、工作流编译器（AutoML）以及 NL2SQL 系统，阐明 Data Agent 是面向数据系统的根本性架构变革。

## 2. 论文提出的方法论

Data Agent 系统包含六大核心组件，整体架构如图 1 所示：

- **语义数据组织（Semantic Data Organization）**
  - 构建树状语义目录（tree-structured semantic catalog），节点为语义标签（如 basketball、NBA），边表示类别—子类别关系。
  - 为异构数据生成嵌入（embeddings），链接嵌入空间中高度相似的数据点。
  - 建立向量索引，实现基于稀疏/稠密嵌入的高效语义检索。
  - 语义目录物化在共享记忆层，所有代理可访问一致的结构化数据视图。

- **语义算子（Semantic Operators）**
  - 在传统关系算子（filter、project、group by、join 等）之外引入语义算子：语义过滤、语义分组、语义连接、语义提取等。
  - 实现方式灵活：LLM 直接调用、LLM 生成程序或基于嵌入匹配。
  - 采用**级联执行策略**（cascading strategy）降低成本：先进行近似最近邻检索，再阈值剪枝，仅对模糊候选项调用轻量 LLM 粗筛，最后用强 LLM 精细验证。

- **智能体流水线编排、优化与执行（Agentic Pipeline Orchestration, Optimization and Execution）**
  - 多智能体协作：任务理解、任务分解、数据画像、查询规划、推理、流水线验证等子任务由专门代理完成，通过 A2A 协议（JSON 消息）通信。
  - 将自然语言请求转换为结构化任务图（task graph），节点为子目标，匹配原子算子；规划代理基于逻辑一致性与资源约束选择算子序列。
  - 验证代理通过低代价 dry-run 并行评估多条候选执行序列，选择最优方案。
  - 优化采用**基于代价的方法**：利用语义目录估计语义算子基数，用动态规划选择最低期望代价的流水线。

- **反馈循环管理（Feedback Loop Management）**
  - 多流水线交叉验证：生成多条候选流水线并执行，按结果频率计算“覆盖率得分”，选择覆盖率最高的流水线。
  - 置信度评分：低分流水线提供负反馈。
  - 检测到错误时触发警告信号并启动纠正子流程。
  - 注入带 ground truth 的数据，对出错流水线提供负反馈。
  - 生成合成数据并由 LLM 生成参考答案，评估流水线质量。
  - 设定置信度阈值和最大重试次数防止无限循环。

- **短期与长期记忆管理（Memory Management）**
  - 短期记忆：会话内临时上下文、执行日志、中间推理；容量受上下文窗口限制。
  - 长期记忆分为三类：**情景记忆**（用户偏好、历史事件）、**语义记忆**（客观事实、领域知识）、**程序记忆**（可复用的技能与工作流）。
  - 记忆算子：提取、插入/更新/删除（遗忘）、检索、整合。
  - 冲突解决采用基于规则策略（近因优先、置信度优先、LLM 显式确认），并维护版本图（version graph）以追溯记忆演变（Algorithm 1）。
  - 存储层使用向量数据库，每个记忆条目带类型、时间戳、重要性分数等元数据。

- **主动适应（Proactive Adaptation）**
  - 持续监控性能指标（查询成功率、流水线延迟、结果合理性、用户反馈）。
  - 检测到显著偏差时触发自动根因分析，诊断代理提出假设，通过定向验证确认后主动修复（更新记忆先验、调整算子偏好、重新规划流水线）。
  - 在用户感知到问题之前完成调整，保持系统鲁棒性和相关性。

- **专用代理变体**
  - **数据分析代理**：用于异构数据（结构化+非结构化）的语义分析，包含可视化代理，自动选择图表类型、设计视觉编码、生成标签和图例。
  - **数据科学代理**：涵盖数据发现、清洗、标准化、模型选择、参数选择、模型训练、评估等基础代理，通过多代理流水线编排完成端到端数据科学任务，并用 LLM 生成参考样本或注入 ground-truth 样本作为反馈。
