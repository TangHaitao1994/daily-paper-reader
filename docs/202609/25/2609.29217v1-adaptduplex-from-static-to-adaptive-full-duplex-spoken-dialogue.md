## 摘要
全双工语音对话需要在亚秒级延迟下同时听与说，并应对时刻变化的对话时序和认知需求。然而现有模型大多采用静态工作点，缺乏系统性的自适应决策机制。我们提出 AdaptDuplex，它为 Qwen3-Omni 升级了此类机制，并在三个层面协同设计。紧凑的 token 级协议将每个窗口表示为规范序列，通过有界文本领先于语音来训练双流对齐，并将每个行为决策暴露为显式 token，以便通过 logits 偏置实现免训练的运行期控制。自适应机制动态地在离散窗口时长中进行预测，并在需要时通过非阻塞的认知整合和多路外部推理来增强直接响应。渐进式流程通过三阶段 Thinker 课程引入这些行为，随后进行仅 Talker 和联合 SFT，并以 GRPO 作为进一步增量。在 Full-Duplex-Bench v1 和 v1.5 上，AdaptDuplex 在大多数可比的轮流发言、重叠行为和时序指标上优于 DuplexOmni 和 MiniCPM-o 4.5，在交互决策和响应时序方面均有提升。在人工录制的 HumDial-FDBench 上，它在对比的全双工模型中取得了最高的最终得分（72.9）。

## Abstract
Full-duplex spoken dialogue requires simultaneous listening and speaking at sub-second latency, under conversational timing and cognitive demands that change moment to moment. Yet current models mostly impose static operating points, lacking a systematic mechanism for adaptive decisions. We present AdaptDuplex, which upgrades Qwen3-Omni with such a mechanism, co-designed across three layers. A compact token-level protocol represents every window as a canonical sequence, trains dual-stream alignment through a bounded text lead over speech, and exposes every behavioral decision as an explicit token for training-free runtime control via logits bias. Adaptive mechanisms dynamically predict among discrete window durations and augment direct response as needed with non-blocking cognitive consolidation and multi-flight external reasoning. A progressive pipeline introduces these behaviors through a three-stage Thinker curriculum, then Talker-only and joint SFT, with GRPO as a further increment. On Full-Duplex-Bench v1 and v1.5, AdaptDuplex outperforms DuplexOmni and MiniCPM-o 4.5 on the majority of comparable turn-taking, overlap-behavior, and timing metrics, with gains in both interaction decisions and response timing. On the human-recorded HumDial-FDBench, it attains the highest Final score (72.9) of the compared duplex models.

## 1. 核心问题与整体含义

- **研究背景**：人类对话本质上是全双工的，听者会在对方说话时进行确认、打断、修正等行为；语音对话模型需要连续监听、协调重叠语音，并在亚秒级延迟内响应。
- **核心问题**：现有全双工对话模型大多采用**静态工作点**：
  - 窗口时长固定，无法根据对话时序和认知需求动态调整；
  - 可用动作在设计阶段就被硬编码，难以扩展更丰富的交互策略；
  - 如 DuplexOmni 固定窗口时长、只支持单路外部推理；MiniCPM-o 4.5 只提供二值交互控制。
- **本文整体含义**：提出 **AdaptDuplex**，将 Qwen3-Omni 升级为具备自适应决策机制的全双工语音对话模型，使时间粒度可选、动作可在运行时组合，并通过显式 token 暴露所有行为决策。

## 2. 方法论

### 2.1 总体架构

- 继承 Qwen3-Omni 的 **Thinker–Talker 架构**：
  - Thinker 不再为每个用户回合生成完整回复，而是逐窗口做出交互决策；
  - Talker 仍负责语音合成，但条件输入方式发生变化。

### 2.2 Token 级序列协议

- 每个窗口被表示为一个由 Unit 分隔符包围的**规范序列**，Thinker 按固定顺序输出：
  - listen/speak 控制；
  - 可为空的动作 token 序列：`<|memory|>`、`<|launch:N|>/<|cancel:N|>`；
  - 可选的助手文本；
  - next-window token；
  - 边界 token。
- 结束说话回合的窗口会先发出 `<|turn eos|>`，再发出 `<|chunk eos|>`。
- 三个关键设计：
  1. **紧凑序列化**：用固定顺序的紧凑 token 替代 DuplexOmni 的 JSON 元数据，降低结构化解码开销。
  2. **双流对齐**：Talker 通过一次预填充启动，利用 turn-local FIFO 按声学位置弹出文本条件；训练时采用**有界 Text-ahead** 策略，把文本前缀移动到同一说话回合内更早的相邻窗口，保持全局文本序列、控制决策、codec 目标的不变性；`<|tts pad|>` 填充空位。
  3. **运行时可控性**：行为决策是显式 token，推理时可通过 **logits bias** 进行免训练控制。

### 2.3 自适应交互机制

- **动态窗口预测**：
  - 在每个窗口结束时，模型仅基于因果可用的多模态上下文预测 \(z_k \in \{short, mid, long\}\)；
  - 对应下一窗口时长为 0.48s、0.64s、0.96s（6/8/12 个 Mimi 帧）；
  - 证据不足时回退到 mid，并用 mid 初始化第一个窗口；
  - 弱标签来自时间戳、声学/语义边界、重叠标签的优先级规则。
- **条件动作组合**：
  - **L0**：直接响应，动作序列为空；
  - **L1**：`<|memory|>` 触发非阻塞的认知整合，更新记忆后端，后续 Unit 可见；
  - **L2**：最多管理 4 个并发外部请求，使用索引的 `<|launch:N|>/<|cancel:N|>` 控制可插拔 LLM、工具或 agent；有效结果和失败以 loss-masked Tool Block 形式在 Unit 边界重新进入 Thinker；取消、过期或未返回的请求不注入，且失败/不返回不阻塞当前响应。

### 2.4 渐进训练流程

- SFT 沿两个正交维度展开：
  - **数据难度**：三阶段 Thinker 课程；
  - **可训练模块**：Thinker-only、Talker-only、joint。
- **三阶段 Thinker 课程 SFT**：
  1. Stage 1：固定中间窗口的回合制对话，只学习规范协议；
  2. Stage 2：加入 backchannels、短停顿、简单打断等基本双工事件，并激活动态窗口预测；
  3. Stage 3：加入完整双工数据以及 memory、launch/cancel，要求模型同时组合交互与外部推理编排。
- 训练数据由自动化多智能体流程生成。
- **Talker-only SFT**：冻结 Thinker，在 FIFO 文本条件与有界 Text-ahead 下训练 Talker；
- **Joint SFT**：在高质量 DuplexDrama 子集上端到端校准；
- **GRPO**：从 Joint SFT 继续，优化交互策略但不改变架构。
