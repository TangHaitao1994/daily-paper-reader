## 摘要
全双工对话系统在说话的同时聆听，必须区分话轮结束与话轮内的停顿，并区分请求话轮的打断与简短确认或面向第三方的讲话。然而，现有对话语料库对这些事件的控制有限，且对其意图的标签有限。我们提出一种从关系事件列表合成带意图标签的双通道对话语音的流水线。由一个大语言模型（LLM）编写每个事件的说话人、文本、对话行为以及与先前事件的依附关系，而不预测绝对时间戳。事件被独立合成，与源文本对齐，并放置于共享时钟上，因此话轮转换标志从渲染信号中测量，而静音时长则被指定或从话轮转换分布中采样。该流水线覆盖英语和普通话中八个类别下的42种现象，从编写的意图推导帧级系统动作，并通过使用少量多样化的先例集以及要求提供带自报概率的替代方案的批量提示来促进多样性。消融实验显示在每个目标多样性维度上都有提升。在包含占用、保持、释放和不占用会话发言权的四动作标签空间中，一个仅使用当前和过去音频的语义语音活动检测器在开始说话和开始聆听上达到0.819和0.802的F1分数。在生成自身响应时，全双工语音模型Moshi在生成的语料库上微调后接过了0.85的参考话轮，而微调前为0.44。其预测系统发言权占用的帧级精确率从0.46提升至0.88。在每一步提供参考上下文时，其帧级发言权F1从0.893提升至0.962。这些结果表明，受控合成可以为全双工话轮管理提供可学习且可迁移的监督。

## Abstract
Full-duplex dialogue systems, which listen while speaking, must distinguish a completed turn from a pause within a turn and an interruption that requests a turn from a brief acknowledgment or speech addressed to a third party. Yet existing conversational corpora provide limited control over these events and limited labels for their intent. We present a pipeline for synthesizing intent-labeled, two-channel conversational speech from relational event lists. An LLM authors each event's speaker, text, conversational act, and attachment to an earlier event without predicting absolute timestamps. Events are synthesized independently, aligned with their source text, and placed on a shared clock, so turn-taking landmarks are measured from the rendered signal while silence durations are specified or sampled from turn-taking distributions. The pipeline covers 42 phenomena across eight families in English and Mandarin, derives frame-level system actions from authored intent, and promotes diversity using small, diverse sets of prior examples and batch prompts that request alternatives with self-reported probabilities. Ablations show gains in each targeted diversity dimension. On a four-action label space for taking, holding, releasing, and not holding the conversational floor, a semantic voice-activity detector using only current and past audio reaches start-speaking and start-listening F1 scores of 0.819 and 0.802. When generating its own responses, the full-duplex speech model Moshi takes 0.85 of the reference turns after fine-tuning on the generated corpus, compared with 0.44 before fine-tuning. Its frame-level precision for predicting system-floor occupancy rises from 0.46 to 0.88. With reference context at each step, its frame-level floor F1 rises from 0.893 to 0.962. These results show that controlled synthesis can provide learnable and transferable supervision for full-duplex turn management.

## 1. 论文的核心问题与整体含义

- **核心问题**：全双工对话系统在“边听边说”时，必须实时判断：当前是话轮结束、话轮内停顿，还是打断请求、简短确认（backchannel）、面向第三方的旁白（side-talk）。这些事件在声学上可能高度相似，但需要完全不同的系统动作。
- **现有语料的不足**：
  - 真实对话语料（如 Fisher）虽然时序自然，但**不标注每次重叠的意图**，也无法按构造平衡各种现象。
  - 语音混合 / 说话人分离模拟能复现重叠统计，但把打断、确认、旁白都归为同一种“说话活动”，缺乏意图区分。
  - 文本对话合成能控制内容，但**不控制声学时间线**。
- **整体含义**：提出一种受控、带意图标签的双通道语音合成管线，把“说什么、为什么说”（authoring）与“何时发声”（acoustic realization）分离，从而为全双工话轮管理提供可学习、可迁移的监督信号。

## 2. 论文提出的方法论

### 2.1 关系事件表示
- 对话被表示为一个有序的**事件列表**，每个事件包含：
  - 说话人、通道（ch1 人类 / ch2 系统）、文本、会话行为（act）、与先前事件的关系性时间线索（cue）。
- 核心行为（acts）：
  - `turn`：开始一个新的话轮。
  - `continue`：同一说话人在话轮内停顿后继续。
  - `backchannel`：确认但**不夺取发言权**。
  - `barge_in`：争夺发言权；成功时会截断被引用事件。
  - `aside`：面向第三方，不转移发言权。
- 时间线索只引用**先前事件**，锚定到：
  - 事件开始、有效结束（截断后的结束）、或命名词的词边界（word start / word end）。
  - 可附加 `gap_before_ms` 与 `offset_ms`。
- 这种“仅向后引用”的结构形成有向无环图，按事件顺序解析，不要求 LLM 预测绝对时间戳。

### 2.2 生成、合成与装配流程
- **Authoring**：使用 DeepSeek-V4-Pro 生成完整对话 JSON；经过静态校验、时间线预检、文本过滤、数字/符号归一化；可选 Qwen3.7-Plus 作为 judge 检查语义一致性。
- **Render**：每个事件独立用 Qwen3-TTS 合成，使用说话人参考录音，独立合成以保留自然韵律。
- **Align**：用 Qwen3-ForcedAligner-0.6B 对每个事件做强制对齐，得到词/字边界。短片段临时加尾填充以保证对齐稳定。
- **Assemble**：按依赖顺序解析时间线，绝对开始时间计算为：
  \[
  t_i = t_{r(i)} + p_{r(i)} + g_i + o_i
  \]
  其中 \(r(i)\) 为被引用事件，\(p_{r(i)}\) 为其测量 cue 点，\(g_i\) 为插入静音，\(o_i\) 为小偏移。正 gap 表示静音，负 gap 表示故意重叠。
  - 成功 `barge_in` 会截断被干扰事件，并按词边界定位截断点。
  - 最终复制到两个零填充缓冲区：ch1 放用户与旁白，ch2 放系统；同通道语音串行，跨通道重叠保留。
- **Label**：从系统视角，在 80ms 网格上定义四类帧级动作：`take floor`（start-speaking）、`speaking`、`release floor`（start-listening）、`listening`。意图信息决定哪些重叠触发 yield，哪些不触发。

### 2.3 多样性机制
- **Few-shot diversity hubs（少样本多样性枢纽）**：
  - **Structural hub**：用 27 维特征向量表示“发言权管理方式”，结合有序行为序列距离（基于 ROUGE-L，权重 0.75）与标准化特征距离（权重 0.25）。成员以“floor fingerprint”形式写入 prompt，作为**负样本记忆**，要求新生成不重复。
  - **Semantic hub**：用 BGE-M3 对所有事件文本拼接生成 1024 维句向量，计算欧氏距离，阻止语义重复。
  - 两个 hub 都用 **streaming max-min coreset** 算法维护 5–32 个代表性样本。
- **Probability-verbalized batch authoring（概率口述批量生成）**：一次请求 5 个候选，并让模型给出每个候选的自报概率，从而暴露低概率、非典型输出。
- **Topic seeding**：从 Wikipedia Level 5 Vital Articles 无放回抽取主题。

### 2.4 声学变化与可复用输出
- Render 时可从按语言、性别、年龄分组的 voice bank 采样参考录音（LibriSpeech、VCTK、Interspeech 2020 DNS、DiDiSpeech、内部普通话语料）。
- 可向用户通道混入经 RIR 处理的环境噪声（OpenSLR-28、MUSAN），系统通道保持干净，并保留干净副本。
- 每个样本保存事件对象、双通道波形、截断后实际播放文本、事件时间戳、可选含词边界的时间线，便于审计和重新打标签。

  - 13-token merged 标签空间（clean / noisy）。
  - 此外合并用户/陪伴者来源标签，对比 15-token 与 merged 性能。

### 3.3 Moshi 全双工模型 benchmark
- 在 Moshiko English checkpoint 上，用英语语料微调 2,000 步。
- 数据划分：5,906 训练片段、890 验证片段，说话人与对话不重叠。
- 两种评估模式：
  - **Free generation**：只给用户通道，模型生成自身 assistant 流。
  - **Teacher forcing**：提供参考人机流作为上下文，做一步预测。
- 指标：turn coverage、floor precision、floor F1、start-speaking / start-listening F1、onset latency。

## 6. 主要结论与发现

- **受控合成可作为监督**：从编写的事件图生成带意图标签的双通道语音，能够训练模型区分在声学上相似但意图不同的事件。
- **多样性机制有效但作用不同**：
  - Structural hub 防止“话轮 + backchannel”模式塌缩，恢复打断、截断等；
  - Semantic hub 在 topic seeding 基础上进一步增加语义分散；
  - Probability verbalization 显著提升词汇与语义多样性，但对发言权机制和时序分布影响混合，需监测。
- **语义 VAD 可恢复标签**：
  - 4-token core：clean 下 start-speaking F1 = 0.819、start-listening F1 = 0.802；噪声下几乎不变。
  - 13-token merged：clean 准确率 0.9613，但稀有 `barge-in` 类 F1 仅 0.4325（仅 209 帧）。
  - 合并用户/陪伴者来源标签可提高 performance，说明标签空间应保留有音频证据的区分。
- **Moshi 迁移有效**：
  - Free generation：turn coverage 从 0.44 升到 0.85；floor precision 从 0.46 升到 0.88。
  - Teacher forcing：floor F1 从 0.893 升到 0.962；零容忍 release 时间 F1 从 0.60 升到 0.93。
  -

- 在 teacher forcing 模式下，零容忍 release 时间 F1 从 0.60 升到 0.93，表明模型对“结束发言”的边界判断更加精准；结合 free generation 的提升，验证了合成语料能够为全双工系统提供可迁移的时序监督。

总体来看，论文通过受控事件图合成双通道对话语音，证明其能够有效补充真实语料在意图标注与声学时间线控制方面的不足，为全双工话轮管理提供了新的监督来源。
