## 摘要
主动对话要求智能体在多轮交互中持续推进任务目标的同时，不断根据用户反馈调整策略。为了超越静态数据集上的模仿学习，近期方法使用用户模拟器收集交互数据进行策略优化。然而，许多模拟器并未显式建模用户认知状态的演变，限制了跨轮反馈的一致性与状态依赖性。此外，仅用高层策略标签表示每个动作会忽略庞大的话语空间，无法区分同一策略的不同实现形式。为此，我们联合设计了认知用户模拟器（Cog-Sim）和认知状态转移驱动的策略优化（CSTPO）。Cog-Sim 维护用户的认知与情感状态，并通过跨轮约束状态转移生成回复，因此反馈既取决于实际生成的话语，也取决于用户当前状态。CSTPO 将每个动作组织为层级化的“策略—话语”表示：高层策略标签约束话语采样，并在各标签内部对话语进行优化。稀疏完全分支采样复用共享的对话前缀，并分别估计策略级和话语级优势，从而在两级实现细粒度优化。在三个任务上，Cog-Sim 表现出单调的剂量—反应关系，且在自然度上优于基于提示的模拟器。CSTPO 将 Qwen3-14B 的性能提升至与基于 GPT-5.5 的规划方法相当的水平。

## Abstract
Proactive dialogue requires agents to continually adapt their policies to user feedback while progressing toward task objectives over multiple turns. To move beyond imitation learning on static datasets, recent approaches use user simulators to collect interactive data for policy optimization. However, many simulators do not explicitly model the evolution of user cognition, limiting the consistency and state dependence of feedback across turns. Moreover, representing each action only by a high-level strategy label overlooks the large utterance space and cannot distinguish alternative realizations of the same strategy. To this end, we jointly design a $\textbf{Cog}$nitive User $\textbf{Sim}$ulator $\textbf{(Cog-Sim)}$ and $\textbf{C}$ognitive-$\textbf{S}$tate $\textbf{T}$ransition--Driven $\textbf{P}$olicy $\textbf{O}$ptimization $\textbf{(CSTPO)}$. Cog-Sim maintains the user's cognitive and affective states and generates responses through constrained state transitions across turns, so feedback depends on both the realized utterance and the user's current state. CSTPO organizes each action as a hierarchical strategy--utterance representation: a high-level strategy label constrains utterance sampling, and utterances are optimized within each label. Sparse complete-branch sampling reuses shared dialogue prefixes and estimates separate strategy-level and utterance-level advantages, enabling fine-grained optimization at both levels. Across three tasks, Cog-Sim exhibits monotonic dose--response relationships and is preferred over prompt-based simulators for naturalness. CSTPO improves Qwen3-14B's performance to a level comparable to that of GPT-5.5-based planning methods.

## 2. 论文提出的方法论

### 2.1 Cog-Sim：认知状态驱动的用户模拟

- **状态表示**：
  - 用户画像 \(P\) 是稳定的个人特征。
  - 动态认知状态 \(C_t=(B_t,D_t,I_t)\)，基于 BDI 框架：信念（beliefs）、愿望（desires）、意图（intentions）。
  - 情感状态 \(E_t=(v_t,\rho_t,c_t)\)：效价、唤醒度、离散情绪类别。
  - 用户特定参数 \(\Theta_u=(\eta_R,\tau_A,\tau_R)\)，控制信息加工路线与接受/拒绝区域。
- **动作分类与状态转移**：
  - 动作类型分类器（ATC）将智能体实际话语分为 **Influence / Elicit / Social** 三类，而不是依赖任务特定策略标签。
  - 仅 Influence 触发认知状态更新；Elicit 和 Social 保持 BDI 状态不变，但三类都能更新情感并生成用户回复。
  - 认知更新基于 **ELM（Elaboration Likelihood Model）** 和 **社会判断理论**：先判定加工路线（中央/外周）和立场（接受/非承诺/拒绝），然后应用确定性的“路线—判断契约”约束 LLM 提出的 BDI 变化幅度与方向。
- **可恢复检查点**：Cog-Sim 在每轮前保存完整用户状态、对话历史、随机流等，允许从同一前缀状态出发，对不同候选动作进行反事实延续（counterfactual continuations）。

### 2.2 CSTPO：认知状态辅助的层级策略优化

- **层级动作表示**：
  - 动作 \(a_t=(k_t,u_t)\)，\(k_t\) 是策略标签，\(u_t\) 是条件于策略的话语。
  - 策略分解为：
    \[
    \pi_\theta(a_t|o_t)=\pi_\theta(k_t|o_t)\,\pi_\theta(u_t|o_t,k_t)
    \]
- **双值头 Critic（Cog-Critic）**：
  - 状态值函数 \(V^\pi(x)=\mathbb{E}_\pi[G|x]\)：在策略选择前估计期望回报。
  - 策略条件值函数 \(U^\pi(x,k)=\mathbb{E}_\pi[G|x,k]\)：在策略已选但话语未定前估计回报。
  - 动作值函数 \(Q^\pi(x,k,u)\) 可分解为：
    \[
    Q^\pi-V^\pi = \underbrace{U^\pi-V^\pi}_{\text{策略选择优势}} + \underbrace{Q^\pi-U^\pi}_{\text{话语实现优势}}
    \]
    这使得策略级和话语级信用可以分开估计。
- **同状态延续与稀疏完全分支采样**：
  - 在主轨迹中选择少量非终结检查点（P4G/CB 每轨迹 2 个，ESConv 每轨迹 4 个）。
  - 在每个检查点，使用冻结旧策略采样 \(m=2\) 个不同策略，每个策略采样 \(\ell=2\) 条话语；主路径动作作为其中一条路径，其余 \(m\ell-1\) 条尾部只需额外模拟。
  - 策略级回报对同一策略下的多条话语取平均，减少单条话语随机性的影响。
  - 所有额外尾部只用于 Critic 拟合和策略级回报估计，Actor 仅用主路径动作更新。
- **Field-aware PPO**：
  - 策略字段和话语字段使用各自的优势：
    \[
    \hat{A}_j=
    \begin{cases}
    \hat{A}^{k_t}, & \text{token } w_j \text{ 属于策略字段}\\
    \hat{A}^{u_t}, & \text{token } w_j \text{ 属于话语字段}
    \end{cases}
    \]
  - 对动作 token 做 PPO 裁剪更新，SFT 策略初始化。
- **终端评估**：冻结 LLM 评估器输出结构化任务判断，任务特定函数计算最终回报；评估器不接触隐藏认知状态。

## 7. 优点

- **显式认知建模**：将 BDI 认知状态和维度情感状态作为持久变量，引入理论约束的转移机制，使反馈状态依赖且可反事实采样，提升了模拟器的可控性与一致性。
- **层级动作分解**：明确分离策略选择和话语实现，通过双值头 Critic 实现策略级与话语级的正交信用分解，克服了“仅策略标签”的动作空间局限。
- **高效分支采样**：稀疏完全分支采样复用共享前缀，在有限交互预算下获得多组反事实回报，兼顾探索效率与表达能力。

- **核心贡献**：论文提出 Cog-Sim 与 CSTPO 的联合框架，通过显式建模用户认知—情感状态并采用层级“策略—话语”动作表示，实现了状态依赖的用户模拟与细粒度信用分配，在三个主动对话任务上取得了有竞争力的结果。
- **关键机制**：Cog-Sim 基于 BDI 和 ELM/社会判断理论构建可恢复检查点，支持反事实延续；CSTPO 利用双值头 Critic 分解策略选择优势与话语实现优势，并通过稀疏完全分支采样高效获取多组回报信号。
- **实验结论**：Cog-Sim 在剂量—反应和自然度上优于提示类模拟器；CSTPO 在 ESConv、P4G、CB 上均超过 SFT 基线，部分任务接近或超过最强 GPT-5.5 基线；消融验证了认知状态输入和层级 Critic 的必要性；小骨干实验表明方法具有一定迁移性。
- **未来方向**：可扩展到更多任务领域和真实用户在线评估；引入更灵活的认知状态更新机制（如概率图模型）以增强模拟器生态效度；探索更高效的分支采样策略（如基于不确定性选择检查点）以降低计算开销；在多智能体设置下检验层级信用分配框架的适用性。
