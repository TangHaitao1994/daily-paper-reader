## 摘要
交错文本与声学令牌的自回归生成是语音大语言模型中生成语音响应的常见方法。尽管该设计支持具有显式文本引导的流式生成，但生成的声学令牌会成为后续文本预测上下文的一部分。在相同语音输入下，我们观察到语音到文本再到语音（S2TS）模式中生成的内部文本的答案准确率明显低于语音到文本（S2T）响应。我们将这种差异称为输出模式差距（OMG）。为缩小 OMG，我们提出联合输出在线策略蒸馏（JO-OPD），利用学生生成的 S2TS 轨迹将模型更强的 S2T 策略蒸馏到联合生成中。在每个文本位置，S2T 教师根据学生先前输出的纯文本投影提供软目标，学生则根据相应的完整交错历史进行预测。一个保留目标进一步正则化原生非文本预测。在 Step-Audio-2-mini 和 Baichuan-Audio-Instruct 上的实验揭示了两种交错生成架构中的 OMG。在 Step-Audio-2-mini 上，JO-OPD 将 Spoken-MQA 上的 OMG 从 42.87 个百分点降至 16.26 个百分点，将语音渲染的 GSM8K 上的 OMG 从 29.72 降至 13.04 个百分点，S2T 准确率几乎不变，且降幅显著大于匹配的 SFT 基线。基于 ASR 的评估进一步显示 Spoken-MQA 上的语音答案准确率提高了 7.49 个百分点。

## Abstract
Autoregressive generation of interleaved text and acoustic tokens is a common approach to spoken-response generation in speech large language models. Although this design enables streaming generation with explicit textual guidance, generated acoustic tokens become part of the context for subsequent text predictions. Given identical speech inputs, we observe markedly lower answer accuracy for the internal text generated in speech-to-text-and-speech (S2TS) mode than for speech-to-text (S2T) responses. We term this discrepancy the \emph{output-mode gap} (OMG). To reduce OMG, we propose \emph{Joint-Output On-Policy Distillation} (JO-OPD), which distills the model's stronger S2T policy into joint generation using student-generated S2TS trajectories. At each text position, the S2T teacher provides soft targets from a text-only projection of the student's preceding outputs, while the student predicts from the corresponding full interleaved history. A preservation objective further regularizes native non-text predictions. Experiments on Step-Audio-2-mini and Baichuan-Audio-Instruct reveal OMG across two interleaved generation architectures. On Step-Audio-2-mini, JO-OPD reduces OMG from 42.87 to 16.26 percentage points on Spoken-MQA and from 29.72 to 13.04 points on speech-rendered GSM8K, with little change in S2T accuracy and substantially larger reductions than matched SFT baselines. ASR-based evaluation further shows a 7.49-point improvement in spoken-answer accuracy on Spoken-MQA.

## 1. 论文的核心问题与整体含义

- **研究背景**：语音大语言模型（Speech LLM）通常以交错方式自回归生成文本 token 和声学 token，从而在保持文本引导的同时实现流式语音输出。该设计的一个副作用是：先前生成的声学 token 会成为后续文本预测上下文的一部分。
- **核心问题**：在相同语音输入、相同模型、相同评分规则下，模型在“语音→文本+语音”（S2TS）模式中生成的内部文本，其答案准确率明显低于“语音→文本”（S2T）模式。论文将这一差异定义为 **输出模式差距（Output-Mode Gap, OMG）**：
  \[
  \Delta_{\text{OMG}} = A_{\text{S2T}} - A_{\text{S2TS(T)}}
  \]
- **研究动机**：OMG 意味着开启语音输出会损害模型回答内容的正确性，这限制了语音交互系统的可靠性。因此，论文希望在不显著牺牲 S2T 能力和原生语音生成行为的前提下，缩小 S2TS 内部文本与 S2T 文本答案质量之间的差距。

## 2. 论文提出的方法论

论文提出 **联合输出在线策略蒸馏（Joint-Output On-Policy Distillation, JO-OPD）**，核心思想是：利用同一个模型自身更强的 S2T 策略作为教师，监督学生生成的 S2TS 联合轨迹中的文本预测。

- **历史投影**：
  - 学生从基础模型初始化，在 S2TS 模式下采样联合输出轨迹 \(z\)。
  - 对每个文本预测位置 \(i\)，学生上下文包含完整交错历史：\(h_i^{\text{stu}}=(x_S, H(z_{<i}), \text{S2TS})\)。
  - 教师上下文只包含学生前缀的纯文本投影：\(h_i^{\text{tea}}=(x_S, P_T(z_{<i}), \text{S2T})\)。
  - 也就是说，教师看不到学生此前生成的声学 token，学生则同时看到文本和声学历史。

- **文本蒸馏目标**：
  - 只在文本词表上比较教师和学生分布，监督文本 token 之间的相对偏好，而不直接强制文本 vs 非文本的整体概率。
  - 设学生分布为 \(p_i\)，教师目标为 \(q_i\)。JO-OPD-Soft 取教师 top-\(k\) 文本 token 并重归一化；JO-OPD-Hard 使用教师最高概率文本 token 的 one-hot 目标。
  - 损失函数：
    \[
    L_T = \mathbb{E}_{z,i}\left[\mathrm{CE}(q_i, p_i)\right]
    \]
    即对训练轨迹和采样文本位置求平均的交叉熵。

- **非文本保留目标**：
  - 为了防止共享参数更新破坏声学和控制器/控制 token 的预测，引入一个冻结参考模型（基础模型）进行正则化。
  - 对 Step-Audio 2：在采样的非文本位置，使用重归一化 top-\(k\) 参考目标在完整输出词表上做交叉熵；学生概率在完整词表上归一化。
  - 对 Baichuan-Audio：分别对 controller 和 codec 分布使用精确的参考-学生 KL 散度；codec 损失梯度通过冻结语音头回传到共享语言模型。
  - 总体目标：
    \[
    L = L_T + L_{\text{pres}}
    \]

- **训练策略**：主实验使用初始学生生成的固定 S2TS 轨迹训练一个 epoch；轨迹刷新实验中重新从更新后的学生采样轨迹。

## 6. 论文的主要结论与发现

- **OMG 广泛存在**：在相同语音输入下，S2TS 内部文本答案准确率显著低于 S2T。Step-Audio-2-mini 上 OMG 在 Spoken-MQA 达 42.87 个百分点，GSM8K 达 29.72 个百分点；Baichuan-Audio 上分别为 12.41 和 10.39 个百分点。
- **JO-OPD 能大幅缩小 OMG**：JO-OPD-Soft 将 Step-Audio 2 的 OMG 从 42.87 降至 16.26（Spoken-MQA），从 29.72 降至 13.04（GSM8K），而 S2T 准确率几乎不变。
- **JO-OPD 优于匹配 SFT 基线**：Self-SFT 和 Response-SFT 在 S2TS(T) 上提升很小甚至下降，说明利用教师 S2T 策略在“学生自己的联合生成前缀”上进行监督是有效的。
- **跨架构有效**：在 Baichuan-Audio 上也降低了 OMG，并提高了 S2TS(T) 和部分口语答案精度。
- **推理指令会放大 OMG**：VoiceBench-BBH 上，要求显式推理时 Base 的 OMG 从 8.2 扩大至 19.0，而 JO-OPD-Soft 在 CoT 下将 S2TS(T) 提升 14.7 个百分点。
- **软目标优于硬目标**：JO-OPD-Soft 比 JO-OPD-Hard 在 S2TS(T) 上更高。
- **文本词表限制和非文本保留很重要**：使用完整词表监督或去掉非文本保留都会显著降低语音答案精度，尽管内部文本精度变化不大。
- **数据规模和轨迹刷新有帮助**：训练集扩大可提升 S2TS(T)；刷新轨迹比固定初始轨迹进一步改善。

## 7. 优点

- **问题定义清晰**：提出并量化了输出模式差距 OMG，是对既有输入侧模态差距研究的重要补充。
